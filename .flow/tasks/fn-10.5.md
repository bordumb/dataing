# fn-10.5 Integrate queue with InvestigationService

## Description

Replace `asyncio.create_task()` in `InvestigationService.start_investigation()` with queue-based enqueue.

### Files to Modify

**dataing/src/dataing/core/investigation/service.py**:

Current code at lines 200-208:
```python
# Fire-and-forget task (loses state on restart)
asyncio.create_task(self._run_investigation(...))
```

Replace with:
```python
from dataing.core.queue import enqueue_investigation

# Create job record
await self._create_job_record(investigation.id, tenant_id)

# Queue for durable execution
await enqueue_investigation(
    investigation_id=str(investigation.id),
    tenant_id=str(tenant_id),
)
```

Add helper method:
```python
async def _create_job_record(self, investigation_id: UUID, tenant_id: UUID) -> None:
    await self._app_db.execute(
        """
        INSERT INTO investigation_jobs (investigation_id, tenant_id, priority)
        VALUES ($1, $2, $3)
        """,
        investigation_id, tenant_id, 0
    )
```

### API Response Changes

Update `start_investigation()` return to include:
- `status: "queued"` instead of "running"
- Job ID for tracking
