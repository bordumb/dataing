### 2. State Machine Logic

Implement state transitions with relaxed assignee constraint:
- OPEN → TRIAGED: any user
- TRIAGED → IN_PROGRESS/BLOCKED: requires assignee OR acknowledged_by
- IN_PROGRESS ↔ BLOCKED: any assigned/acknowledged user
- IN_PROGRESS → RESOLVED: requires resolution_note OR linked investigation synthesis OR runbook
- RESOLVED → CLOSED: any user
- CLOSED → OPEN: any user (reopening)

### 3. Dataset Permission Enforcement

- Users without dataset permission see redacted stubs (title, number, status only)
- Full content (description, comments, events) requires dataset permission
- Check via existing RBAC patterns
