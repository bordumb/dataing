# Replace local bond with PyPI bond-agent

## Overview

Migrate from the local `python-packages/bond` package to the external PyPI package `bond-agent==0.1.2`. This involves updating dependencies, removing tool configuration paths, and deleting the local package directory.

## Scope

**In scope:**
- Update dependency declarations in pyproject.toml files
- Remove tool.uv.sources entries for local bond
- Update mypy/ruff/pytest configuration paths
- Verify import compatibility (bond-agent should use same `from bond import ...` path)
- Delete python-packages/bond directory
- Regenerate lock files

**Out of scope:**
- API changes to bond-agent (assume 0.1.2 is API-compatible)
- Changes to how dataing uses bond

## Approach

1. **Verify import compatibility** - Confirm bond-agent uses `from bond import ...` not `from bond_agent import ...`
2. **Update root pyproject.toml** - Change dependency and remove source/tool paths
3. **Update dataing pyproject.toml** - Change dependency and remove sources
4. **Regenerate locks and sync** - Run `uv lock && uv sync`
5. **Run tests** - Verify everything works with external package
6. **Delete local bond** - Remove python-packages/bond directory
7. **Final verification** - Run full test suite

## Acceptance Criteria

- [ ] `bond-agent==0.1.2` is the only bond dependency (no local path)
- [ ] `uv lock && uv sync` succeeds without errors
- [ ] `just test-ce` passes
- [ ] `just lint` passes
- [ ] `just typecheck` passes
- [ ] `python-packages/bond/` directory is deleted
- [ ] No references to `python-packages/bond` remain in config files

## Risks / Dependencies

- **Import path assumption**: If bond-agent uses `from bond_agent import ...` instead of `from bond import ...`, import statements in 5 files need updating
- **Missing submodules**: If bond-agent doesn't include `bond.tools.schema.SchemaLookupProtocol`, test will fail
- **Dependency conflicts**: bond-agent's transitive deps may conflict with existing pinned versions
