# fn-15.2 Create commands.py with Command types

## Description

Create `maestro/src/maestro/commands.py` with frozen dataclasses representing what the Engine tells the Runner to do.

**Classes to implement:**

1. **Command** - Base dataclass (frozen, empty)

2. **ExecuteStep(Command)** - Execute a workflow step:
   - `step_name: str`
   - `input_data: Any | None = None`

3. **StartBranches(Command)** - Start parallel branch execution:
   - `branch_request: BranchRequest` - from `result.py`

4. **WaitForInput(Command)** - Pause and wait for external input:
   - `token: str`

5. **Stop(Command)** - Terminate workflow:
   - `status: Literal["completed", "failed"]`
   - `final_context: Any | None = None`
   - `error: str | None = None`

**Design notes:**
- Commands are instructions from Engine to Runner
- They are the "output" side of the reducer: `(state, event) -> (state, command)`
- Import `BranchRequest` from `maestro.result`

**File location:** `maestro/src/maestro/commands.py`
