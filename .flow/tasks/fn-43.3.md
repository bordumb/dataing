# fn-43.3 Create issue templates: bug report, feature request, question

## Description

Create GitHub issue templates so that users file structured, actionable issues. Well-designed templates reduce back-and-forth, speed up triage, and make it easier for contributors to pick up work. Three templates are needed: bug report, feature request, and question. A `config.yml` will also add a link to Discord for general discussion.

### Implementation

1. Create the directory `.github/ISSUE_TEMPLATE/` if it does not exist.
2. Create `.github/ISSUE_TEMPLATE/bug_report.yml` (YAML form format):
   - **Title prefix**: `[Bug]`
   - Fields: description (required textarea), steps to reproduce (required textarea), expected behavior (required textarea), actual behavior (required textarea), environment (dropdown: OS, Python version, browser), logs/screenshots (optional textarea), additional context (optional textarea).
   - Labels: `bug`, `triage`
3. Create `.github/ISSUE_TEMPLATE/feature_request.yml`:
   - **Title prefix**: `[Feature]`
   - Fields: problem statement (required textarea), proposed solution (required textarea), alternatives considered (optional textarea), additional context (optional textarea).
   - Labels: `enhancement`, `triage`
4. Create `.github/ISSUE_TEMPLATE/question.yml`:
   - **Title prefix**: `[Question]`
   - Fields: question (required textarea), context / what you tried (optional textarea).
   - Labels: `question`
5. Create `.github/ISSUE_TEMPLATE/config.yml`:
   - Disable blank issues (`blank_issues_enabled: false`).
   - Add external link: "Ask on Discord" pointing to the Discord invite URL (placeholder until fn-44).
