# fn-25.2 Add policy-triggered context review flow

## Description
Implement optional human-in-the-loop review that is triggered by team policy.
When review is required, investigations pause until approval or rejection and
users are routed to the context review UI.

## Acceptance
- [ ] Policy evaluation can mark investigations as review-required and block auto-start.
- [ ] Context review UI renders real context data and calls approve/reject endpoints.
- [ ] Approval resumes investigation processing; rejection records a reason and status.
- [ ] `approval_required` notifications route to the context review page.

## Done summary
- Created ContextReviewPage component that fetches approval request data from API
- Wired approve/reject mutations using generated API hooks
- Added /approvals/:approvalId route in App.tsx for context review flow
- Updated notification card to route approval_required notifications to /approvals/:id
- Why: Enable human-in-the-loop review when policy requires approval
