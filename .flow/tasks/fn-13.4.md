# Task fn-13.4: Observability Subchart

**Epic:** fn-13 Helm Charts for Self-Hosted Deployment
**Status:** blocked-by fn-13.2
**Estimate:** Medium

## Objective

Create optional observability components as a subchart, integrating with fn-12's OTEL implementation.

## Deliverables

1. **Observability subchart** (charts/dataing/charts/observability/):
   - OTEL Collector deployment
   - Jaeger all-in-one deployment (for small deployments)
   - ConfigMap for collector configuration

2. **OTEL Collector template**:
   - Receives OTLP from API/Worker
   - Exports traces to Jaeger
   - Exports metrics to Prometheus (optional)
   - Configurable via values.yaml

3. **Jaeger template**:
   - all-in-one image for simplicity
   - Service for UI access
   - Optional Ingress for external access

4. **values.yaml structure**:
   ```yaml
   observability:
     enabled: false

     otelCollector:
       image:
         repository: otel/opentelemetry-collector-contrib
         tag: "0.96.0"
       resources:
         requests: { cpu: 100m, memory: 128Mi }

     jaeger:
       enabled: true
       image:
         repository: jaegertracing/all-in-one
         tag: "1.54"
       ingress:
         enabled: false
   ```

5. **Integration with core deployments**:
   - When observability.enabled, set OTEL env vars on API/Worker
   - Conditional OTEL_EXPORTER_OTLP_ENDPOINT

## Acceptance Criteria

- [ ] OTEL Collector receives traces from API/Worker
- [ ] Jaeger UI shows traces when enabled
- [ ] Observability can be disabled without errors
- [ ] Resources are configurable via values.yaml
