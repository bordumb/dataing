# fn-48.1 Create migration for thresholds table

## Description

Create the SQL migration that defines the `thresholds` table and a companion `threshold_evaluations` history table. The thresholds table stores metric conditions that, when breached, can automatically trigger investigations. The evaluations table provides an audit trail of every evaluation for hysteresis and debugging.

### Implementation

1. Create migration file `python-packages/dataing/migrations/033_thresholds.sql`.
2. Define the tables:

```sql
-- Threshold-Based Auto-Investigation
-- Epic fn-48: Threshold-Based Auto-Investigation

CREATE TABLE thresholds (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id UUID NOT NULL REFERENCES tenants(id) ON DELETE CASCADE,
    asset_id UUID NOT NULL,
    metric_name TEXT NOT NULL,
    metric_source TEXT NOT NULL DEFAULT 'query',
    metric_query TEXT,
    operator TEXT NOT NULL CHECK (operator IN ('gt', 'lt', 'eq', 'gte', 'lte', 'neq')),
    value NUMERIC NOT NULL,
    severity TEXT NOT NULL DEFAULT 'warning'
        CHECK (severity IN ('info', 'warning', 'critical')),
    cooldown_hours INT NOT NULL DEFAULT 24,
    hysteresis_count INT NOT NULL DEFAULT 1,
    evaluation_cron TEXT NOT NULL DEFAULT '0 * * * *',
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    state TEXT NOT NULL DEFAULT 'normal'
        CHECK (state IN ('normal', 'breached', 'recovering')),
    consecutive_breaches INT NOT NULL DEFAULT 0,
    last_evaluated_at TIMESTAMPTZ,
    last_triggered_at TIMESTAMPTZ,
    last_value NUMERIC,
    created_by UUID REFERENCES users(id) ON DELETE SET NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_thresh_tenant ON thresholds(tenant_id);
CREATE INDEX idx_thresh_tenant_active ON thresholds(tenant_id, is_active);
CREATE INDEX idx_thresh_asset ON thresholds(tenant_id, asset_id);
CREATE INDEX idx_thresh_state ON thresholds(tenant_id, state)
    WHERE is_active = TRUE;

-- Evaluation history for debugging and hysteresis audit trail
CREATE TABLE threshold_evaluations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    threshold_id UUID NOT NULL REFERENCES thresholds(id) ON DELETE CASCADE,
    tenant_id UUID NOT NULL,
    measured_value NUMERIC NOT NULL,
    is_breach BOOLEAN NOT NULL,
    previous_state TEXT NOT NULL,
    new_state TEXT NOT NULL,
    investigation_id UUID,
    evaluated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_te_threshold ON threshold_evaluations(threshold_id);
CREATE INDEX idx_te_evaluated ON threshold_evaluations(threshold_id, evaluated_at DESC);
```

3. Validate the SQL locally against a running Postgres instance.
