# fn-36.4 Implement GitHub OAuth provider and git commit parser

## Description

Build the git provider abstraction and the GitHub implementation. This includes GitHub OAuth token exchange, fetching commit history via the GitHub API (REST), and a git commit parser that extracts structured data from commits. The provider abstraction allows GitLab and Bitbucket to be added later with the same interface. The commit parser shells out to `git log` for local repos or uses the GitHub API for remote repos.

### Implementation

1. Create `python-packages/dataing/src/dataing/adapters/git/` package with `__init__.py`.

2. Create the provider protocol in `python-packages/dataing/src/dataing/adapters/git/provider.py`:
   ```python
   """Git provider protocol and data types."""
   from __future__ import annotations
   from dataclasses import dataclass
   from datetime import datetime
   from typing import Protocol

   @dataclass
   class GitCommit:
       """Parsed commit data from a git provider."""
       hash: str
       author_name: str | None
       author_email: str | None
       message: str | None
       committed_at: datetime | None
       files_changed: list[str]
       raw_diff: str | None = None

   class GitProvider(Protocol):
       """Protocol for git provider implementations."""

       async def exchange_oauth_code(self, code: str) -> str:
           """Exchange an OAuth authorization code for an access token."""
           ...

       async def fetch_commits(
           self, repo_url: str, access_token: str,
           since_hash: str | None = None, branch: str = "main",
           tracked_paths: list[str] | None = None,
       ) -> list[GitCommit]:
           """Fetch commits from a remote repository (incremental)."""
           ...

       async def validate_token(self, access_token: str) -> bool:
           """Check if the access token is still valid."""
           ...
   ```
