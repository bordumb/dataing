# fn-34.2 Convert lineage API response to cytoscape elements with dagre layout

## Description

Implement the core data transformation that converts the lineage API response (from `GET /api/v1/lineage/graph`) into ipycytoscape-compatible elements and renders an interactive DAG using the dagre hierarchical layout algorithm. This is the central piece of the visualization pipeline -- it takes the dict with `root`, `datasets`, `edges`, and `jobs` keys and produces a styled, interactive graph widget.

Depends on: fn-34.1 (module scaffold and ipycytoscape dependency).

### Implementation

1. **Define the element builder** in `lineage_graph.py` that converts the API response into cytoscape node/edge dicts:

```python
# Node type -> visual style mapping
NODE_STYLES = {
    "table": {"background-color": "#3b82f6", "shape": "round-rectangle"},   # blue
    "view": {"background-color": "#10b981", "shape": "round-rectangle"},    # green
    "source": {"background-color": "#f59e0b", "shape": "ellipse"},          # amber
    "job": {"background-color": "#8b5cf6", "shape": "diamond"},             # purple
```

2. **Depth and direction filtering**: Walk edges from the root node using BFS, pruning nodes beyond `depth` hops. When `direction` is `upstream`, only follow edges where `target == current`; for `downstream`, only where `source == current`; for `both`, follow both directions.

3. **Build the CytoscapeWidget** with dagre layout:

```python
def _build_widget(elements: list[dict[str, Any]]) -> Any:
    """Build an ipycytoscape widget from elements with dagre layout.

    Args:
        elements: Cytoscape element dicts.

    Returns:
        ipycytoscape.CytoscapeWidget instance.
    """
    cyto = _get_cytoscape_widget()
    widget = cyto.CytoscapeWidget()
    widget.graph.add_graph_from_json({"elements": elements})

    # Use dagre for hierarchical DAG layout
    widget.set_layout(name="dagre", rankDir="TB", nodeSep=60, rankSep=80)

    # Apply visual styles
    widget.set_style([
        {"selector": "node", "style": {
            "label": "data(label)",
            "text-valign": "center",
            "text-halign": "center",
            "font-size": "12px",
            "width": "label",
            "height": 40,
            "padding": "10px",
        }},
        {"selector": "edge", "style": {
            "curve-style": "bezier",
            "target-arrow-shape": "triangle",
            "arrow-scale": 1.2,
            "line-color": "#94a3b8",
            "target-arrow-color": "#94a3b8",
            "width": 2,
        }},
        # Per-type node styles generated from NODE_STYLES dict
    ])

    return widget
```

4. **Wire into `render_lineage_graph()`** (the stub from fn-34.1):

```python
def render_lineage_graph(lineage_data, *, depth=2, direction="both"):
    if not is_widget_environment():
        _render_ascii_fallback(lineage_data, depth=depth, direction=direction)
        return None

    elements = lineage_to_cytoscape_elements(
        lineage_data, depth=depth, direction=direction
    )
    widget = _build_widget(elements)
    return widget
```
