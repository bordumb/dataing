# Task fn-13.1: Chart Scaffolding

**Epic:** fn-13 Helm Charts for Self-Hosted Deployment
**Status:** ready
**Estimate:** Small

## Objective

Create the foundational Helm chart structure with proper metadata and helper templates.

## Deliverables

1. **Chart directory structure**:
   ```
   charts/dataing/
   ├── Chart.yaml
   ├── values.yaml
   ├── .helmignore
   └── templates/
       └── _helpers.tpl
   ```

2. **Chart.yaml** with:
   - apiVersion: v2
   - name: dataing
   - version: 0.1.0
   - appVersion matching release
   - Dependencies declared (postgresql, redis)

3. **values.yaml** with:
   - Global settings (imageTag, imagePullPolicy)
   - Placeholder sections for api, worker, postgresql, redis, observability
   - Documented with comments

4. **_helpers.tpl** with:
   - `dataing.name`
   - `dataing.fullname`
   - `dataing.chart`
   - `dataing.labels`
   - `dataing.selectorLabels`

## Acceptance Criteria

- [ ] `helm lint charts/dataing` passes
- [ ] Chart structure follows Helm best practices
- [ ] values.yaml is well-documented with comments
- [ ] _helpers.tpl provides reusable label functions
