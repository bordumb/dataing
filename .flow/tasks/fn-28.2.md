### Methods to Add

1. **`list_datasources()`** - List all datasources for tenant
   ```python
   def list_datasources(self) -> list[Datasource]:
       """List all datasources."""
       response = self._request("GET", "/api/v1/datasources")
       return [Datasource.model_validate(ds) for ds in response.json().get("items", [])]
   ```

2. **`test_datasource(datasource_id: str)`** - Test datasource connection
   ```python
   def test_datasource(self, datasource_id: str) -> TestConnectionResult:
       """Test a datasource connection."""
       response = self._request("POST", f"/api/v1/datasources/{datasource_id}/test")
       return TestConnectionResult.model_validate(response.json())
   ```

3. **`get_schema(datasource_id: str)`** - Get datasource schema
   ```python
   def get_schema(self, datasource_id: str) -> DatasourceSchema:
       """Get schema for a datasource."""
       response = self._request("GET", f"/api/v1/datasources/{datasource_id}/schema")
       return DatasourceSchema.model_validate(response.json())
   ```
