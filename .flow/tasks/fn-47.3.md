# fn-47.3 Implement Temporal cron workflow for scheduled execution

## Description

Create a Temporal cron wrapper workflow (`ScheduledInvestigationWorkflow`) that starts a child `InvestigationWorkflow` on each cron tick. This workflow is started once per schedule and Temporal handles the cron scheduling natively. Each cron tick creates a new workflow execution that loads the schedule config, starts the investigation as a child workflow, and records the outcome.

Depends on: fn-47.2 (repository and model must exist).

### Implementation

1. Create `python-packages/dataing/src/dataing/temporal/workflows/scheduled_investigation.py`:

```python
@dataclass
class ScheduledInvestigationInput:
    """Input for the cron wrapper workflow."""
    schedule_id: str
    tenant_id: str

@workflow.defn
class ScheduledInvestigationWorkflow:
    """Cron wrapper that starts InvestigationWorkflow on each tick.

    Started with Temporal's cron_schedule option. Each execution:
    1. Loads schedule config from DB via activity
    2. Checks if schedule is still active (skip if paused)
    3. Starts InvestigationWorkflow as child workflow
    4. Records outcome (success/failure) back to schedule
    """

    @workflow.run
    async def run(self, input: ScheduledInvestigationInput) -> dict:
        # Load schedule config
        config = await workflow.execute_activity(
            "load_schedule_config",
            args=[input.schedule_id, input.tenant_id],
            start_to_close_timeout=timedelta(seconds=30),
        )
        if not config or not config.get("is_active"):
            return {"status": "skipped", "reason": "inactive"}

        # Start child InvestigationWorkflow
        result = await workflow.execute_child_workflow(
            InvestigationWorkflow.run,
            InvestigationInput(
                investigation_id=str(uuid4()),
                tenant_id=input.tenant_id,
                datasource_id=config["datasource_id"],
                alert_data=build_scheduled_alert(config),
                alert_summary=f"Scheduled: {config['goal']}",
            ),
            id=f"sched-{input.schedule_id}-{workflow.now().isoformat()}",
        )

        # Record outcome
        await workflow.execute_activity(
            "record_schedule_run",
            args=[input.schedule_id, result.status],
            start_to_close_timeout=timedelta(seconds=30),
        )
        return {"status": result.status}
```

2. Create activities in `python-packages/dataing/src/dataing/temporal/activities/schedule.py`:
   - `load_schedule_config(schedule_id, tenant_id)` -- reads from ScheduleRepository
   - `record_schedule_run(schedule_id, status)` -- updates last_run_at, last_run_status, and computes next_run_at

3. Add `start_cron_workflow(schedule_id, tenant_id, cron_expression, timezone)` and `stop_cron_workflow(schedule_id)` to `TemporalInvestigationClient`. The start method passes `cron_schedule=cron_expression` to Temporal's `start_workflow`.

4. Wire schedule activities into the Temporal worker registration in `activities/__init__.py`.
