# fn-40.3 Create dataing meta-package with extras for all sub-packages

## Description

Create a `dataing` meta-package on PyPI that acts as a convenience wrapper. Users should be able to `pip install dataing[all]` to get every client package, or `pip install dataing[cli]`, `dataing[sdk]`, or `dataing[notebook]` for individual components. The root `pyproject.toml` already has a `[demo]` extra -- this task adds the public-facing extras for PyPI distribution.

**Depends on:** fn-40.1

### Implementation

1. Update the root `pyproject.toml` to add user-facing optional dependencies:
   ```toml
   [project.optional-dependencies]
   cli = [
       "dataing-cli>=0.1.0",
   ]
   sdk = [
       "dataing-sdk>=0.1.0",
   ]
   notebook = [
       "dataing-notebook>=0.1.0",
   ]
   all = [
       "dataing[cli,sdk,notebook]",
   ]
   # Keep existing dev/docs/demo extras unchanged
   ```

2. Evaluate whether the root `pyproject.toml` should be the meta-package or a separate package:
   - The root currently builds the backend (`dataing` package) which is a large dependency tree not suitable for `pip install`.
   - **Decision**: Create a separate lightweight meta-package at `python-packages/dataing-meta/`:
     ```toml
     [project]
     name = "dataing"
     version = "0.1.0"
     description = "Dataing - Autonomous Data Quality Investigation (meta-package)"
     readme = "README.md"
     requires-python = ">=3.10"
     license = { text = "MIT" }
     dependencies = []  # No required deps - everything is optional

     [project.optional-dependencies]
     cli = ["dataing-cli>=0.1.0"]
     sdk = ["dataing-sdk>=0.1.0"]
     notebook = ["dataing-notebook>=0.1.0"]
     all = ["dataing[cli,sdk,notebook]"]

     [build-system]
     requires = ["hatchling"]
     build-backend = "hatchling.build"
     ```
   - NOTE: The name `dataing` on PyPI must be available. If not, use `dataing-all` or `dataing-platform`.

3. Create a `README.md` for the meta-package that renders well on PyPI:
   ```markdown
   # Dataing

   Autonomous Data Quality Investigation.

   ## Installation

   Install everything:
   ```bash
   pip install dataing[all]
   ```

   Or install individual components:
   ```bash
   pip install dataing[cli]     # CLI tool
   pip install dataing[sdk]     # Python SDK
   pip install dataing[notebook] # Jupyter integration
   ```
   ```

4. Set `requires-python = ">=3.10"` (broader than the backend's `>=3.11` since client packages may work on 3.10).

5. Add the meta-package to the publish workflow matrix.
