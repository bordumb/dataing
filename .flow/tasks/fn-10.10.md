# fn-10.10 Create KEDA ScaledObject for autoscaling

## Description

Create KEDA ScaledObject for queue-based autoscaling of workers.

### Files to Create

**k8s/worker-scaledobject.yaml**:

```yaml
apiVersion: keda.sh/v1alpha1
kind: ScaledObject
metadata:
  name: dataing-worker-scaler
spec:
  scaleTargetRef:
    name: dataing-worker
  pollingInterval: 15
  cooldownPeriod: 300
  minReplicaCount: 2
  maxReplicaCount: 20
  triggers:
  - type: redis
    metadata:
      address: redis-master:6379
      listName: arq:queue:investigations
      listLength: "10"
      activationListLength: "1"
    authenticationRef:
      name: redis-auth
---
apiVersion: keda.sh/v1alpha1
kind: TriggerAuthentication
metadata:
  name: redis-auth
spec:
  secretTargetRef:
  - parameter: password
    name: redis-secrets
    key: REDIS_PASSWORD
```

### KEDA Configuration

- `listLength: "10"` - Scale up when >10 jobs queued per replica
- `activationListLength: "1"` - Activate scaling when at least 1 job
- `cooldownPeriod: 300` - Wait 5 minutes before scaling down
- `minReplicaCount: 2` - Keep minimum 2 workers for availability

### Prerequisites

- KEDA must be installed in cluster
- Redis password in Kubernetes Secret

### Reference

- KEDA Redis scaler: https://keda.sh/docs/scalers/redis-lists/
