# fn-30.2 Add CLI export command with markdown output

## Description

Add `dataing run export <run_id>` CLI command that generates a markdown report of an investigation.

### Implementation

1. **Add Jinja2 dependency** to `python-packages/dataing-cli/pyproject.toml`

2. **Create export module** at `python-packages/dataing-cli/src/dataing_cli/export.py`:
   - Define Jinja2 template for markdown report
   - `render_markdown(investigation: dict) -> str` function
   - Handle missing/optional fields gracefully

3. **Add export command** to `python-packages/dataing-cli/src/dataing_cli/commands/run.py`:
   - `@run_app.command("export")` with `@cli_error_handler`
   - Arguments: `run_id: str`
   - Options: `--output/-o: Path` (optional, defaults to stdout)
   - Fetch investigation via SDK `get_investigation()`
   - Render markdown and output to stdout or file

### Markdown Template Structure
```markdown
# Investigation Report: {id}

**Status:** {status} | **Confidence:** {confidence}%
**Duration:** {duration} | **Generated:** {timestamp}

## Summary
{root_cause}

## Hypotheses Evaluated
### 1. {hypothesis_title}
**Verdict:** Supported/Refuted | **Confidence:** {confidence}%

```sql
{query}
```

**Evidence:** {interpretation}

## Recommendations
- {recommendation_1}
- {recommendation_2}

---
*Generated by Dataing CLI*
```
