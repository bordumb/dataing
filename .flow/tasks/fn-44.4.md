# fn-44.4 Add Discord links to README, docs, and website

## Description

Add the Discord invite link and community references across all user-facing surfaces: README, documentation site, and website. Discoverability is critical for community growth -- every new user who reads the README or browses the docs should see a clear path to the Discord community.

**Depends on**: fn-44.1

### Implementation

1. **README.md** -- Add Discord link in multiple locations:
   - **Badges section** (top of README): Add a Discord badge using shields.io: `[![Discord](https://img.shields.io/discord/SERVER_ID?label=Discord&logo=discord&color=5865F2)](https://discord.gg/INVITE_CODE)`. Replace `SERVER_ID` and `INVITE_CODE` with actual values.
   - **Community section**: Add a "Community" or "Get Help" section (if not already present) with:
     - Discord invite link with brief description ("Join our Discord for support, discussion, and to connect with other users and contributors.")
     - Link to GitHub Discussions (if enabled)
     - Link to CONTRIBUTING.md

2. **Documentation site** (`docs/`) -- Add Discord links:
   - **`docs/index.md`** (or main landing page): Add a "Community" callout or section with the Discord invite link.
   - **`docs/contributing/index.md`** (or equivalent): Reference Discord `#contributing` channel for development discussion.
   - **`mkdocs.yml`**: Add Discord to the `nav` footer or social links if the theme supports it (e.g. Material for MkDocs `extra.social`).

3. **Website** (if applicable): Add Discord link to footer or community page. If no separate website exists, skip this step.

4. **CONTRIBUTING.md**: Update the Community section (added in fn-43.1) to replace the Discord placeholder URL with the actual invite link.

5. **Issue template config**: Update `.github/ISSUE_TEMPLATE/config.yml` (from fn-43.3) to replace the Discord placeholder URL with the actual invite link.

### Key Files
- **MODIFY**: `README.md`
- **MODIFY**: `docs/index.md` (or equivalent landing page)
- **MODIFY**: `mkdocs.yml` (add social link)
- **MODIFY**: `CONTRIBUTING.md` (replace Discord placeholder)
- **MODIFY**: `.github/ISSUE_TEMPLATE/config.yml` (replace Discord placeholder)

### Verification
```bash
# README has Discord badge and link
grep -q "discord.gg\|discord.com/invite" README.md && echo "Discord link in README"
grep -q "shields.io/discord\|img.shields.io/discord" README.md && echo "Discord badge in README"
# Docs have Discord reference
grep -rq "discord" docs/ && echo "Discord in docs"
# CONTRIBUTING has actual Discord link (not placeholder)
grep -q "discord.gg\|discord.com/invite" CONTRIBUTING.md && echo "Discord link in CONTRIBUTING"
# Issue template config has actual Discord link
grep -q "discord.gg\|discord.com/invite" .github/ISSUE_TEMPLATE/config.yml && echo "Discord link in issue config"
```
