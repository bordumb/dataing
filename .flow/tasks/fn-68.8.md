# fn-68.8 Add just worktrees to list work not yet on main

## Description
With dozens of agent worktrees, nobody could tell what was still unmerged: PRs are squash-merged and the merge train rebases branches, so `git branch --merged` misses almost every merged branch. Add a script and just recipe that answer it per worktree as branch, yes/no.

## Acceptance
- `just worktrees` prints, for every git worktree, the branch and whether its work is on origin/main (yes/no), with a short reason for each "no"
- `just worktrees --branches` also covers local branches that no worktree has checked out
- Squash-merged and train-rebased branches count as merged: commits are matched against merged PR heads and main by sha, patch-id and title (title-only matches are flagged)
- Uncommitted edits count as merged only when main already has them (snapshot in a throwaway index, 3-way merge onto main with HEAD as the base); other sessions' worktree indexes and files stay untouched
- Standard library only (runs with python3, no venv); gh is optional


## Done summary
- scripts/worktree_status.py plus `just worktrees [--branches]`. It prints one line per worktree (and, with --branches, per local branch no worktree has checked out): the branch, merged yes/no, and for each "no" a reason (commits not landed, PR open/closed/none, uncommitted files, conflicts with main).
- Merged detection handles squash merges and train rebases. It indexes every merged PR head's commits (not on main) and main's commits by sha, stable patch-id and title (main's " (#N)" suffix is stripped), then matches the branch's own commits. It falls back to merge-tree onto main == main's tree. Title-only matches are flagged "by title: #N".
- Uncommitted edits are snapshotted in a throwaway GIT_INDEX_FILE (read-tree HEAD, add --all of the status paths, write-tree, commit-tree), then merged onto main with --merge-base=HEAD. The result equal to main, or the snapshot's patch-id in a merged PR, means main already has the edits. That catches gallant-boyd's edits in #150 and ignores old-base worktrees whose files simply differ from main.
- Verified on 36 worktrees and 100 branches: all 36 real index files had unchanged mtimes after a run. Title matches were spot-checked (all specific conventional-commit subjects). #206 vs #207 was checked by hand (superseded). ruff check and format are clean, mypy is clean, and `just worktrees --branches` matches the scratch run line for line.
