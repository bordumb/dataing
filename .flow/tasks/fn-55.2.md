# fn-55.2 Update AgentClient to accept memory store

## Description

Modify `AgentClient` to accept an optional `memory_store: AgentMemoryProtocol` parameter. When provided, wire `memory_toolset` to all BondAgent instances.

### Implementation

1. Import `memory_toolset` and `AgentMemoryProtocol` from `bond.tools.memory`
2. Add `memory_store: AgentMemoryProtocol | None = None` parameter to `__init__`
3. Store as `self._memory_store`
4. When creating BondAgent instances (lines 68-102), if `memory_store` is provided:
   - Add `toolsets=[memory_toolset]`
   - Add `deps=memory_store`
5. Change type annotations from `BondAgent[T, None]` to `BondAgent[T, AgentMemoryProtocol | None]`
