# fn-15.8 Create replay.py with Replayer class

## Description

Create `maestro/src/maestro/replay.py` with the Replayer class for deterministic state reconstruction.

**Key principle:** Given an initial state and event sequence, replay should always produce the same final state.

**Classes to implement:**

1. **Replayer[ContextT]** - Deterministic replay:
   - `__init__(engine: Engine[ContextT])`
   - `replay(initial_state: RunState[ContextT], events: list[Event]) -> RunState[ContextT]`
   - `replay_with_commands(initial_state: RunState[ContextT], events: list[Event]) -> tuple[RunState[ContextT], list[Command]]`

**Replay algorithm:**
```python
def replay(self, initial_state, events):
    state = initial_state
    for event in events:
        state, _ = self.engine.apply(state, event)
    return state
```

**Use cases:**
1. **Debugging**: Reproduce exact state at any point in a workflow
2. **Recovery**: Rebuild state after crash by replaying persisted events
3. **Testing**: Verify Engine determinism by comparing live vs replay

**Invariant to verify:**
```python
# If you run a workflow and capture events:
live_outcome = await runner.run(...)
live_events = live_outcome.events

# Replay should produce identical state:
replayed_state = replayer.replay(initial_state, live_events)
assert replayed_state == live_outcome.final_state
```
