# fn-40.4 Verify README rendering on PyPI and Python 3.10+ support

## Description

Ensure that every publishable package's README renders correctly on PyPI (which only supports a subset of Markdown/RST) and that Python 3.10+ is properly declared and tested. PyPI rendering failures result in a blank project page which severely hurts adoption. Python 3.10 support must be verified since the current `requires-python` is `>=3.11` in most packages.

**Depends on:** fn-40.1

### Implementation

1. Verify README rendering for each package using `twine check` and `readme_renderer`:
   ```bash
   pip install build twine readme_renderer[md]
   for pkg in dataing-cli dataing-sdk dataing-notebook; do
       cd python-packages/$pkg
       python -m build
       twine check dist/*
       cd ../..
   done
   ```

2. Fix any README rendering issues found. Common problems:
   - Relative links (e.g., `![logo](./assets/logo.png)`) -- must use absolute URLs.
   - HTML tags not supported by PyPI's markdown renderer.
   - Missing or incorrect `content-type` in `pyproject.toml` for README.
   - Ensure each `pyproject.toml` has `readme = "README.md"` set correctly.

3. Update `requires-python` to `">=3.10"` for client packages:
   - `python-packages/dataing-cli/pyproject.toml` -- change from `>=3.11` to `>=3.10`
   - `python-packages/dataing-sdk/pyproject.toml` -- change from `>=3.11` to `>=3.10`
   - `python-packages/dataing-notebook/pyproject.toml` -- change from `>=3.11` to `>=3.10`
   - **Keep backend at `>=3.11`** -- it uses `3.11+` syntax features.

4. Audit each package for Python 3.10 compatibility:
   - Check for `match/case` statements (3.10+, OK).
   - Check for `X | Y` union type syntax in runtime annotations -- use `from __future__ import annotations` or `Union[X, Y]` for 3.10 compatibility.
   - Check for `tomllib` usage (3.11+) -- use `tomli` backport if needed.
   - Check for `ExceptionGroup` (3.11+).

5. Add Python version classifiers to each `pyproject.toml`:
   ```toml
   classifiers = [
       "Programming Language :: Python :: 3",
       "Programming Language :: Python :: 3.10",
       "Programming Language :: Python :: 3.11",
       "Programming Language :: Python :: 3.12",
       "Programming Language :: Python :: 3.13",
   ]
   ```

6. Add a CI matrix test for Python 3.10 in `.github/workflows/test.yml` (or equivalent):
   ```yaml
   strategy:
     matrix:
       python-version: ["3.10", "3.11", "3.12", "3.13"]
   ```
