# fn-44.1 Set up Discord server with structured channels

## Description

Create and configure the Dataing Discord server as the primary community hub for users and contributors. A well-organized channel structure ensures conversations are discoverable, reduces noise, and sets the tone for a professional open-source community. This is the foundation task for fn-44; all other community tasks depend on it.

### Implementation

1. **Create the Discord server** named "Dataing" with an appropriate icon (use the project logo).
2. **Configure server settings**:
   - Verification level: Medium (must have a verified email and be registered for 5+ minutes).
   - Default notification settings: Only @mentions.
   - Enable Community features (required for welcome screen, server discovery).
3. **Create channel categories and channels**:
   - **GENERAL**
     - `#general` -- open conversation, introductions, community chat.
     - `#announcements` -- read-only for maintainers; release notes, breaking changes, project updates (use Announcement channel type).
   - **SUPPORT**
     - `#support` -- Q&A for users running Dataing (setup, config, troubleshooting).
     - `#bug-reports` -- bug discussion before filing GitHub issues.
   - **DEVELOPMENT**
     - `#contributing` -- discussion for contributors: picking issues, architecture questions, PR feedback.
     - `#showcase` -- share investigations, dashboards, integrations built with Dataing.
   - **META**
     - `#feedback` -- server and project feedback, feature requests.
     - `#off-topic` -- non-project chat.
4. **Configure roles**:
   - `@Maintainer` -- full admin, distinct color (e.g. purple).
   - `@Contributor` -- assigned after first merged PR, permissions to manage threads.
   - `@Community` -- default role for verified members.
5. **Set channel permissions**:
   - `#announcements` -- only `@Maintainer` can post; everyone can read and react.
   - All other channels -- `@Community` and above can post.
6. **Create a permanent invite link** with no expiration for use in README and docs.
