# fn-55.6 Add RLS and audit logging for memory compliance

## Description
Add PostgreSQL Row-Level Security (RLS) and audit logging to the `agent_memories` table for compliance in regulated industries (banking, healthcare, etc.).

### Implementation

1. **Row-Level Security (RLS)**

   Create migration `013_memory_rls.sql`:
   ```sql
   -- Enable RLS on agent_memories
   ALTER TABLE agent_memories ENABLE ROW LEVEL SECURITY;

   -- Policy: users can only access their tenant's memories
   CREATE POLICY tenant_isolation ON agent_memories
       FOR ALL
       USING (tenant_id = current_setting('app.current_tenant', true)::uuid);

   -- Allow superuser/migration user to bypass (for admin operations)
   ALTER TABLE agent_memories FORCE ROW LEVEL SECURITY;
   ```

2. **Tenant Context Setting**

   Update `PgVectorMemoryStore` to set tenant context before queries:
   ```python
   async def _set_tenant_context(self, conn, tenant_id: UUID):
       await conn.execute(f"SET LOCAL app.current_tenant = '{tenant_id}'")
   ```

3. **Audit Logging Table**

   Add to migration:
   ```sql
   CREATE TABLE memory_access_log (
       id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
       memory_id UUID REFERENCES agent_memories(id) ON DELETE SET NULL,
       tenant_id UUID NOT NULL,
       actor_id UUID,  -- user or agent that performed action
       operation TEXT NOT NULL CHECK (operation IN ('create', 'search', 'delete', 'get')),
       query_text TEXT,  -- for search operations, the search query
       result_count INT,  -- number of results returned
       accessed_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
       metadata JSONB DEFAULT '{}'
   );

   CREATE INDEX idx_memory_access_log_tenant ON memory_access_log(tenant_id);
   CREATE INDEX idx_memory_access_log_time ON memory_access_log(accessed_at);
   ```

4. **Audit Logging in PgVectorMemoryStore**

   Add logging after each operation:
   ```python
   async def _log_access(
       self,
       operation: str,
       tenant_id: UUID,
       memory_id: UUID | None = None,
       query_text: str | None = None,
       result_count: int | None = None,
   ):
       await self._pool.execute(
           "INSERT INTO memory_access_log (memory_id, tenant_id, operation, query_text, result_count) "
           "VALUES ($1, $2, $3, $4, $5)",
           memory_id, tenant_id, operation, query_text, result_count,
       )
   ```

### Security Notes
- RLS provides defense-in-depth: even if application code has bugs, DB enforces isolation
- Audit logs are immutable (no UPDATE/DELETE policy)
- Logs retained per compliance requirements (add retention policy later)
- Consider encrypting `query_text` if it may contain PII
