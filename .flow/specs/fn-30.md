# CLI run export for Investigation Bundles

## Overview

Add `dataing run export <run_id>` command to generate self-contained markdown/JSON reports from completed investigations. These reports are suitable for sharing in PRs, Slack, or incident post-mortems.

## Scope

**In Scope:**
- `dataing run export <run_id>` - outputs markdown to stdout
- `--output <file>` - writes to file instead of stdout
- `--format json|markdown` - output format selection
- Report contents: summary, hypotheses, SQL queries, evidence, root cause, recommendations
- Investigation metadata: ID, dataset, goal, duration, confidence
- Evidence chain hash for audit trail

**Out of Scope (deferred):**
- Lineage ASCII visualization (no existing implementation, would bloat scope)
- Custom template files (`--template` flag)
- Partial export flags (`--include-queries`, `--exclude-queries`)

## Approach

### 1. SDK Extension
Add `get_investigation(investigation_id: str)` method to SDK client (`dataing_sdk/client.py`). This calls `GET /api/v1/investigations/{id}` which already exists.

### 2. CLI Command
Add `export` subcommand to `dataing_cli/commands/run.py` following existing patterns:
- Use `@cli_error_handler` decorator
- Access client via `get_client()` from config
- Use `OutputFormat` enum for `--format` flag

### 3. Report Generation
Create `dataing_cli/export.py` module with:
- `render_markdown(investigation: dict) -> str` - Jinja2 template rendering
- `render_json(investigation: dict) -> str` - JSON serialization matching API schema
- `compute_chain_hash(evidence: list) -> str` - SHA256 of full evidence chain

### 4. Template
Inline Jinja2 template in `export.py` (no external template files for simplicity):
```
# Investigation Report: {investigation_id}
**Status:** {status} | **Confidence:** {confidence}%
...
```

## Edge Cases

| Case | Handling |
|------|----------|
| Investigation not found | Print error to stderr, exit code 1 |
| Investigation in-progress | Export partial data with "IN PROGRESS" status marker |
| No evidence collected | Show "No evidence collected" in evidence section |
| File already exists | Overwrite without prompting (matches unix tools behavior) |
| Large SQL queries | Truncate to 2000 chars with "... (truncated)" marker |
