## Done summary
- Created JupyterLab 4.x extension package at frontend/jupyterlab-dataing
- Added status bar widget (DataingStatusBar) showing connection state:
  - Green: Connected
  - Gray: Disconnected  
  - Blue (pulsing): Checking
  - Red: Error
- Created settings schema (schema/plugin.json) with:
  - backendUrl: Backend API URL
  - autoConnect: Auto-connect on startup
  - connectionCheckInterval: Health check frequency
  - showStatusBar: Toggle visibility
- Extension auto-activates on JupyterLab startup
- Uses ISettingRegistry for settings persistence
- Periodic connection checks every 30 seconds
- Compatible with JupyterLab 4.0+ via @jupyterlab/* dependencies

Why:
- Provides visual connection status in JupyterLab
- Configurable backend URL via settings panel
- Integrates with server extension for token management
