# fn-32.8 CLI commands: map-repo, show-repo

## Description

Add CLI commands to the `dataing-cli` package for managing repo mappings. Follow existing Typer patterns from `commands/run.py`.

### Implementation

Create `python-packages/dataing-cli/src/dataing_cli/commands/repo.py`:

**Commands:**

1. **`dataing repo map <dataset> <repo>`** — Create explicit mapping
   - `dataset`: dataset identifier (e.g., "analytics.orders")
   - `repo`: owner/repo format (e.g., "acme/etl-pipelines")
   - `--file-path`: optional file path
   - `--branch`: optional branch
   - `--pattern-type`: "exact" (default) or "glob"
   - Calls POST /dataset-repo-mappings

2. **`dataing repo show <dataset>`** — Resolve and display repo mapping
   - Calls GET /datasets/{dataset_id}/repo?include_all=true
   - Rich table output: repo, file_path, confidence, source
   - If no mapping: "No repo mapping found for {dataset}"

3. **`dataing repo list`** — List all mappings
   - Calls GET /dataset-repo-mappings
   - Rich table with columns: pattern, type, repo, file_path, source, confirmed
   - `--source` filter
   - `--suggestions` flag to show only unconfirmed

4. **`dataing repo confirm <mapping_id>`** — Confirm a suggestion
   - Calls POST /dataset-repo-mappings/{id}/confirm

5. **`dataing repo dismiss <mapping_id>`** — Dismiss a suggestion
   - Calls POST /dataset-repo-mappings/{id}/dismiss

6. **`dataing repo import-dbt <manifest_path> --repo <owner/repo>`** — Import dbt manifest
   - Reads manifest.json from local path
   - Calls POST /dataset-repo-mappings/import-dbt-manifest
   - Shows count of imported models

**Register in main.py:**
```python
from dataing_cli.commands import repo
app.add_typer(repo.app, name="repo")
```
