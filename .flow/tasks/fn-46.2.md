# fn-46.2 Create SQLAlchemy models and workspace repository

## Description

Create the SQLAlchemy ORM models for `Workspace` and `WorkspaceMember`, plus a repository class
that provides async CRUD operations. The repository follows the same patterns as existing
repositories (e.g., `SSORepository` with raw asyncpg, or `DataSource` with SQLAlchemy models).
This is the domain layer foundation that all workspace API routes and filtering will depend on.

Depends on: fn-46.1 (tables must exist).

### Implementation

1. Create `python-packages/dataing-ee/src/dataing_ee/models/workspace.py`:
   ```python
   """Workspace models for multi-workspace support."""
   from uuid import UUID
   from sqlalchemy import Boolean, ForeignKey, String, Text, CheckConstraint, UniqueConstraint
   from sqlalchemy.dialects.postgresql import JSONB
   from sqlalchemy.orm import Mapped, mapped_column, relationship
   from dataing.models.base import BaseModel

   class Workspace(BaseModel):
       """A workspace within a tenant for resource isolation."""
       __tablename__ = "workspaces"
       __table_args__ = (
           UniqueConstraint("tenant_id", "slug", name="uq_workspaces_tenant_slug"),
       )

       tenant_id: Mapped[UUID] = mapped_column(ForeignKey("tenants.id"), nullable=False)
       name: Mapped[str] = mapped_column(String(100), nullable=False)
       slug: Mapped[str] = mapped_column(String(100), nullable=False)
       description: Mapped[str | None] = mapped_column(Text, nullable=True)
       settings: Mapped[dict] = mapped_column(JSONB, default=dict)
       is_default: Mapped[bool] = mapped_column(Boolean, default=False, nullable=False)

       # Relationships
       members: Mapped[list["WorkspaceMember"]] = relationship(
           "WorkspaceMember", back_populates="workspace", cascade="all, delete-orphan"
       )

   class WorkspaceMember(BaseModel):
       """Membership linking users to workspaces with per-workspace roles."""
       __tablename__ = "workspace_members"
       __table_args__ = (
           CheckConstraint("role IN ('owner', 'admin', 'member')", name="ck_workspace_members_role"),
       )

       # Override BaseModel's id -- use composite PK instead
       workspace_id: Mapped[UUID] = mapped_column(
           ForeignKey("workspaces.id", ondelete="CASCADE"), primary_key=True
       )
       user_id: Mapped[UUID] = mapped_column(
           ForeignKey("users.id", ondelete="CASCADE"), primary_key=True
       )
       role: Mapped[str] = mapped_column(String(20), default="member", nullable=False)

       # Relationships
       workspace: Mapped["Workspace"] = relationship("Workspace", back_populates="members")
   ```
   Note: `WorkspaceMember` has a composite PK so it does NOT inherit `BaseModel.id`. Use a
   custom base or override.
