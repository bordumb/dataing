# fn-70.4 M1: chat agent (pydantic-ai) with tools, prompt assembly and streaming

## Description
Spec: `docs/specs/0001_issue_chat.md`. Epic decisions: `.flow/specs/fn-70.md` (read both first).


- New package `agents/chat/`: `build_chat_agent(settings)` using pydantic-ai `Agent` + `AnthropicModel(settings=AnthropicModelSettings(cache flags, extra_body effort))`; config keys `CHAT_AGENT_MODEL` (default `claude-opus-5`), `CHAT_AGENT_EFFORT` (default `low`) in `config.py`.
- Tools (deps = a `ChatDeps` dataclass with tenant, issue, asker principal, services): `get_issue_context`, `list_tables`, `describe_table`, `run_query`, `get_investigation`, `propose_steer` (returns a proposal payload only). No tool writes. Tool errors returned as structured results (use ModelRetry for validation failures).
- Deterministic prompt assembly (`agents/chat/prompt.py`): frozen system prompt; issue context block rendered with sorted keys; history = human comments labelled by author, agent replies, tool-call summaries with query_result_id refs; thread summary + last K turns when long. Unit-test byte stability.
- `run_turn(...)` coroutine: runs `agent.iter()` (or run with event_stream_handler), streams text deltas via a callback, records tool calls and usage (incl. cache_read tokens) — no Temporal/DB coupling here (the activity wires DB writes).
