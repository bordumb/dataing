# fn-30.4 Add unit tests for export command

## Description

Add comprehensive unit tests for the export command covering all scenarios.

### Test Cases

1. **Happy path tests**:
   - Export completed investigation to stdout (markdown)
   - Export to file with `--output`
   - Export as JSON with `--format json`

2. **Error handling tests**:
   - Investigation not found (404) - verify error message and exit code 1
   - Network/API error handling

3. **Edge case tests**:
   - In-progress investigation - verify partial export with status marker
   - Investigation with no evidence - verify "No evidence" placeholder
   - Investigation with empty synthesis - handle gracefully

4. **Format tests**:
   - Verify markdown contains fenced SQL code blocks
   - Verify JSON is valid and parseable
   - Verify chain hash is present and valid SHA256

### Test Patterns

Follow existing test patterns from `test_commands_run.py`:
- Use `CliRunner` from typer.testing
- Mock `get_client()` to return test data
- Use `configured_env` fixture for API key
