# fn-25.5 Stabilize queue worker and retry behavior

## Description
Harden the investigation queue worker and retry path to reduce dropped jobs,
duplicate processing, and noisy failures.

## Acceptance
- [ ] Retry policy is explicit (max retries + backoff) and logged per job.
- [ ] Failed jobs are retried or marked failed with status persisted for inspection.
- [ ] Worker avoids duplicate processing and handles stale processing safely.
- [ ] Retry flow has basic coverage (unit test or reproducible script).
