# fn-29.2 Refactor _watch_run() for timeline streaming

## Description

Refactor `_watch_run()` in `run.py` to use the new timeline formatters and display events progressively with elapsed timestamps.

### File to Modify
`python-packages/dataing-cli/src/dataing_cli/commands/run.py`

### Changes to `_watch_run()`

1. **Track start time and hypothesis index**
   ```python
   start_time = time.time()
   hypothesis_index = 0
   ```

2. **Map event types to formatters**
   - `hypothesis_testing` → `format_hypothesis()` (increment index)
   - `run_progress` with query → `format_query()`
   - `run_evidence` → `format_evidence_item()`
   - `run_completed` → `format_synthesis()`
   - `run_heartbeat` → update elapsed time display only (no new panel)

3. **Use Rich Live with Group for timeline**
   - Build up a list of rendered panels
   - Use `Live(Group(*panels), ...)` to show timeline
   - On each event, append new panel and `live.update()`

4. **Preserve existing behavior for `--json` mode**
   - When `json_output=True`, skip Rich rendering
   - Output handled separately in fn-29.4

### Key Pattern
```python
from rich.console import Group
from display import format_hypothesis, format_query, format_evidence_item, format_synthesis, format_timestamp

panels = []
start_time = time.time()
hypothesis_idx = 0

with Live(Group(), console=console, transient=False) as live:
    for event in client.stream_run(run_id):
        elapsed = format_timestamp(start_time)

        if event.event == "hypothesis_testing":
            hypothesis_idx += 1
            panels.append(format_hypothesis(event, hypothesis_idx, elapsed))
        elif event.event == "run_evidence":
            panels.append(format_evidence_item(event, elapsed))
        # ... etc

        live.update(Group(*panels))
```

### Notes
- Keep `transient=False` so timeline persists after completion
- Handle `KeyboardInterrupt` gracefully (exit 130)
- Call `live.stop()` before printing final completion message
