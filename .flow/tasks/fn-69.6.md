# fn-69.6 [M1] QueryGateway principals, suite sessions and credential errors

## Description
### Goal
Implement D11 in the gateway (design §5.2, §17).

### Implementation
- **Principals** (`adapters/datasource/gateway.py:34-44`):
  - Replace `QueryPrincipal` with `UserPrincipal(user_id, tenant_id, datasource_id)` or `AutomationPrincipal(tenant_id, datasource_id)`.
  - Resolve credentials by kind: users through `CredentialsService`, automation through `datasource_automation_credentials`.
  - There is **no fallback in either direction**. Add `AutomationCredentialsNotConfiguredError`.
- **Connection config comes from fn-69.31's `build_connection_config`.**
  - It strips every authentication field from the datasource's base config and injects only the principal's credential.
  - It **replaces** the current merge at `:218-224`, which keeps base authentication such as BigQuery's `credentials_json`.
- **Session:**
  - `async with gateway.session(principal) as s: await s.execute(sql, actor=…, timeout_seconds=…)`.
  - A session lives inside **one process and one activity**, and is never shared across activities. It reuses one adapter instance; pooled adapters such as Postgres may still use several physical connections.
  - The audit `actor` (e.g. `check:<suite>/<key>`) is passed **per execute call**, not bound to the session.
- **Audit:** write `principal_kind` and `actor` (`_audit_log` at `:239-285`, `app_db.insert_query_audit_log` at `:1815`).
- **Error classification** (`:141-156`): check typed adapter errors first. Only auth-typed errors become `CredentialsInvalidError`.
- **Preflight:** `gateway.has_credentials(principal)` for API endpoints (fn-69.9).
- **FastAPI exception handlers:**
  - `CredentialsNotConfiguredError` → 403 with `action_url` = `/settings/datasources/{id}/credentials`
  - `CredentialsInvalidError` → 401
  - `AutomationCredentialsNotConfiguredError` → 409
## Acceptance
- [ ] Unit tests show no fallback between kinds, and audit rows for both kinds, with the per-call actor and a null `user_id` for automation.
- [ ] Two concurrent executes in one session with different actors produce correctly attributed audit rows.
- [ ] A session reuses one adapter instance, counted by adapter construction.
- [ ] An error on the `author_id` column stays ColumnNotFound.
- [ ] The handlers return 403, 401 and 409 with the documented bodies.
