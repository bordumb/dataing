# fn-29.4 Fix NDJSON output format

## Description

Fix the `--json` output to produce valid NDJSON format (one compact JSON object per line, no indentation).

### File to Modify
`python-packages/dataing-cli/src/dataing_cli/commands/run.py`

### Current Code (lines 105-112)
```python
if json_output:
    for event in client.stream_run(run_id):
        console.print(json.dumps(event.model_dump(), indent=2, default=str))
```

### Fixed Code
```python
if json_output:
    for event in client.stream_run(run_id):
        # NDJSON: one compact JSON object per line
        print(json.dumps(event.model_dump(), separators=(',', ':'), default=str))
```

### Key Changes
1. Remove `indent=2` - NDJSON must be single-line
2. Add `separators=(',', ':')` for compact output (no spaces)
3. Use `print()` instead of `console.print()` to avoid Rich formatting
4. Each event is one complete JSON object on its own line

### NDJSON Format
```
{"event":"run_started","data":{"goal":"..."},"seq":1}
{"event":"hypothesis_testing","data":{"hypothesis":"..."},"seq":2}
{"event":"run_completed","data":{"root_cause":"..."},"seq":10}
```

### Notes
- NDJSON is machine-parseable: `dataing run start ... --json | jq -c 'select(.event == "run_completed")'`
- Each line must be valid JSON independently
- No trailing comma, no array wrapper
## Acceptance

- [ ] Each line is valid JSON parseable by `jq`
- [ ] Output can be piped: `dataing run start ... --json | jq .event`
