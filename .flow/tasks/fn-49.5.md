# fn-49.5 Build JupyterLab Hydrate Command and Widget

## Description
Add UI button and magic command to fetch and inject snapshot state into notebook kernel.

**Why:** This is the user-facing feature. Everything else is plumbing. The user clicks "Hydrate" and their notebook populates with production state.

**Key Design Notes:**
- Use `IPython.get_ipython().push()` to inject variables
- Widget fetches via SDK client (uses stored auth)
- Show progress bar during download
- Consider namespacing: `dataing.alert` instead of `alert` to avoid collisions

**Widget Flow:**
```
[Sidebar: Recent Investigations]
├─ inv_abc123 (2h ago) - orders null spike [Hydrate]
├─ inv_def456 (1d ago) - revenue drop [Hydrate]
└─ inv_ghi789 (3d ago) - schema change [Expired]

User clicks [Hydrate] on inv_abc123
→ Progress: "Downloading snapshot... 45%"
→ Progress: "Deserializing... 80%"
→ Progress: "Injecting into kernel... 100%"
→ Toast: "✓ Hydrated! Variables: alert, hypotheses, evidence, synthesis, df_orders, df_customers"
```

**Location:** `frontend/src/features/notebook/` and notebook magic commands

## Done summary
Implemented JupyterLab Hydrate Command and Widget:

1. **IPython Magic Commands** (`dataing.sdk.magic`):
   - `%dataing hydrate <investigation_id>` - Fetches snapshot, deserializes, injects into kernel
   - `%dataing list` - Lists recent investigations
   - `%dataing help` - Shows usage information
   - Options: `--checkpoint`, `--namespace`, `--overwrite`
   - Variables injected: `dataing_alert`, `dataing_hypotheses`, `dataing_evidence`, `dataing_synthesis`, `dataing_schema`, `dataing_lineage`, `dataing_state`, `df_<table>`

2. **Widget Enhancements** (JupyterLab sidebar):
   - Recent investigations section showing last 10 investigations
   - "Hydrate" button next to each investigation (disabled when no kernel active)
   - "Refresh" button to reload investigations list
   - Hydration progress indicator with states: downloading, deserializing, injecting, complete, error
   - Relative time display (e.g., "2h ago")

3. **Integration**:
   - Widget fetches investigations via proxy endpoint
   - Hydrate button executes magic command in kernel
   - Kernel execution callback wired up in index.ts
