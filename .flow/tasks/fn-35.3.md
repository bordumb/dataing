# fn-35.3 Add compare magic handler with side-by-side diff

## Description

Add a `%dataing compare <id1> <id2>` subcommand that fetches two investigations and displays a side-by-side comparison highlighting the differences in hypotheses, evidence, synthesis conclusions, and status. This is valuable for understanding how the same anomaly evolved over time or how different anomalies were diagnosed differently.

Depends on fn-35.1 because users typically discover investigation IDs via `%dataing history`.

### Implementation

1. **Register the handler in magic.py** -- add `"compare": self._handle_compare` to the `handlers` dict.

2. **Implement `_handle_compare`** in `DataingMagics`:
   ```python
   def _handle_compare(self, args: list[str]) -> None:
       """Handle compare subcommand -- diff two investigations."""
       parser = argparse.ArgumentParser(prog="%dataing compare")
       parser.add_argument("id1", help="First investigation UUID")
       parser.add_argument("id2", help="Second investigation UUID")
       parser.add_argument("--format", "-f", choices=["rich", "plain"],
                           default="rich", help="Output format")
       # parse ...

       if self._state.client is None:
           print("Error: Not connected. Use '%dataing connect' first.",
                 file=sys.stderr)
           return

       # Fetch both investigations
       try:
           inv1 = self._state.client.get_investigation(parsed.id1)
       except Exception as e:
           print(f"Error fetching investigation {parsed.id1}: {e}",
                 file=sys.stderr)
           return

       try:
           inv2 = self._state.client.get_investigation(parsed.id2)
       except Exception as e:
           print(f"Error fetching investigation {parsed.id2}: {e}",
                 file=sys.stderr)
           return

       self._render_comparison(inv1, inv2, parsed.format)
   ```

3. **Implement `_render_comparison`** to produce a diff view:
   - Side-by-side header with investigation IDs, statuses, datasets, timestamps
   - Synthesis comparison: show both summaries with differences highlighted
   - Evidence comparison: list evidence items from each, marking unique vs shared
   - Hypothesis comparison: show which hypotheses appear in one but not the other
   - Status comparison: completed vs failed, duration differences
