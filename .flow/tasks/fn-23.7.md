# fn-23.7 Asset Typeahead Component

## Description

Build a search-based asset picker using React embedded in Lumino for proper a11y.

### Goal
Replace manual `%dataing attach` with a GUI picker that searches across all datasources.

### UI Framework Decision

**Use React** for typeahead (not pure Lumino):
- Autocomplete has complex a11y requirements (ARIA, focus management, keyboard nav)
- Debouncing and loading states are easier in React
- Can use battle-tested patterns from React component libraries

```typescript
import { ReactWidget } from '@jupyterlab/apputils';

class AssetPickerWidget extends ReactWidget {
  render(): JSX.Element {
    return <AssetPicker onSelect={...} />;
  }
}
```

### Implementation

1. **React Component**: `AssetPicker.tsx`
   - Combobox with search input
   - Debounced search (300ms)
   - Dropdown showing: asset name + schema + datasource badge + match_reason highlight
   - Full keyboard navigation (up/down/enter/escape)
   - ARIA attributes for screen readers
   - Loading spinner during search

2. **API integration**:
   - Call `GET /dataing/api/assets/search?q={query}` (proxied to fn-23.1)
   - Handle cursor pagination for "Load more" (optional)
   - Use `match_reason` to highlight matched portion

3. **Selection behavior**:
   - On select, POST to `/dataing/command/attach` (from fn-23.9)
   - Update sidebar to show "Attached to: {asset} ({datasource})"
   - Show asset badge with info icon for details popup

4. **Files**:
   - `frontend/jupyterlab-dataing/src/components/AssetPicker.tsx` - React component
   - `frontend/jupyterlab-dataing/src/assetPicker.ts` - Lumino wrapper

### UX Considerations
- Show "Type to search assets..." as placeholder
- Show "No results for '{query}'" when search returns empty
- Limit dropdown to 8-10 results (Baymard research)
- Highlight matched portion based on `match_reason`:
  - `name_exact` → bold entire name
  - `name_prefix` → bold prefix
  - `name_contains` → bold matching substring
  - `schema_match` → bold schema, normal name
- Show datasource name as subtle badge
- Show `type` icon (table/view/dataset)

### A11y Requirements
- ARIA: `combobox`, `listbox`, `option` roles
- `aria-activedescendant` for current selection
- `aria-expanded` for dropdown state
- Focus trap within dropdown when open
- Escape closes and restores focus to input

### Reuse
- Consider using lightweight React combobox library (e.g., Downshift, Headless UI)
- Or implement from scratch following WAI-ARIA Combobox pattern
