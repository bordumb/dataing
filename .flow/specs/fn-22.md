# fn-22: JupyterLab E2E

## Goal
Prove the JupyterLab sidebar → attach → stream timeline loop works end-to-end.

## Problem
The JupyterLab extension is scaffolded but not proven:
- `checkConnection()` at line 46 in `index.ts` is basic HTTP fetch
- No SSE streaming for timeline
- No attach/bind UX
- TypeScript build verification pending

## Solution
Build a working proof-of-concept that demonstrates:
1. Sidebar widget with connection status
2. Attach to datasource via UI
3. Stream run events via SSE
4. Render evidence timeline in sidebar

## Technical Approach

### Architecture
- Use Lumino widgets (JupyterLab standard)
- SSE via native `EventSource` API
- State management via JupyterLab signals

### Key Components
```typescript
// DataingWidget.ts
class DataingWidget extends Widget {
    private _status: 'disconnected' | 'connected' | 'streaming';
    private _eventSource: EventSource | null;
    private _timeline: EvidenceEvent[];

    async connect(apiUrl: string, apiKey: string): Promise<void>;
    async attach(datasourceUrn: string): Promise<void>;
    streamRun(runId: string): void;
    renderTimeline(): void;
}
```
