# fn-14.7 IssueCreate and IssueWorkspace frontend pages

## Description

Create IssueCreate (/issues/new) and IssueWorkspace (/issues/:id) pages.

### IssueCreate
- Form with title, description, priority, severity, dataset, labels
- Templates dropdown (optional)
- Submit creates issue and navigates to workspace

### IssueWorkspace
- Header with title, status, priority, severity
- Description panel (editable)
- Comments section
- Activity timeline
- Right rail: assignee, labels, watchers, metadata
- "Run Investigation" button

- `frontend/app/src/features/notifications/notifications-page.tsx` - Tabs pattern
- `frontend/app/src/components/shared/page-header.tsx` - Header pattern
