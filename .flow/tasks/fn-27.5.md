# fn-27.5 Create dbt Cloud webhook adapter

## Description
Create a dbt Cloud webhook adapter for test failure notifications.

## What to Do

1. Add `dbt` to `IntegrationProvider` enum in `dataing-ee/models/integration.py`
2. Create `dataing-ee/src/dataing_ee/adapters/integrations/dbt.py`:
   - Extend `IntegrationAdapter`
   - Implement `verify_signature()` - dbt Cloud uses HMAC-SHA256
   - Implement `parse_payload()` - extract test failures from job webhook
   - Implement `get_fingerprint()` for deduplication
   - Implement `to_anomaly_alert()` with type mapping

## Key Consideration

dbt Cloud job webhooks contain run status. We need to:
1. Only process failed runs
2. Extract test failures from run results
3. May need to call dbt Cloud API to get detailed test results

## Reference

- dbt Cloud webhooks: https://docs.getdbt.com/docs/deploy/webhooks
- Follow pattern from `monte_carlo.py`
