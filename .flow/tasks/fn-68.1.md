# fn-68.1 Run DB integration tests in CI on pgvector and stop silent skips

## Description
Backend CI never ran `@pytest.mark.integration` tests, because the root pytest addopts pass `-m 'not integration'`. The older DB integration tests connected to DATABASE_URL directly and turned every exception into `pytest.skip`.

Add a CI job on pgvector/pgvector:pg16 (migration 012 needs the vector extension) and bring in the `migrated_db` fixture. Move the comment, feedback and repo-mapping tests onto it so that schema errors fail.
## Acceptance
- ci-backend.yml runs `pytest python-packages/dataing/tests/integration -m integration` against a pgvector/pgvector:pg16 service
- `migrated_db` fixture (tests/integration/conftest.py) builds a throwaway DB from migrations; no silent skips when integration tests are selected
- Older DB integration tests (comments, feedback, repo mappings) use `migrated_db`; schema errors fail instead of skip
- Verified locally against pgvector:pg16 on :55432
