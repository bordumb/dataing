# fn-16.9 Wire API routes to TemporalInvestigationClient

## Description

Wire API routes to use TemporalInvestigationClient instead of Arq queue.

### Changes

1. Create `TemporalInvestigationClient` class:
   - `start_investigation()` - Starts workflow
   - `cancel_investigation()` - Sends cancel signal
   - `get_status()` - Queries workflow
   - `send_user_input()` - Sends user input signal

2. Update API routes:
   - `POST /investigations` -> call `client.start_investigation()`
   - `DELETE /investigations/{id}` -> call `client.cancel_investigation()`
   - `GET /investigations/{id}/status` -> call `client.get_status()`
   - `POST /investigations/{id}/input` -> call `client.send_user_input()`

3. Add feature flag `INVESTIGATION_ENGINE=temporal` to route between Arq and Temporal
