# fn-39.3 Add API endpoint GET /investigations/{id}/snapshot

## Description

Add a streaming download endpoint that generates a snapshot archive on the fly and returns it as an `application/gzip` response. This allows the frontend and external integrations to download snapshots via the API without needing CLI access.

Also add `POST /investigations/import` for uploading a snapshot archive to create a new replayed investigation (same-tenant only in CE; cross-tenant is EE).
