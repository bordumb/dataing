# fn-15.4 Create log.py with InMemoryEventLog

## Description

Create `maestro/src/maestro/log.py` with an in-memory event log implementation.

**Classes to implement:**

1. **EventLog** - Protocol for event log interface:
   - `append(event: Event) -> Event` - assign seq and store
   - `events() -> list[Event]` - return all events
   - `__len__() -> int` - event count

2. **InMemoryEventLog** - In-memory implementation:
   - `_events: list[Event]` - internal storage
   - `_next_seq: int` - next sequence number (starts at 1)
   - `append(event)` - create new event with assigned seq, append, return it
   - `events()` - return copy of events list
   - `__len__()` - return length

**Design notes:**
- Since events are frozen, `append()` must create a new event instance with the assigned `seq`
- Use `dataclasses.replace(event, seq=self._next_seq)` to create stamped event
- Return a copy from `events()` to prevent external mutation
- Protocol enables future persistent implementations (PostgreSQL, file, etc.)

**File location:** `maestro/src/maestro/log.py`
