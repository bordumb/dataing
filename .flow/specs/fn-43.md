# GitHub Repository Setup

**Plan ref:** Task 1.3.1
**Phase:** 1 (Distribution)
**Designation:** OSS

## Overview

Set up the public GitHub repository with proper structure, contributing guidelines, issue templates, and CI/CD for open-source release.

## Scope

- CONTRIBUTING.md with setup, code style, PR process
- CODE_OF_CONDUCT.md
- Issue templates: bug report, feature request, question
- PR template with checklist
- Branch protection on main
- Dependabot enabled
- Conventional commits enforcement


## Acceptance

- CONTRIBUTING.md with complete dev setup instructions
- CODE_OF_CONDUCT.md
- Issue templates for bug, feature, question
- PR template with checklist
- Branch protection configured
- Dependabot enabled
- DCO sign-off required
