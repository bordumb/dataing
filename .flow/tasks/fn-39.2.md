# fn-39.2 Build tar.gz archive builder with evidence and Parquet results

## Description

Implement the snapshot archive builder that takes a completed investigation and produces a compressed `.tar.gz` file following the schema defined in fn-39.1. Query results are stored as Parquet for space efficiency, but `pyarrow` is an optional dependency since it adds ~200MB to the install. When Parquet is unavailable, results fall back to JSON.

**Depends on:** fn-39.1

### Implementation

1. Create `python-packages/dataing/src/dataing/core/snapshot_builder.py`:

   ```python
   class SnapshotBuilder:
       """Build a tar.gz snapshot archive from an investigation."""

       def __init__(
           self,
           investigation_id: str,
           max_size_bytes: int = 100 * 1024 * 1024,
       ) -> None: ...

       async def build(
           self,
           investigation_state: dict[str, Any],
           evidence_items: list[dict[str, Any]],
           lineage: dict[str, Any] | None = None,
           code_changes: dict[str, Any] | None = None,
           prompts: dict[str, str] | None = None,
       ) -> Path: ...
   ```

2. Evidence serialization logic:
   - Each evidence item written as `evidence/{seq:03d}-{kind}.json`.
   - For `query_result` evidence with `sample_rows`, attempt Parquet via optional `pyarrow`:
     ```python
     try:
         import pyarrow as pa
         import pyarrow.parquet as pq
         # Write sample_rows to evidence/{seq:03d}-results.parquet
     except ImportError:
         # Fall back to JSON
     ```
   - Write `lineage.json`, `code_changes.json` (empty `{}` if not available).
   - Write `prompts/` directory with `hypothesis.txt`, `query.txt`, `synthesis.txt`.

3. Archive assembly:
   - Use `tarfile` to create a `tar.gz` with a top-level `snapshot-{id}/` directory.
   - Write `metadata.json` using `SnapshotMetadata` from fn-39.1 with the complete file inventory.
   - Enforce `max_size_bytes` -- raise `SnapshotSizeExceededError` if the archive exceeds it.
   - Return the `Path` to the generated file in a temp directory.

4. Add `pyarrow` as an optional dependency:
   ```toml
   [project.optional-dependencies]
   snapshot = ["pyarrow>=15.0.0"]
   ```
