# fn-27.3 Add auto-investigation flow to EE provider webhooks

## Description
Wire the EE provider webhook route to trigger auto-investigation when policy evaluates to AUTO.

## Current Problem

CE generic webhook (`dataing/entrypoints/api/routes/integrations.py:280-361`) has policy evaluation and auto-investigation. EE provider webhooks stop at Issue creation.

## What to Do

1. After creating Issue in EE webhook route, call policy evaluation
2. If policy is AUTO, start investigation using `InvestigationStarterService`
3. Pass `AnomalyAlert` (from fn-27.2) to investigation

## Pattern to Follow

From CE generic webhook:
```python
# Line 280-361 in dataing/entrypoints/api/routes/integrations.py
policy_result = await policy_service.evaluate(...)
if policy_result.action == PolicyAction.AUTO:
    await _start_auto_investigation(...)
```
