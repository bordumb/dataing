# fn-48.3 Add threshold CRUD API routes

## Description

Expose REST API endpoints for managing thresholds: create, list, get, update, and delete. These endpoints allow the frontend and CLI to define metric conditions that will automatically trigger investigations when breached. All operations are tenant-scoped via the existing auth middleware.

Depends on: fn-48.2 (repository must exist).

### Implementation

1. Create `python-packages/dataing/src/dataing/entrypoints/api/routes/thresholds.py`:

```python
router = APIRouter(prefix="/thresholds", tags=["thresholds"])

# Pydantic request/response models:
class CreateThresholdRequest(BaseModel):
    asset_id: UUID
    metric_name: str
    operator: str  # gt, lt, eq, gte, lte, neq
    value: float
    severity: str = "warning"  # info, warning, critical
    cooldown_hours: int = 24
    hysteresis_count: int = 1
    evaluation_cron: str = "0 * * * *"
    metric_source: str = "query"
    metric_query: str | None = None

class ThresholdResponse(BaseModel):
    id: UUID
    asset_id: UUID
    metric_name: str
    operator: str
    value: float
    severity: str
    cooldown_hours: int
    hysteresis_count: int
    evaluation_cron: str
    is_active: bool
    state: str
    consecutive_breaches: int
    last_evaluated_at: datetime | None
    last_triggered_at: datetime | None
    last_value: float | None
    created_at: datetime

class UpdateThresholdRequest(BaseModel):
    operator: str | None = None
    value: float | None = None
    severity: str | None = None
    cooldown_hours: int | None = None
    hysteresis_count: int | None = None
    evaluation_cron: str | None = None
    is_active: bool | None = None
    metric_query: str | None = None

class ThresholdEvaluationResponse(BaseModel):
    id: UUID
    measured_value: float
    is_breach: bool
    previous_state: str
    new_state: str
    investigation_id: UUID | None
    evaluated_at: datetime
```

2. Implement six endpoints:
   - `POST /thresholds` -- create threshold, validate operator enum and severity enum
   - `GET /thresholds` -- list thresholds for tenant (query params: `?active_only=true`, `?asset_id=UUID`)
   - `GET /thresholds/{id}` -- get single threshold
   - `PATCH /thresholds/{id}` -- update mutable fields
   - `DELETE /thresholds/{id}` -- delete threshold (cascades evaluation history)
   - `GET /thresholds/{id}/evaluations` -- get evaluation history for a threshold

3. Validate `operator` against allowed values (gt, lt, eq, gte, lte, neq). Validate `severity` against allowed values (info, warning, critical). Return 422 for invalid values.

4. Register the router in `python-packages/dataing/src/dataing/entrypoints/api/routes/__init__.py`.
