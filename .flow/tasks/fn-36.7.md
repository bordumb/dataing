# fn-36.7 Add CLI commands: dataing git connect, sync, list

## Description

Add a `git` command group to the dataing CLI with subcommands for connecting repositories, triggering syncs, and listing connected repos and their changes. This follows the same Typer + Rich pattern used in `commands/repo.py` and `commands/ds.py`. The CLI calls the API endpoints created in fn-36.6 via the SDK client.

### Implementation

1. Create `python-packages/dataing-cli/src/dataing_cli/commands/git.py`:

2. **Connect command:**
   ```python

   console = Console()

   @app.command("connect")
   @cli_error_handler
   def connect_repo(
       ctx: typer.Context,
       url: Annotated[str, typer.Argument(help="Repository URL (e.g., https://github.com/org/repo)")],

       provider: Annotated[str, typer.Option("--provider", "-p", help="Provider")] = "github",
       token: Annotated[str | None, typer.Option("--token", "-t", help="Access token")] = None,
       tracked_paths: Annotated[list[str] | None, typer.Option("--path", help="Tracked paths")] = None,
       branch: Annotated[str, typer.Option("--branch", "-b", help="Default branch")] = "main",
   ) -> None:
       """Connect a git repository for pipeline change detection."""
       # Auto-detect provider from URL if not specified
       # Auto-derive name from URL if not specified (e.g., "org/repo")
   ```

   ```python

   @cli_error_handler
   def list_changes(
       ctx: typer.Context,

       asset: Annotated[str | None, typer.Option("--asset", "-a")] = None,
   ```
