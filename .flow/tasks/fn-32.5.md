# fn-32.5 Bulk import and dbt manifest import endpoints

## Description

Add endpoints for bulk importing mappings via JSON array and importing from dbt manifest.json files.

### Implementation

Add to the repo_mappings router (`routes/repo_mappings.py`):

**1. Bulk import endpoint:**

```python
class BulkRepoMappingItem(BaseModel):
    dataset_pattern: str
    pattern_type: str = "exact"
    repo_owner: str
    repo_name: str
    file_path: str | None = None
    branch: str | None = None
    job_name: str | None = None

class BulkImportRequest(BaseModel):
    mappings: list[BulkRepoMappingItem] = Field(..., min_length=1, max_length=1000)

class BulkImportResponse(BaseModel):
    created: int
    updated: int
    errors: list[str]
```

- `POST /dataset-repo-mappings/bulk` — Accepts JSON array
- Auto-set source='bulk_import', confirmed=true, priority=0, confidence=1.0
- Use `upsert_repo_mapping` for each item to handle duplicates
- Return count of created/updated + any errors

**2. dbt manifest import endpoint:**

```python
class DbtManifestImportRequest(BaseModel):
    repo_owner: str
    repo_name: str
    branch: str | None = None

class DbtManifestImportResponse(BaseModel):
    imported: int
    skipped: int
    models: list[str]
```

- `POST /dataset-repo-mappings/import-dbt-manifest` — Accepts multipart form: manifest file + repo info
- Parse `manifest.json` → iterate `nodes` where `resource_type == "model"`
- Extract: `schema` + `name` → dataset_pattern, `original_file_path` → file_path
- Create with source='dbt_manifest', confirmed=false, priority=20, confidence=0.85
- Skip non-model nodes (tests, sources, seeds)

**dbt manifest parsing logic:**

```python
def parse_dbt_manifest(manifest: dict, repo_owner: str, repo_name: str) -> list[dict]:
    mappings = []
    for node_id, node in manifest.get("nodes", {}).items():
        if node.get("resource_type") != "model":
            continue
        schema = node.get("schema", "").lower()
        name = node.get("name", "").lower()
        if not schema or not name:
            continue
        mappings.append({
            "dataset_pattern": f"{schema}.{name}",
            "pattern_type": "exact",
            "repo_owner": repo_owner,
            "repo_name": repo_name,
            "file_path": node.get("original_file_path"),
            "job_name": node_id,
            "source": "dbt_manifest",
            "confirmed": False,
            "priority": 20,
            "confidence": 0.85,
            "metadata": {"dbt_unique_id": node_id},
        })
    return mappings
```
