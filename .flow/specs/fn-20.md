# fn-20: Evidence Schema

## Goal
Normalize evidence into a queryable, rich format with optional tamper-evidence for enterprise audit requirements.

## Problem
Evidence is where trust lives. Without normalization:
- Can't query "show all runs where null_rate spike caused by schema change"
- Rendering depends on ad-hoc field presence
- No standard way to export evidence for compliance

## Solution
Define a Pydantic schema for evidence with:
1. **Kind discrimination** - `EvidenceKind` enum (query_result, hypothesis, lineage_trace, etc.)
2. **Queryable fields** - Indexed projections for common queries
3. **Optional hash chain** - For enterprise auditability (disabled by default)

## Schema Design
```python
class EvidenceKind(str, Enum):
    QUERY_RESULT = "query_result"
    HYPOTHESIS = "hypothesis"
    LINEAGE_TRACE = "lineage_trace"
    SCHEMA_SNAPSHOT = "schema_snapshot"
    METRIC_CALCULATION = "metric_calculation"
    RUN_SUMMARY = "run_summary"

class EvidenceBase(BaseModel):
    id: UUID
    run_id: UUID
    seq: int
    kind: EvidenceKind
    timestamp: datetime
    content_hash: str  # SHA256 of content (always computed)
    # Optional hash chain for enterprise auditability
    prev_hash: str | None = None  # Only populated if EVIDENCE_HASH_CHAIN=true

class QueryResultEvidence(EvidenceBase):
    kind: Literal[EvidenceKind.QUERY_RESULT]
    sql: str
    row_count: int
    columns: list[str]
    sample_rows: list[dict]
    execution_ms: int

class HypothesisEvidence(EvidenceBase):
    kind: Literal[EvidenceKind.HYPOTHESIS]
    hypothesis_text: str
    confidence: float
    supporting_facts: list[str]
    verdict: Literal["accepted", "rejected", "inconclusive"]
```

## Database Schema
```sql
CREATE TABLE sdk_evidence (
    id UUID PRIMARY KEY,
    run_id UUID NOT NULL REFERENCES sdk_runs(id),
    seq INTEGER NOT NULL,
    kind VARCHAR(50) NOT NULL,
    content JSONB NOT NULL,
    content_hash VARCHAR(64) NOT NULL,
    prev_hash VARCHAR(64),  -- NULL unless hash chain enabled
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE(run_id, seq)
);

-- Queryable projections
CREATE INDEX idx_sdk_evidence_kind ON sdk_evidence(kind);
CREATE INDEX idx_sdk_evidence_run_kind ON sdk_evidence(run_id, kind);
CREATE INDEX idx_sdk_evidence_content ON sdk_evidence USING GIN (content);
```

## Hash Chain (Optional - Enterprise Feature)

**VP Product guidance**: Hash chain is cool but borderline scope creep. Ship without it unless you have an enterprise buyer asking for auditability.

**Implementation**:
- Disabled by default
- Enable via `EVIDENCE_HASH_CHAIN=true` env var
- When enabled: `prev_hash = hash(previous_evidence.content_hash + seq)`
- When disabled: `prev_hash = NULL`

This allows us to ship fast and enable auditability for enterprise customers without blocking the core product.
