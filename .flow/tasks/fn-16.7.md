# fn-16.7 Add Queries for investigation status

## Description

Add Temporal Queries for investigation status.

### Implementation

```python
@workflow.query
def get_status(self) -> InvestigationStatus:
    return InvestigationStatus(
        current_step=self._current_step,
        progress=self._progress,
        is_complete=self._is_complete,
        hypotheses_evaluated=self._hypotheses_evaluated,
    )
```

Track progress by updating `self._progress` after each activity.

### Client Usage

```python
handle = client.get_workflow_handle(workflow_id)
status = await handle.query(InvestigationWorkflow.get_status)
```
