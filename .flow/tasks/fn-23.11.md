# fn-23.11 Timeline UI Improvements

## Description
## Task: Timeline UI Improvements

Enhance the investigation timeline display in the sidebar.

### Goal
Make the timeline more readable with event grouping, icons, and status indicators.

### Implementation

1. **Event grouping**:
   - Group related events (e.g., hypothesis + its evaluation)
   - Collapsible groups for detailed view
   - Summary line for collapsed groups

2. **Event icons**:
   - Different icons per event type: context, hypothesis, query, finding, error
   - Color coding: info (blue), success (green), warning (yellow), error (red)

3. **Status indicators**:
   - Run status badge: "Running", "Completed", "Failed"
   - Progress indicator for multi-phase investigations
   - Timestamp display (relative: "2m ago")

4. **Styling**:
   - Consistent with JupyterLab theme (light/dark mode support)
   - Compact but readable
   - Scroll to latest event option

### Files to Modify
- `frontend/jupyterlab-dataing/src/timeline.ts` - New timeline component or enhance existing
- `frontend/jupyterlab-dataing/src/widget.ts` - Integrate improved timeline
- `frontend/jupyterlab-dataing/style/` - CSS for timeline

### UX Considerations
- Don't overwhelm with too much detail by default
- Allow expand/collapse for detail levels
- Performance: virtualize if event count is high
