# fn-16.5 Implement EvaluateHypothesisWorkflow child workflow

## Description

Implement `EvaluateHypothesisWorkflow` child workflow for parallel hypothesis evaluation.

### Design

Each hypothesis is evaluated as a child workflow with 3 activities:
1. `generate_query` - LLM generates SQL for hypothesis
2. `execute_query` - Run query against datasource
3. `interpret_evidence` - LLM interprets results

### Implementation

```python
@workflow.defn
class EvaluateHypothesisWorkflow:
    @workflow.run
    async def run(self, input: EvaluateHypothesisInput) -> dict:
        query = await workflow.execute_activity("generate_query", ...)
        result = await workflow.execute_activity("execute_query", ...)
        evidence = await workflow.execute_activity("interpret_evidence", ...)
        return {
            "hypothesis_index": input.hypothesis_index,
            "evidence": [evidence],
            "queries_executed": 1,
        }
```

### Parent Workflow Integration

```python
# In InvestigationWorkflow.run()
handles = []
for i, hypothesis in enumerate(hypotheses):
    handle = await workflow.start_child_workflow(
        EvaluateHypothesisWorkflow.run,
        EvaluateHypothesisInput(hypothesis=hypothesis, ...),
        id=f"{workflow.info().workflow_id}-hypothesis-{i}",
    )
    handles.append(handle)

# Wait for all in parallel
results = await asyncio.gather(*handles, return_exceptions=True)
```
