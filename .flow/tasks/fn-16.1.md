# fn-16.1 Set up Temporal dev environment and SDK

## Description

Set up Temporal development environment and add SDK dependency to the project.

### Steps

1. Add `temporalio` to `pyproject.toml` dependencies
2. Add Temporal config to `dataing/src/dataing/config/settings.py`:
   - `TEMPORAL_HOST` (default: `localhost:7233`)
   - `TEMPORAL_NAMESPACE` (default: `default`)
   - `TEMPORAL_TASK_QUEUE` (default: `investigations`)
3. Create `dataing/src/dataing/temporal/__init__.py` package
4. Verify local Temporal server runs: `temporal server start-dev`
5. Verify SDK imports work: `from temporalio import workflow, activity`

### Files to Create/Modify

- `pyproject.toml` - Add temporalio dependency
- `dataing/src/dataing/config/settings.py` - Add Temporal settings
- `dataing/src/dataing/temporal/__init__.py` - New package
