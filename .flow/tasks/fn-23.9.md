# fn-23.9 Unified Workspace Context

## Description

Establish server extension as single source of truth with workspace + kernel scoped state, versioned commands, and proper state machine.

### Goal
Eliminate state drift between magic, sidebar, and server extension. Prevent multi-notebook and multi-workspace confusion.

### Two-Level Identity: Workspace + Kernel

```python
# Server extension state is keyed by (workspace_id, kernel_id)
_notebook_states: dict[tuple[str, str], WorkspaceState] = {}

@dataclass
class WorkspaceState:
    workspace_id: str       # Stable across sessions (from ISettingRegistry)
    kernel_id: str          # Current kernel (transient per session)
    state_version: int      # Monotonically increasing
    state: str              # DISCONNECTED | CONNECTED | BOUND | RUNNING | ERROR
    connection: ConnectionState
    binding: BindingState
    run: RunState
```

**Why workspace_id?**
- Enables "restore previous context" without cross-workspace pollution
- Segments telemetry correctly (same user, different projects)
- Prevents "restore wrong binding in different workspace" bugs

**Generation**:
- First launch: generate UUID, store in ISettingRegistry as `dataing:workspaceId`
- Subsequent launches: read from settings
- JupyterHub: can use workspace path if available

### Active Kernel Resolution Order

How the sidebar finds "active kernel":

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Active notebook panel's sessionContext.session.kernel.id │
│    └─ If notebook focused and has running kernel → use it   │
│                                                             │
│ 2. If no notebook focused OR no kernel running:             │
│    └─ Show empty state: "Select a notebook to connect"      │
│                                                             │
│ 3. [Nice-to-have] Dropdown to choose among running kernels  │
│    └─ Useful for power users with multiple notebooks        │
└─────────────────────────────────────────────────────────────┘
```

### State Machine

```
                    ┌─────────────────┐
                    │  DISCONNECTED   │
                    │  (initial)      │
                    └────────┬────────┘
                             │ connect()
                             ▼
                    ┌─────────────────┐
        clear() ◄───│   CONNECTED     │───► disconnect()
           │        │  (no binding)   │         │
           │        └────────┬────────┘         │
           │                 │ attach()         │
           │                 ▼                  │
           │        ┌─────────────────┐         │
           ├────────│     BOUND       │─────────┤
           │        │ (asset+ds set)  │         │
           │        └────────┬────────┘         │
           │                 │ start_run()      │
           │                 ▼                  │
           │        ┌─────────────────┐         │
           │        │    RUNNING      │─────────┤
           │        │  (run active)   │         │
           │        └───┬────────┬────┘         │
           │            │        │              │
           │     complete()   error()           │
           │            │        │              │
           │            ▼        ▼              │
           │        ┌─────────────────┐         │
           └────────│  BOUND (idle)   │◄────────┘
                    │  or ERROR       │
                    └─────────────────┘
```

**Allowed commands per state**:
| State | Allowed Commands |
|-------|------------------|
| DISCONNECTED | `connect()` |
| CONNECTED | `attach()`, `disconnect()`, `clear()` |
| BOUND | `start_run()`, `attach()`, `clear()` |
| RUNNING | (none - wait for complete/error) |
| ERROR | `start_run()`, `attach()`, `clear()` |

Commands called from wrong state return 400 with `{error: "invalid_state", current_state: "...", allowed: [...]}`.

### Versioned Commands (NOT last-write-wins)

State changes are explicit commands, not arbitrary state patches:

| Command | Endpoint | Payload | Returns |
|---------|----------|---------|---------|
| `connect` | `POST /dataing/command/connect` | `{workspace_id, kernel_id, base_url, expected_version?}` | `{state, state_version}` |
| `attach` | `POST /dataing/command/attach` | `{workspace_id, kernel_id, asset_urn, expected_version?}` | `{state, state_version}` |
| `set_datasource` | `POST /dataing/command/set_datasource` | `{workspace_id, kernel_id, datasource_id, expected_version?}` | `{state, state_version}` |
| `start_run` | `POST /dataing/command/start_run` | `{workspace_id, kernel_id, question, client_request_id, expected_version?}` | `{state, state_version, run_id}` |
| `clear` | `POST /dataing/command/clear` | `{workspace_id, kernel_id, expected_version?}` | `{state, state_version}` |

**Conflict Resolution**:
- If `expected_version` provided and doesn't match current `state_version` → **409 Conflict**
- 409 response includes: `{error: "stale_state", current_state: {...}, current_version: N}`
- Client refreshes state, re-applies user intent with fresh version

### Idempotency for start_run()

Prevents double-click and retry duplicates:

```python
POST /dataing/command/start_run
{
  "workspace_id": "...",
  "kernel_id": "...",
  "question": "Why did revenue drop?",
  "expected_version": 5,
  "client_request_id": "uuid-from-client"  # REQUIRED
}
```

- Server stores `client_request_id` → `run_id` mapping for 60s
- If duplicate `client_request_id` received within window, returns existing `run_id` (not error)
- Prevents accidental duplicate investigations

### State Schema

```python
@dataclass
class WorkspaceState:
    workspace_id: str
    kernel_id: str
    state_version: int = 0
    state: str = "DISCONNECTED"

    connection: ConnectionState = field(default_factory=ConnectionState)
    binding: BindingState = field(default_factory=BindingState)
    run: RunState = field(default_factory=RunState)

@dataclass
class ConnectionState:
    base_url: str | None = None
    connected: bool = False
    credential_mode: str = "none"  # keychain | env_var | session | none
    last_error: str | None = None

@dataclass
class BindingState:
    asset_urn: str | None = None
    datasource_id: str | None = None
    datasource_name: str | None = None

@dataclass
class RunState:
    run_id: str | None = None
    status: str = "idle"  # idle | running | completed | error
    last_seq: int = 0
    started_at: str | None = None  # ISO timestamp
```
