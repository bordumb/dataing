# fn-47.5 Add notification on completion (email, Slack, webhook)

## Description

When a scheduled investigation completes, send notifications to the configured channels. The schedule's `notification_channels` JSONB field specifies which channels to notify (email, Slack, webhook) and their configuration. If `notify_always` is true, notify on every run; otherwise, notify only on anomaly findings or failures. This leverages the existing `EmailNotifier`, `SlackNotifier`, and `WebhookNotifier` adapters.

Depends on: fn-47.3 (the cron workflow must exist to trigger notifications after completion).

### Implementation

1. Create `python-packages/dataing/src/dataing/core/schedule/notification.py`:

```python
class ScheduleNotificationService:
    """Dispatches notifications after scheduled investigation completes."""

    def __init__(
        self,
        email_notifier: EmailNotifier | None,
        slack_notifier: SlackNotifier | None,
        webhook_notifier: WebhookNotifier | None,
    ) -> None:
        """Initialize the notification service."""
        self._email = email_notifier
        self._slack = slack_notifier
        self._webhook = webhook_notifier

    async def notify_completion(
        self,
        schedule: ScheduledInvestigation,
        result: InvestigationResult,
    ) -> None:
        """Send notifications for a completed scheduled investigation."""
        if not schedule.notify_always and result.status == "completed":
            if not self._has_actionable_findings(result):
                return

        for channel in schedule.notification_channels:
            channel_type = channel.get("type")
            if channel_type == "email":
                await self._send_email(channel, schedule, result)
            elif channel_type == "slack":
                await self._send_slack(channel, schedule, result)
            elif channel_type == "webhook":
                await self._send_webhook(channel, schedule, result)
```

2. Create a Temporal activity `notify_schedule_completion` in `python-packages/dataing/src/dataing/temporal/activities/schedule.py` that calls `ScheduleNotificationService.notify_completion()`.

3. Wire the activity into `ScheduledInvestigationWorkflow` after the child workflow completes:

```python
# After child workflow completes in ScheduledInvestigationWorkflow.run():
await workflow.execute_activity(
    "notify_schedule_completion",
    args=[input.schedule_id, result],
    start_to_close_timeout=timedelta(minutes=2),
    retry_policy=RetryPolicy(maximum_attempts=3),
)
```

4. Define the notification payload format for each channel:
   - **Email**: Subject = `"Scheduled Investigation: {goal} - {status}"`, body includes summary and link to investigation
   - **Slack**: Block Kit message with schedule name, status badge, key findings, and link
   - **Webhook**: JSON payload `{"schedule_id", "investigation_id", "status", "findings_url", "goal", "timestamp"}`
