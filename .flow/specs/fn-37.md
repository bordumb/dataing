# Agent Code Context Injection

**Plan ref:** Task 0.3.2
**Phase:** 0 (Foundation)
**Designation:** OSS

## Overview

When generating hypotheses, the agent should have access to recent code changes affecting the investigated asset. Include a "Recent Changes" section in hypothesis prompts with commit summaries, enabling the agent to generate `code_change` hypotheses with commit references.

## Scope

- `get_relevant_code_changes(asset_id, lookback_days)` function
- Modify hypothesis generation prompt to include code changes section
- Add `code_change` hypothesis category
- Evidence can link to specific commits
- Final synthesis includes "Related Code Changes" section

## Acceptance

- Hypothesis prompt includes code changes section (last 14 days, max 5 changes)
- Changes sorted by recency x relevance (exact asset > upstream > path match)
- Agent generates `code_change` hypothesis category with commit reference
- Synthesis includes "Related Code Changes" section when relevant
