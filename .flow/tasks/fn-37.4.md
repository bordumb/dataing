# fn-37.4 Add Related Code Changes section to synthesis prompt and tests

## Description

When the investigation identifies code changes as relevant, the final synthesis should include a "Related Code Changes" section that surfaces commit references alongside the root cause. This gives users a direct link between the anomaly and the code deploy that caused it. Update the synthesis prompt to include code change context and add end-to-end tests for the full code context injection pipeline.

### Implementation

1. Update `build_user()` in `python-packages/dataing/src/dataing/agents/prompts/synthesis.py` to accept optional `code_changes` parameter:
   ```python
   def build_user(
       alert: AnomalyAlert,
       evidence: list[Evidence],
       code_changes: list[CodeChange] | None = None,
   ) -> str:
   ```

2. Add a "Related Code Changes" section to the synthesis prompt when code changes are present and at least one hypothesis with `code_change` category was supported by evidence:
   ```python
   code_changes_section = ""
   if code_changes:
       code_changes_section = "\n## Related Code Changes\n"
       for c in code_changes:
           date_str = c.committed_at.strftime("%Y-%m-%d %H:%M") if c.committed_at else "unknown"
           code_changes_section += f"- {c.commit_hash[:8]} ({date_str}): {c.message}\n"
       code_changes_section += (
           "\nIf a code change is the root cause, reference the commit hash "
           "in your root_cause and include it in recommendations.\n"
       )
   ```

3. Update `SynthesizeInput` in `python-packages/dataing/src/dataing/temporal/activities/synthesize.py` to include `code_changes: list[dict[str, Any]] | None = None`.

4. Update `TemporalAgentAdapter.synthesize_findings_for_temporal()` to accept and forward `code_changes` to the prompt builder.

5. Update the SYSTEM_PROMPT to mention that synthesis should reference commit hashes when code changes are the root cause.

6. Write integration-style tests that verify the full pipeline:
   - `get_relevant_code_changes()` returns changes
   - Changes are included in hypothesis prompt
   - `code_change` hypothesis is generated and tested
   - Synthesis prompt includes "Related Code Changes" section
   - Final output references commit hash
