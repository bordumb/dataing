# fn-44.2 Create welcome message and FAQ bot

## Description

Configure the Discord welcome screen and set up a FAQ bot so that new members are immediately oriented and common questions are answered without maintainer intervention. A strong onboarding experience reduces repeated questions and helps new users become productive quickly.

**Depends on**: fn-44.1

### Implementation

1. **Welcome Screen** (Discord Server Settings > Community > Welcome Screen):
   - Enable the welcome screen.
   - Welcome message: "Welcome to the Dataing community! Dataing is an autonomous data quality investigation platform. Here's how to get started:"
   - Channel links:
     - `#general` -- "Introduce yourself and say hello"
     - `#support` -- "Get help with setup and troubleshooting"
     - `#contributing` -- "Find issues to work on and discuss development"
     - `#announcements` -- "Stay up to date with releases and news"
     - `#showcase` -- "Share what you've built with Dataing"

2. **Welcome DM / Auto-role message** (via bot or Discord's built-in onboarding):
   - Send new members a DM or post in `#general` with:
     - Link to documentation: `https://docs.dataing.io` (or placeholder)
     - Link to GitHub: `https://github.com/dataing/dataing`
     - Link to quickstart guide
     - Link to CONTRIBUTING.md
     - Reminder about `#support` for questions

3. **FAQ Bot** -- Set up a bot (e.g. Carl-bot, MEE6, or a custom Discord bot) with:
   - **Auto-responses** for common keywords/phrases:
     - "how to install" / "getting started" -> link to quickstart docs
     - "how to contribute" -> link to CONTRIBUTING.md
     - "license" -> brief explanation of MIT (CE) + EE license split
     - "bug" / "report a bug" -> link to GitHub issue template
     - "feature request" -> link to GitHub feature request template
   - **Slash command** `/faq` that lists all FAQ topics.
   - **GitHub integration** -- configure a webhook in `#announcements` to post:
     - New releases (GitHub release events)
     - Optional: new issues labeled `good first issue`

4. **Document the bot setup** in `docs/community/discord-bot-setup.md` so maintainers can update FAQ entries.
