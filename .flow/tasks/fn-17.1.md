# fn-17.1 Scaffold Rust workspace structure

## Description

Create the `core/` Rust workspace directory structure with workspace-level Cargo.toml and empty crate scaffolds.

**Directory structure:**
```
core/
├── Cargo.toml                    # Workspace root
├── crates/
│   └── dataing_investigator/
│       ├── Cargo.toml
│       └── src/
│           └── lib.rs
└── bindings/
    └── python/
        ├── Cargo.toml
        ├── pyproject.toml
        └── src/
            └── lib.rs
```

**Workspace Cargo.toml:**
```toml
[workspace]
members = ["crates/dataing_investigator", "bindings/python"]
resolver = "2"
```

**dataing_investigator Cargo.toml:**
```toml
[package]
name = "dataing_investigator"
version = "0.1.0"

[dependencies]

```
