# fn-36.5 Build asset matching: parse SQL/dbt refs from diffs

## Description

Implement the code change parser that extracts table references from git diffs. When commits are synced, their file changes need to be analyzed to determine which data assets (tables, views) are affected. This enables the investigation agent to correlate anomalies with specific code changes. Start with dbt model parsing (well-structured) and basic SQL table extraction, with room to expand to Airflow DAGs and Spark jobs later.
