# fn-20: Evidence Schema

## Goal
Normalize evidence into a queryable, rich, tamper-evident format that enables trust and auditability.

## Problem
Evidence is where trust lives. Without normalization:
- Can't query "show all runs where null_rate spike caused by schema change"
- Can't verify evidence hasn't been tampered with
- Rendering depends on ad-hoc field presence

## Solution
Define a Pydantic schema for evidence with:
1. **Kind discrimination** - `EvidenceKind` enum (query_result, hypothesis, lineage_trace, etc.)
2. **Queryable fields** - Indexed projections for common queries
3. **Tamper-evidence** - Hash chain using `seq` + previous hash

## Schema Design
```python
class EvidenceKind(str, Enum):
    QUERY_RESULT = "query_result"
    HYPOTHESIS = "hypothesis"
    LINEAGE_TRACE = "lineage_trace"
    SCHEMA_SNAPSHOT = "schema_snapshot"
    METRIC_CALCULATION = "metric_calculation"

class EvidenceBase(BaseModel):
    id: UUID
    run_id: UUID
    seq: int
    kind: EvidenceKind
    timestamp: datetime
    prev_hash: str | None  # For hash chain
    content_hash: str  # SHA256 of content

class QueryResultEvidence(EvidenceBase):
    kind: Literal[EvidenceKind.QUERY_RESULT]
    sql: str
    row_count: int
    columns: list[str]
    sample_rows: list[dict]
    execution_ms: int

class HypothesisEvidence(EvidenceBase):
    kind: Literal[EvidenceKind.HYPOTHESIS]
    hypothesis_text: str
    confidence: float
    supporting_facts: list[str]
    verdict: Literal["accepted", "rejected", "inconclusive"]
```

## Database Schema
```sql
CREATE TABLE evidence (
    id UUID PRIMARY KEY,
    run_id UUID NOT NULL REFERENCES runs(id),
    seq INTEGER NOT NULL,
    kind VARCHAR(50) NOT NULL,
    content JSONB NOT NULL,
    content_hash VARCHAR(64) NOT NULL,
    prev_hash VARCHAR(64),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE(run_id, seq)
);

-- Queryable projections
CREATE INDEX idx_evidence_kind ON evidence(kind);
CREATE INDEX idx_evidence_run_kind ON evidence(run_id, kind);
```

## Success Criteria
- [ ] All evidence has a `kind` discriminator
- [ ] Evidence can be queried by kind across runs
- [ ] Hash chain is computed and stored
- [ ] SDK types match backend schema
- [ ] Renderers use discriminated union for type-safe rendering
