# fn-45.1 Create SAML provider module parallel to oidc_provider.py

## Description

Create a `saml_provider.py` module in the EE SSO adapters package that mirrors the structure of
`oidc_provider.py`. This module encapsulates all SAML 2.0 SP logic: parsing IdP metadata, building
AuthnRequest XML, validating SAML responses/assertions (signature, conditions, audience), and
extracting user attributes. The provider is a dependency for every subsequent SAML task.

### Implementation

1. Add `python3-saml` (or `signxml` + `lxml`) to the EE package dependencies in
   `python-packages/dataing-ee/pyproject.toml`.

2. Create `python-packages/dataing-ee/src/dataing_ee/adapters/sso/saml_provider.py` with:
   - `SAMLConfig` dataclass holding `idp_metadata_url`, `idp_entity_id`, `idp_certificate`,
     `sp_entity_id`, `sp_acs_url`, `sp_metadata_url`, `clock_skew_seconds` (default 300).
   - `SAMLUserInfo` dataclass with `name_id`, `email`, `name`, `groups` (list[str] | None).
   - `SAMLProvider` class with methods:
     a. `async load_idp_metadata()` -- fetch + cache IdP metadata XML from `idp_metadata_url`,
        extract SSO endpoint URL and signing certificate.
     b. `build_authn_request(state: str, relay_state: str | None) -> tuple[str, str]` -- return
        (saml_request_deflated_b64, idp_sso_url) for HTTP-Redirect binding.
     c. `async validate_response(saml_response_b64: str, expected_request_id: str | None) -> SAMLUserInfo`
        -- decode, verify XML signature against IdP certificate, check NotBefore/NotOnOrAfter with
        clock skew tolerance, validate audience restriction matches `sp_entity_id`, extract
        NameID + attribute statements.
   - Exception classes: `SAMLResponseError`, `SAMLSignatureError`, `SAMLConditionError`.

3. Follow the same patterns as `OIDCProvider`:
   - `httpx.AsyncClient` for async HTTP calls.
   - Dataclass-based config and result types (no Pydantic in adapter layer).
   - Logging via `logging.getLogger(__name__)`.

4. Re-export from `__init__.py`:
   ```python
   from dataing_ee.adapters.sso.saml_provider import (
       SAMLConfig,
       SAMLProvider,
       SAMLUserInfo,
       SAMLConditionError,
       SAMLResponseError,
       SAMLSignatureError,
   )
   ```

5. Add unit tests in `python-packages/dataing-ee/tests/unit/adapters/sso/test_saml_provider.py`:
   - Test `build_authn_request` produces valid deflated + base64 XML.
   - Test `validate_response` with a crafted valid assertion (use `signxml` to self-sign in test).
   - Test signature failure, expired assertion, audience mismatch.
   - Test clock skew tolerance (5-minute window).
