# fn-15.7 Create runner.py with Async Generator Runner

## Description

Create `maestro/src/maestro/runner.py` with the async Runner that executes commands and emits events.

**Key principles:**
1. Runner translates runtime facts into Events - Engine never sees raw exceptions
2. Branch completion events emitted in **canonical alphabetical order** for determinism
3. Runner can be an async generator yielding events for streaming

**Classes to implement:**

**Step execution (translates facts to events):**

```python
# Emit StepStarted before execution
yield StepStarted(step_name=cmd.step_name)

try:
    result = await step.execute(state.context, cmd.input_data)
    # Extract context_update from result (delta, not full context)
    event = StepCompleted(
        step_name=cmd.step_name,
        context_update=result.context_update,  # Delta
        signal=result.signal
    )
except Exception as e:
    event = StepFailed(step_name=cmd.step_name, error=str(e))

yield event
state, cmd = self.engine.apply(state, event)
```

**Canonical branch ordering (determinism):**

```python
async def _execute_branches(self, branch_request: BranchRequest) -> dict[str, dict]:
    """Execute branches in parallel, return results keyed by branch name."""
    tasks = {}
    for spec in branch_request.branches:
        tasks[spec.name] = asyncio.create_task(self._run_branch(spec))

    # Wait for all branches
    results = {}
    for name, task in tasks.items():
        results[name] = await task

    # Emit BranchCompleted events in CANONICAL ORDER (alphabetical by name)
    for branch_name in sorted(results.keys()):
        yield BranchCompleted(
            branch_name=branch_name,
            context_update=results[branch_name]
        )
```

**Design notes:**
- `run_streaming()` is an async generator for real-time event consumption
- `run()` collects all events and returns `RunOutcome`
- All exceptions caught and converted to `StepFailed` events
- Canonical branch ordering ensures reproducibility across machines
