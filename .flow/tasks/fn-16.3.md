# fn-16.3 Verify crash recovery with worker kill test

## Description

Verify that Temporal properly resumes workflow after worker crash. This validates the core durability guarantee.

### Steps

1. Start workflow that takes >30 seconds (add artificial delay or mock slow activity)
2. Kill worker process mid-execution (SIGKILL)
3. Restart worker
4. Verify workflow resumes from last completed activity
5. Verify workflow completes successfully

### Test Script

```python
# scripts/test_crash_recovery.py
async def test_crash_recovery():
    # Start workflow
    handle = await client.start_workflow(...)

    # Wait for first activity to complete
    await asyncio.sleep(5)

    # Kill worker (external: kill -9 <pid>)
    print("Kill worker now!")
    await asyncio.sleep(10)

    # Verify workflow continues after worker restart
    result = await handle.result()
    assert result.status == "completed"
```
