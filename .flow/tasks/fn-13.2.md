# Task fn-13.2: Core Deployments

**Epic:** fn-13 Helm Charts for Self-Hosted Deployment
**Status:** blocked-by fn-13.1
**Estimate:** Medium

## Objective

Create Kubernetes deployment templates for API and Worker services.

## Deliverables

1. **api-deployment.yaml**:
   - Deployment with configurable replicas
   - Resource requests/limits
   - Liveness and readiness probes
   - Environment variables from ConfigMap/Secret
   - Security context (non-root, read-only fs)

2. **api-service.yaml**:
   - ClusterIP service for internal access
   - Proper port naming

3. **worker-deployment.yaml**:
   - Similar structure to API
   - No service (workers don't expose ports)
   - Appropriate resource defaults for LLM workloads

4. **configmap.yaml**:
   - Non-sensitive configuration
   - OTEL settings (when enabled)
   - Redis/PostgreSQL connection strings

5. **secret.yaml**:
   - Template for sensitive values
   - ANTHROPIC_API_KEY
   - DATADR_ENCRYPTION_KEY
   - Database credentials (if not using subchart)

## Acceptance Criteria

- [ ] API deployment includes health probes
- [ ] Worker deployment has appropriate resource limits
- [ ] ConfigMap and Secret templates work with values.yaml
- [ ] Security contexts are properly configured
- [ ] `helm template` renders valid YAML
