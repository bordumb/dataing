# fn-10.6 Implement adapter reconstruction for workers

## Description

Implement adapter reconstruction in workers so they can connect to tenant datasources without API request context.

### Problem

Current flow passes `BaseAdapter` from API route to service. Workers run in separate processes and can't receive adapter instances. They need to reconstruct adapters from stored configuration.

### Solution

Create a factory function in worker that:
1. Queries `datasources` table for tenant's datasource config
2. Decrypts connection credentials using `ENCRYPTION_KEY`
3. Instantiates appropriate adapter (SQL, Document, etc.)

### Files to Create/Modify

**dataing/src/dataing/adapters/datasource/factory.py** (new):

```python
async def create_adapter_for_datasource(
    db: AppDatabase,
    tenant_id: UUID,
    datasource_id: UUID,
) -> BaseAdapter:
    """Reconstruct adapter from stored datasource config."""
    row = await db.fetchrow(
        """
        SELECT type, connection_config_encrypted
        FROM datasources
        WHERE id = $1 AND tenant_id = $2
        """,
        datasource_id, tenant_id
    )

    if not row:
        raise DatasourceNotFound(datasource_id)

    config = decrypt_connection_config(row["connection_config_encrypted"])
    adapter_class = get_adapter_class(row["type"])
    return await adapter_class.create(config)
```

**dataing/src/dataing/entrypoints/worker.py**:

Use factory in `run_investigation()`:
```python
adapter = await create_adapter_for_datasource(
    ctx["db"],
    tenant_id=job["tenant_id"],
    datasource_id=job["datasource_id"],
)
```
