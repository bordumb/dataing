# fn-44.3 Write moderation guidelines

## Description

Create clear moderation guidelines for the Discord community and document the escalation process. Moderation guidelines protect community members, give moderators consistent rules to enforce, and align with the project's Code of Conduct (fn-43.2). Documenting these ensures continuity as the moderation team grows.

**Depends on**: fn-44.1

### Implementation

1. **Create `docs/community/moderation-guidelines.md`** with the following sections:
   - **Purpose** -- explain why moderation exists: to maintain a welcoming, productive environment aligned with the Code of Conduct.
   - **Code of Conduct Reference** -- link to `CODE_OF_CONDUCT.md` and state that Discord moderation enforces the same standards.
   - **Channel-specific rules**:
     - `#announcements` -- maintainer-only posts; no discussion (use threads or #general).
     - `#support` -- stay on topic; no spam; use threads for extended debugging.
     - `#contributing` -- technical discussion only; be constructive in code reviews.
     - `#showcase` -- self-promotion is OK if it involves Dataing; no unrelated marketing.
     - `#off-topic` -- relaxed rules but Code of Conduct still applies.
   - **Prohibited behavior** (aligned with Code of Conduct):
     - Harassment, discrimination, hate speech
     - Spam, unsolicited DMs, excessive self-promotion
     - Sharing private information (doxxing)
     - NSFW content
     - Impersonation of maintainers or staff
   - **Enforcement ladder**:
     - **Verbal warning** -- moderator reminds the user of guidelines via DM or public reply.
     - **Message deletion** -- offending message removed with brief explanation.
     - **Temporary mute** -- 24-hour mute for repeated minor violations.
     - **Temporary ban** -- 7-day ban for serious or repeated violations.
     - **Permanent ban** -- for egregious violations or repeated bans.
   - **Escalation process**:
     - Moderators handle warnings and mutes.
     - Bans require agreement from at least 2 moderators or 1 maintainer.
     - Appeals can be sent to the enforcement email from `CODE_OF_CONDUCT.md`.
   - **Moderator expectations**:
     - Respond to reports within 24 hours.
     - Document all enforcement actions in a private `#mod-log` channel.
     - Stay impartial; recuse if personally involved.

2. **Create `#mod-log` channel** (private, visible only to @Maintainer role) for logging enforcement actions.

3. **Pin a summary** of the guidelines in `#general` and link to the full document.
