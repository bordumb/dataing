# fn-14.8 Integration webhooks infrastructure (EE)

## Description

Create webhook infrastructure for external integrations.

### CE: Generic Webhook Ingest

Add to CE (dataing/):
- POST /api/integrations/webhook-generic - Minimal signed endpoint
- Accepts: title, description, dataset_id, severity, labels, source_provider, source_external_id
- Uses shared secret for signature verification
- Creates issue via standard CRUD

### EE: Provider Infrastructure

Add to EE (dataing-ee/):
- `integrations` table (provider, config, signing_secret)
- `integration_events` table (idempotency)
- CRUD for integrations management

### API (EE)
- GET /api/integrations - List integrations
- POST /api/integrations - Create integration
- PATCH /api/integrations/:id - Update integration
- POST /api/integrations/:provider/webhook - Provider-specific webhook

### Implementation
- Signature verification (HMAC) for both CE and EE
- Idempotency via integration_events (EE) or primary dedup index (CE)
- Async processing queue for EE provider webhooks

- `dataing/src/dataing/adapters/notifications/webhook.py` - Signature pattern
