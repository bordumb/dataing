# fn-29.5 Add non-TTY detection and fallback

## Description

Detect when stdout is not a TTY (e.g., piped to file or another command) and fall back to plain text output without Rich Live display.

### File to Modify
`python-packages/dataing-cli/src/dataing_cli/commands/run.py`

### Changes

1. **Detect TTY at start of `_watch_run()`**
   ```python
   import sys
   is_tty = sys.stdout.isatty()
   ```

2. **Conditional Rich Live usage**
   ```python
   if is_tty and not json_output:
       # Use Rich Live timeline display
       with Live(...) as live:
           for event in client.stream_run(run_id):
               # ... update live display
   else:
       # Plain text fallback
       for event in client.stream_run(run_id):
           if json_output:
               print(json.dumps(event.model_dump(), separators=(',', ':')))
           else:
               # Simple text output without ANSI codes
               print(f"[{format_timestamp(start_time)}] {event.event}: {event.data.get('message', '')}")
   ```

3. **Plain text format for non-TTY**
   ```
   [00:01] run_started: Starting investigation...
   [00:05] hypothesis_testing: Testing hypothesis #1
   [00:12] run_evidence: Evidence supports hypothesis
   [01:30] run_completed: Investigation complete
   ```

### Alternative: Use Rich Console force_terminal
```python
# Could also use Rich's built-in detection
console = Console(force_terminal=False)  # Respect TTY detection
# Then use console.is_terminal to check
```

### Notes
- Important for CI/CD pipelines and log capture
- `tee` command should work: `dataing run start ... | tee output.log`
- Ensure no ANSI escape codes leak into non-TTY output
