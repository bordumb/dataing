# fn-41.6 Test full stack startup on Linux and macOS

## Description

Manually test the complete Docker Compose self-host bundle on both Linux and macOS (Intel + Apple Silicon) to verify it works end-to-end. This is the final integration gate before the bundle is released. Temporal is known to require 2-4GB RAM, so total memory usage must be profiled and documented.

**Depends on**: fn-41.4 (health checks and volumes), fn-41.5 (env docs)

### Implementation

1. Test on a clean Linux machine (or VM/CI runner):
   - Clone the repository
   - `cp .env.example .env`, fill in `ANTHROPIC_API_KEY`
   - Generate encryption key: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`
   - `docker compose up -d`
   - Wait for all services healthy (timeout 120s)
   - Run smoke tests (API health, frontend loads, Temporal UI loads)
   - Trigger a test investigation via API
   - Verify worker picks up the workflow in Temporal
   - Record memory usage: `docker stats --no-stream`
   - `docker compose down -v`
2. Repeat on macOS Intel (x86_64) if available.
3. Repeat on macOS Apple Silicon (arm64):
   - Verify all images build/pull for `linux/arm64`
   - Check for any architecture-specific issues (e.g., temporalio image compatibility)
4. Document resource requirements:
   - Measure and record peak memory per service
   - Measure total stack memory at idle and under load
   - Measure cold-start time (all images pulled) and warm-start time (images cached)
   - Update `.env.example` or a new `SELF_HOST.md` with minimum requirements
5. Test edge cases:
   - Start with no `.env` file (should fail gracefully with clear error)
   - Start with missing `ANTHROPIC_API_KEY` (should start but warn)
   - `docker compose down` then `up` again (data persistence)
   - `docker compose down -v` then `up` again (clean start)
6. Create a CI smoke test script `infra/smoke-test.sh` that automates the basic checks:
   ```bash
   #!/bin/bash
   set -e
   echo "Waiting for services..."
   timeout 120 bash -c 'until curl -sf http://localhost:8000/health; do sleep 5; done'
   echo "API: OK"
   curl -sf http://localhost:3000/ > /dev/null && echo "Frontend: OK"
   curl -sf http://localhost:8233/ > /dev/null && echo "Temporal UI: OK"
   echo "All smoke tests passed"
   ```

### Key Files
- **CREATE**: `infra/smoke-test.sh`
- **MODIFY**: `.env.example` (update minimum resource requirements comment)
- **REFERENCE**: `docker-compose.yml`

### Verification
```bash
# Run the smoke test
bash infra/smoke-test.sh

# Check memory usage
docker stats --no-stream --format "table {{.Name}}\t{{.MemUsage}}\t{{.CPUPerc}}"

# Verify cold start time
time docker compose up -d

# Verify warm start time (after down without -v)
docker compose down && time docker compose up -d

# Check all containers healthy
docker compose ps --format "{{.Service}}: {{.Health}}"
```
