# Notebook Investigation History and Replay

**Plan ref:** Task 0.2.3
**Phase:** 0 (Foundation)
**Designation:** OSS

## Overview

Add `%dataing history`, `%dataing replay`, and `%dataing compare` commands to the notebook extension. Enable browsing past investigations, loading them for review, and comparing two investigations side-by-side.

## Scope

- `%dataing history` with filtering by dataset, recency, and pagination
- `%dataing replay <id>` loads investigation into context with all evidence
- `%dataing compare <id1> <id2>` shows diff between two investigations
- API-backed browsing (not just in-memory session history)

## Approach

1. Add history handler to magic.py command dict
2. Use existing `GET /api/v1/investigations` endpoint with query params
3. Render history as rich HTML table with clickable entries
4. Replay loads investigation state and shows evidence/synthesis
5. Compare highlights differing hypotheses and findings
