# fn-23.4 Connection Wizard UI Component

## Description

Build a multi-step connection wizard in the JupyterLab sidebar using React embedded in Lumino.

### Goal
Replace `%dataing connect` as the default connection method with a GUI wizard that detects auth mode.

### UI Framework Decision

**Use React embedded in Lumino** (not pure Lumino):
- Wizard steps have complex form state, validation, and conditional UI
- React provides better a11y defaults (focus management, keyboard nav)
- JupyterLab supports this pattern via `ReactWidget.create()`

```typescript
import { ReactWidget } from '@jupyterlab/apputils';

class ConnectionWizardWidget extends ReactWidget {
  render(): JSX.Element {
    return <ConnectionWizard onConnect={...} onCancel={...} />;
  }
}
```

### Implementation

1. **Wizard steps**:
   - Step 1: Backend URL (text input with recent URLs dropdown)
   - Step 2: Authentication (shows detected mode + API key input)
     - Displays: "Detected mode: [OS Keychain / Env Var / Session Only]"
     - API key input (password type)
     - Checkbox: "Don't store (session only)" if keychain available
   - Step 3: Test connection (auto-triggered, shows success/failure with details)
   - Step 4: Save (confirmation, stores via fn-23.2 credential handler)

2. **React Components** (in `frontend/jupyterlab-dataing/src/components/`):
   - `ConnectionWizard.tsx` - Main wizard with step state
   - `UrlStep.tsx` - URL input with validation
   - `AuthStep.tsx` - Shows auth mode, API key input
   - `TestStep.tsx` - Connection test result
   - `ConfirmStep.tsx` - Summary + save

3. **State management**:
   - React `useState` for form values
   - On save, POST to `/dataing/credentials` and update connection state

4. **Files**:
   - `frontend/jupyterlab-dataing/src/components/ConnectionWizard.tsx` - React component
   - `frontend/jupyterlab-dataing/src/connectionWizard.ts` - Lumino wrapper

### Files to Modify
- `frontend/jupyterlab-dataing/src/components/` - New directory for React components
- `frontend/jupyterlab-dataing/src/connectionWizard.ts` - ReactWidget wrapper
- `frontend/jupyterlab-dataing/src/widget.ts` - Integrate wizard into sidebar
- `frontend/jupyterlab-dataing/package.json` - Add React deps if needed

### UX Considerations
- Show detected credential mode prominently
- "Edit" button to re-enter wizard if already connected
- Loading spinner during test
- Clear error messages with troubleshooting hints:
  - "Connection refused" → "Check that the Dataing backend is running at this URL"
  - "401 Unauthorized" → "Invalid API key. Check for typos or generate a new key."
- "Copy snippet" button in connected state (outputs magic equivalent)

### Reuse
- Use `@jupyterlab/apputils` `ReactWidget` base class
- See JupyterLab react-widget example for patterns
