# fn-46.3 Add workspace CRUD API routes

## Description

Create the REST API routes for workspace management: creating, listing, updating, deleting
workspaces, and managing workspace membership. These routes are gated behind the multi-workspace
enterprise feature flag and require tenant-admin permissions. The routes expose the
`WorkspaceRepository` operations from fn-46.2 through the FastAPI router.

Depends on: fn-46.2 (repository must exist).

### Implementation

1. Create `python-packages/dataing-ee/src/dataing_ee/entrypoints/api/routes/workspaces.py`:
   ```python
   """Workspace management API routes."""
   router = APIRouter(prefix="/workspaces", tags=["workspaces"])

   # -- Pydantic models --

   class CreateWorkspaceRequest(BaseModel):
       name: str = Field(..., min_length=1, max_length=100)
       description: str | None = None
       slug: str | None = None  # Auto-generated from name if not provided

   class UpdateWorkspaceRequest(BaseModel):
       name: str | None = None
       description: str | None = None
       settings: dict[str, Any] | None = None

   class WorkspaceResponse(BaseModel):
       id: UUID
       tenant_id: UUID
       name: str
       slug: str
       description: str | None
       settings: dict[str, Any]
       is_default: bool
       member_count: int
       created_at: datetime
       updated_at: datetime

   class AddMemberRequest(BaseModel):
       user_id: UUID
       role: str = "member"  # owner | admin | member

   class WorkspaceMemberResponse(BaseModel):
       user_id: UUID
       email: str
       name: str | None
       role: str
       joined_at: datetime

   # -- Routes --

   @router.post("/", response_model=WorkspaceResponse, status_code=201)
   async def create_workspace(body: CreateWorkspaceRequest, ...) -> WorkspaceResponse:
       """Create a new workspace in the current tenant."""

   @router.get("/", response_model=list[WorkspaceResponse])
   async def list_workspaces(...) -> list[WorkspaceResponse]:
       """List all workspaces in the current tenant."""

   @router.get("/{workspace_id}", response_model=WorkspaceResponse)
   async def get_workspace(workspace_id: UUID, ...) -> WorkspaceResponse:
       """Get a specific workspace."""

   @router.put("/{workspace_id}", response_model=WorkspaceResponse)
   async def update_workspace(workspace_id: UUID, body: UpdateWorkspaceRequest, ...) -> WorkspaceResponse:
       """Update workspace name, description, or settings."""

   @router.delete("/{workspace_id}", status_code=204)
   async def delete_workspace(workspace_id: UUID, ...) -> None:
       """Delete a workspace. Cannot delete the default workspace."""

   @router.post("/{workspace_id}/members", response_model=WorkspaceMemberResponse, status_code=201)
   async def add_member(workspace_id: UUID, body: AddMemberRequest, ...) -> WorkspaceMemberResponse:
       """Add a user to a workspace."""

   @router.get("/{workspace_id}/members", response_model=list[WorkspaceMemberResponse])
   async def list_members(workspace_id: UUID, ...) -> list[WorkspaceMemberResponse]:
       """List all members of a workspace."""

   @router.put("/{workspace_id}/members/{user_id}")
   async def update_member_role(workspace_id: UUID, user_id: UUID, ...) -> WorkspaceMemberResponse:
       """Update a member's role in a workspace."""

   @router.delete("/{workspace_id}/members/{user_id}", status_code=204)
   async def remove_member(workspace_id: UUID, user_id: UUID, ...) -> None:
       """Remove a user from a workspace."""
   ```

2. Register the router in the EE app:
   - Update `python-packages/dataing-ee/src/dataing_ee/entrypoints/api/app.py` to include the
     workspace router.

3. Guard routes with feature flag:
   - Check `Feature.MULTI_WORKSPACE` (add to entitlements if not already present).
   - Return 403 if the feature is not enabled for the tenant.

4. Business rules:
   - Cannot delete the default workspace (`is_default=True`).
   - Auto-generate slug from name if not provided: `slugify(name)`.
   - Creating a workspace auto-adds the requesting user as `owner`.
   - Workspace names must be unique within a tenant (enforced by slug uniqueness).

5. Add tests in `python-packages/dataing-ee/tests/unit/routes/test_workspaces.py`:
   - Test CRUD lifecycle: create, list, get, update, delete.
   - Test cannot delete default workspace.
   - Test member management: add, list, update role, remove.
   - Test slug auto-generation.
   - Test feature flag enforcement (403 when disabled).
