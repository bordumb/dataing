# fn-16.2 Create minimal InvestigationWorkflow POC

## Description

Create a minimal proof-of-concept `InvestigationWorkflow` with 3 activities to validate Temporal works end-to-end.

### Steps

1. Create `dataing/src/dataing/temporal/workflows/investigation.py`:
   - `InvestigationWorkflow` class with `@workflow.defn`
   - `run()` method with `@workflow.run` that calls 3 activities sequentially
2. Create activity factories in `dataing/src/dataing/temporal/activities/`:
   - `make_gather_context_activity()` - Returns mock schema/lineage
   - `make_generate_hypotheses_activity()` - Returns hardcoded hypotheses
   - `make_synthesize_activity()` - Returns mock synthesis
3. Create minimal test worker script to run POC
4. Run investigation via Temporal CLI: `temporal workflow start`

### Implementation Pattern

```python
@workflow.defn
class InvestigationWorkflow:
    @workflow.run
    async def run(self, input: InvestigationInput) -> InvestigationResult:
        context = await workflow.execute_activity(
            "gather_context",
            args=[input],
            start_to_close_timeout=timedelta(minutes=5),
        )
        # ... more activities
```
