# fn-69.26 [M3] Reconciliation poll and removal of the pasted-token integration

## Description
### Goal
Catch missed webhooks, and delete the personal access token (PAT) flow and every path that depends on it (design §6.5, §6.9, §17).

### Implementation
- **Poll:** an EE schedule runs every 10 minutes for each source. It compares the branch HEAD with `last_synced_sha`, and starts a sync if they differ.
- **Remove:**
  - `POST /git/repos` (`routes/git_repos.py:157-188`).
  - **The manual sync endpoint** (`:285`), because it depends on the stored token.
  - The old OAuth App code (`adapters/git/github.py:18,41-90` and `provider.py:31`).
  - `dataing git connect --token` (`dataing_cli/commands/git.py:31-89`).
- **Update:** the ORM model (`models/git_repository.py:26`) and the DB helpers. A migration drops `git_repositories.access_token_encrypted`.
- **Keep** `sync.py`, `pr_enrichment.py` and `url_templates.py` for the fn-36 follow-up, rewiring them to installation tokens later.
- **Scope:** "no OAuth" means the old OAuth App integration only. fn-69.23's GitHub App user authorization stays.
## Acceptance
- [ ] A missed push is synced within one poll interval.
- [ ] A test of the route surface after the migration shows no endpoint that reads the dropped column, and the related tests are removed or updated.
