# fn-69.24 [M3] Settings: Git (EE UI)

## Description
### Goal
The admin UI for fn-69.23 and fn-69.25 (design §8).

### Implementation
- **Pages** in `features/settings/git/`:
  - Register the app (host and org).
  - An install link and the list of installations.
  - Pick a repo, folder and branch; only repos the user administers are offered.
  - Sync status, with file:line errors.
  - A "bootstrap PR" button when the folder is missing.
  - Clear messages when a claim is rejected ("you must be an org admin").
- **Types:** EE endpoints use `customInstance` with hand-written types (pattern: `features/settings/audit/audit-log-settings.tsx:40,157-160`).
- **Non-EE plans:** show the existing upgrade prompt.
## Acceptance
- [ ] The whole flow works against a mocked API in vitest, including a rejected claim.
- [ ] Non-EE plans see the upgrade prompt.
