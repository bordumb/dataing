**Pydantic schemas:**

```python
class CreateRepoMappingRequest(BaseModel):
    dataset_pattern: str = Field(..., min_length=1, max_length=500)
    pattern_type: str = Field(default="exact")  # "exact" or "glob"
    repo_owner: str = Field(..., min_length=1, max_length=200)
    repo_name: str = Field(..., min_length=1, max_length=200)
    file_path: str | None = None
    branch: str | None = None
    job_name: str | None = None
    metadata: dict[str, Any] | None = None

class UpdateRepoMappingRequest(BaseModel):
    dataset_pattern: str | None = None
    pattern_type: str | None = None
    repo_owner: str | None = None
    repo_name: str | None = None
    file_path: str | None = None
    branch: str | None = None
    job_name: str | None = None
    metadata: dict[str, Any] | None = None

class RepoMappingResponse(BaseModel):
    id: str
    dataset_pattern: str
    pattern_type: str
    priority: int
    repo_owner: str
    repo_name: str
    file_path: str | None
    branch: str | None
    job_name: str | None
    source: str
    confidence: float
    confirmed: bool
    metadata: dict[str, Any]
    last_verified_at: datetime | None
    created_at: datetime
    updated_at: datetime

class RepoMappingListResponse(BaseModel):
    items: list[RepoMappingResponse]
    total: int
```

**Endpoints:**
- `POST /dataset-repo-mappings` — Create (auto-set source='manual', confirmed=true, priority=0, confidence=1.0)
- `GET /dataset-repo-mappings` — List with query params: `source`, `confirmed`, `limit`, `offset`
- `PUT /dataset-repo-mappings/{id}` — Update (only provided fields)
- `DELETE /dataset-repo-mappings/{id}` — Delete (404 if not found)

**Router registration** in `routes/__init__.py`:
```python
api_router.include_router(repo_mappings_router)
```
