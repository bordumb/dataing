# fn-14.3 Issue comments and watchers API

## Description

Add comments and watchers API endpoints for issues.

### Endpoints
- POST /api/issues/:id/comments - Add comment
- GET /api/issues/:id/comments - List comments
- POST /api/issues/:id/watch - Add watcher
- DELETE /api/issues/:id/watch - Remove watcher

### Permission Rules
- Comments require dataset permission (no leaking content)
- Watchers can only be added if user has dataset permission
- Watcher notifications must respect dataset access (redacted or blocked)

### Reference
- `dataing/src/dataing/entrypoints/api/routes/schema_comments.py:1-137` - Comments pattern
- `dataing/src/dataing/adapters/comments/types.py` - Comment types
