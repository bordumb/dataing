# fn-34.3 Add node click handlers for dataset details panel

## Description

Wire up interactive node click handlers on the cytoscape graph widget so that clicking a dataset or job node displays a details panel below the graph. The panel should show dataset metadata (schema, platform, owners, tags), recent investigations (if any), and for job nodes show inputs/outputs and source code links. This transforms the graph from a static visualization into an interactive exploration tool.

Depends on: fn-34.2 (cytoscape widget with elements and layout).

### Implementation

1. **Create a details panel widget** using `ipywidgets.Output` or `ipywidgets.HTML`:

```python
import ipywidgets as widgets

def _create_details_panel() -> widgets.HTML:
    """Create an HTML widget to display node details.

    Returns:
        ipywidgets.HTML widget for rendering details.
    """
    panel = widgets.HTML(value="<p style='color: #6b7280;'>Click a node to see details</p>")
    panel.layout = widgets.Layout(
        border="1px solid #e5e7eb",
        padding="12px",
        margin="8px 0",
        min_height="80px",
    )
    return panel
```

2. **Register a click callback** on the CytoscapeWidget:

```python
def _on_node_click(node_data: dict, details_panel: widgets.HTML, lineage_data: dict):
    """Handle node click event and update details panel.

    Args:
        node_data: Cytoscape node data dict from click event.
        details_panel: HTML widget to update.
        lineage_data: Full lineage data for lookups.
    """
    node_id = node_data.get("data", {}).get("id", "")
    node_type = node_data.get("data", {}).get("node_type", "dataset")

    if node_type == "job":
        job = lineage_data.get("jobs", {}).get(node_id, {})
        html = _render_job_details(node_id, job)
    else:
        dataset = lineage_data.get("datasets", {}).get(node_id, {})
        html = _render_dataset_details(node_id, dataset)

    details_panel.value = html
```

5. **Compose graph + panel into a VBox** in `render_lineage_graph()`:

```python
def render_lineage_graph(lineage_data, *, depth=2, direction="both"):
    if not is_widget_environment():
        _render_ascii_fallback(lineage_data, depth=depth, direction=direction)
        return None

    elements = lineage_to_cytoscape_elements(lineage_data, depth=depth, direction=direction)
    widget = _build_widget(elements)
    details_panel = _create_details_panel()

    # Register click handler
    def on_click(node):
        _on_node_click(node, details_panel, lineage_data)

    widget.on("node", "click", on_click)

    # Return vertical layout: graph on top, details panel below
    return widgets.VBox([widget, details_panel])
```
