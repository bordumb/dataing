# fn-43.2 Create CODE_OF_CONDUCT.md

## Description

Adopt a standard Code of Conduct to set behavioral expectations for all community participants. A clear Code of Conduct signals that the project is a safe, welcoming space and is a prerequisite for healthy open-source community growth. The Contributor Covenant v2.1 is the industry standard and is used by projects such as Kubernetes, Rails, and Swift.

### Implementation

1. Create `CODE_OF_CONDUCT.md` at the repository root based on the Contributor Covenant v2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
2. Customize the following fields:
   - **Contact method** -- set enforcement contact to a project-specific email (e.g. `conduct@dataing.io` or a placeholder to be updated before public launch).
   - **Scope** -- clarify that the CoC applies to all project spaces including GitHub issues/PRs, Discord, and any events.
   - **Enforcement guidelines** -- retain the four-tier enforcement ladder (Correction, Warning, Temporary Ban, Permanent Ban) from Contributor Covenant.
3. Add a brief "Attribution" section at the bottom linking back to Contributor Covenant v2.1.
4. Reference the Code of Conduct from `CONTRIBUTING.md` (if fn-43.1 is complete) with a link.

### Key Files
- **CREATE**: `CODE_OF_CONDUCT.md`
- **MODIFY**: `CONTRIBUTING.md` (add reference link, if it exists)
