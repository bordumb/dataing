# fn-16.4 Add branch execution unit tests

## Description

Add comprehensive unit tests verifying branch execution runs actual steps with correct behavior.

## Test Cases

1. **test_branch_executes_steps** - Verify `_run_branch` calls `step.execute()` with correct context
2. **test_branch_receives_input_data** - First step gets `BranchSpec.data` as `input_data`, subsequent steps get `None`
3. **test_branch_context_isolation** - Verify branches don't mutate parent context (deep copy)
4. **test_branch_terminates_on_complete** - COMPLETE signal stops branch, returns context
5. **test_branch_terminates_on_fail** - FAIL signal returns structured error `{"maistro": {"branch_error": {"reason": "SIGNAL_FAIL", ...}}}`
6. **test_branch_await_user_error** - AWAIT_USER returns structured error (reason="AWAIT_USER")
7. **test_branch_nested_branch_error** - BRANCH signal returns structured error (reason="NESTED_BRANCH")
8. **test_branch_step_not_found** - Missing step returns structured error (reason="STEP_NOT_FOUND")
9. **test_branch_max_iterations** - Exceeding limit returns structured error (reason="MAX_ITERATIONS")
10. **test_multiple_branches_sequential** - `_execute_branches` runs branches sequentially in alphabetical order
11. **test_branch_event_order** - Events emitted as: BranchStarted(A) → BranchCompleted(A) → BranchStarted(B) → ...
12. **test_branch_returns_delta_for_dict** - Dict context returns delta (changed keys only)
13. **test_branch_returns_full_context_wrapper** - Non-dict context returns `{"_full_context": ctx}`

## Location

Add to `maistro/tests/unit/test_branch_execution.py` (new file)
