# fn-14.12 Runbook model and knowledge base APIs (EE)

## Description

Create runbook model and knowledge base APIs (EE).

### Migration
- `runbooks` table (title, body, dataset_id, labels, created_from_issue_id)
- `runbook_links` table (runbook_id, issue_id, score)

### API
- GET /api/runbooks - List runbooks
- POST /api/runbooks - Create runbook
- GET /api/runbooks/:id - Get runbook
- PATCH /api/runbooks/:id - Update runbook
- POST /api/issues/:id/create-runbook - Generate from resolved issue
- GET /api/issues/:id/suggested-runbooks - Get similar runbooks

### Generation
- From resolved issue + investigation synthesis
- Extract: symptoms, root cause, verification steps, fix, prevention

### Similarity
- TF-IDF or embedding-based similarity
- Suggest runbooks for new issues with similar symptoms

## Summary

Implemented the runbook model and knowledge base APIs for EE, enabling teams to capture and reuse knowledge from resolved issues.

## Key Deliverables

1. **Database Migration (022_runbooks.sql)**
   - `runbooks` table with full-text search (tsvector)
   - `runbook_links` table for issue-runbook associations
   - Trigger for automatic search vector updates

2. **Models (runbook.py)**
   - `Runbook` - knowledge base articles with structured content
   - `RunbookLink` - associations between runbooks and issues with scores

3. **Core Services**
   - `RunbookGenerator` - extracts symptoms, root cause, verification steps, fix steps, and prevention notes from resolved issues
   - `SimilarityScorer` - TF-IDF based similarity matching for suggesting relevant runbooks

4. **API Routes**
   - CRUD endpoints for runbooks
   - `POST /runbooks/from-issue/{issue_id}` - generate runbook from resolved issue
   - `GET /runbooks/suggested/{issue_id}` - get similar runbooks for an issue
   - Link feedback endpoints for improving suggestions

5. **Tests**
   - 44 unit tests covering generator, similarity scorer, and API schemas
