# fn-14.10 Automation rules engine (EE)

## Description

Create automation rules engine for auto-triggering investigations (EE).

### Migration
- `automation_rules` table (name, conditions, actions, rate_limits)
- `rule_executions` table (audit trail)

### API
- GET /api/rules - List rules
- POST /api/rules - Create rule
- PATCH /api/rules/:id - Update rule
- POST /api/rules/:id/dry-run - Test rule against sample issue

### Rule DSL
```json
{
  "conditions": {
    "all": [
      {"field": "severity", "operator": "in", "value": ["high", "critical"]},
      {"field": "source_provider", "operator": "equals", "value": "montecarlo"}
    ]
  },
  "actions": [
    {"type": "spawn_investigation", "params": {"profile": "standard"}},
    {"type": "set_priority", "params": {"value": "P1"}}
  ]
}
```

### Implementation
- Rule evaluator with condition matching
- Action executor for each action type
- Rate limiting per rule
- Circuit breaker to prevent loops
