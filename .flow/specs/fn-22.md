# fn-22: JupyterLab E2E

## Goal
Prove the JupyterLab sidebar → attach → stream timeline loop works end-to-end.

**VP Product guidance**: Keep this laser-thin. No extra UX polish. Just prove the loop.

## Problem
The JupyterLab extension is scaffolded but not proven:
- `checkConnection()` at line 46 in `index.ts` is basic HTTP fetch
- No SSE streaming for timeline
- No attach/bind UX
- TypeScript build verification pending

## Solution
Build a working proof-of-concept that demonstrates exactly three things:
1. **Connection indicator** - Shows connected/disconnected/error state
2. **Attach** - Bind context to asset (resolves datasource)
3. **Stream timeline** - SSE events render in sidebar

That's it. No polish. Prove the loop.

## Technical Approach

### Architecture
- Use Lumino widgets (JupyterLab standard)
- SSE via native `EventSource` API (with server extension proxy for CORS)
- State management via JupyterLab signals

### Key Components
```typescript
// widget.ts
class DataingWidget extends Widget {
    private _status: 'disconnected' | 'connected' | 'streaming';
    private _eventSource: EventSource | null;
    private _timeline: EvidenceEvent[];

    updateFromState(appState: IDataingState): void;
    attach(datasourceId: string, name?: string): void;
    detach(): void;
    streamRun(runId: string, serverBaseUrl: string): void;
    stopStream(): void;
}
```

### SSE Proxy (Required for CORS)
Server extension proxies SSE to avoid cross-origin issues:
