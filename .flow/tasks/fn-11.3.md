# fn-11.3 Refactor API and Worker payloads

## Description
Refactor API routes and Worker payloads to use `to_json_string()` for handling complex types (UUID, datetime) in JSON payloads, specifically for SSE (Server-Sent Events) streams where manual JSON construction is common.

**Scope:**
- `dataing/src/dataing/entrypoints/api/routes/investigations.py`: SSE `data` fields.
- `dataing/src/dataing/entrypoints/api/routes/notifications.py`: SSE `data` fields.

**Constraints:**
- **DO NOT** replace `json.dumps` in logging statements or external adapters (e.g. Slack) where `indent` or other specific formatting arguments are used, unless strictly necessary.
- Ensure no double-serialization occurs (serializing a string that is already JSON).

## Acceptance
- [ ] SSE endpoints correctly serialize `datetime` and `UUID` objects without error.
- [ ] No regression in Slack notifications or logging output formats.
