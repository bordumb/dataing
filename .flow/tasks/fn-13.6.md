## Objective

Create comprehensive documentation and testing for the Helm chart.

## Deliverables

1. **Self-hosting guide** (docs/self-hosting/helm.md):
   - Prerequisites (Kubernetes version, Helm version)
   - Quick start guide
   - Configuration reference
   - Common deployment scenarios
   - Troubleshooting section

   - `examples/values-minimal.yaml` - Bare minimum for testing
   - `examples/values-production.yaml` - Production-ready settings

3. **Helm tests** (templates/tests/):

5. **README.md** in charts/dataing/:
   - Installation instructions
   - Values reference table
   - Upgrade notes

## Acceptance Criteria

- [ ] Documentation covers all major use cases
