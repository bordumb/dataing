# fn-26.4 Regenerate locks and sync environment

## Description

Regenerate lock files and sync the environment after updating pyproject.toml files.

## Steps

1. Run `uv lock` from root to regenerate lock file
2. Run `uv sync` to install bond-agent from PyPI
3. Verify bond-agent is installed: `uv run python -c "import bond; print(bond.__version__)"`

## Commands

```bash
uv lock
uv sync
uv run python -c "from bond import BondAgent; print('OK')"
```
