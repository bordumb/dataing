# Amazon S3 Integration

Query Parquet, CSV, and JSON files directly from S3 using SQL.

---

## Overview

S3 integration enables:

- **Direct file queries** - Query files in-place without ETL
- **Schema inference** - Automatically detect file schemas
- **SQL on files** - Use familiar SQL syntax via DuckDB
- **Format flexibility** - Support for Parquet, CSV, and JSON

---

## Prerequisites

- AWS account with S3 access
- IAM user or role with read permissions
- Files in supported formats (Parquet, CSV, JSON)

### Recommended IAM Policy

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "s3:GetObject",
                "s3:ListBucket"
            ],
            "Resource": [
                "arn:aws:s3:::your-bucket",
                "arn:aws:s3:::your-bucket/*"
            ]
        }
    ]
}
```

## Configuration

=== "Environment Variables"

    ```bash
    export DATAING_DATASOURCE=s3
    export DATAING_S3_BUCKET=my-data-bucket
    export DATAING_S3_PREFIX=data/warehouse/
    export DATAING_S3_REGION=us-east-1
    export DATAING_S3_ACCESS_KEY_ID=AKIA...
    export DATAING_S3_SECRET_ACCESS_KEY=...
    ```

=== "Python SDK"

    ```python
    from dataing.adapters.datasource.filesystem.s3 import S3Adapter

    adapter = S3Adapter({
        "bucket": "my-data-bucket",
        "prefix": "data/warehouse/",
        "region": "us-east-1",
        "access_key_id": "AKIA...",
        "secret_access_key": "...",
        "file_format": "auto",  # or "parquet", "csv", "json"
    })
    ```

### Configuration Fields

| Field | Required | Default | Description |
|-------|----------|---------|-------------|
| `bucket` | Yes | - | S3 bucket name |
| `prefix` | No | - | Path prefix to limit scope |
| `region` | Yes | us-east-1 | AWS region |
| `access_key_id` | Yes | - | AWS Access Key ID |
| `secret_access_key` | Yes | - | AWS Secret Access Key |
| `file_format` | No | auto | Default format for files |

## Querying Files

### Single File Query

```python
# Query a specific Parquet file
result = await adapter.execute_query("""
    SELECT *
    FROM read_parquet('s3://my-bucket/data/orders.parquet')
    LIMIT 100
""")
```

### Pattern-Based Query

```python
# Query all Parquet files in a directory
result = await adapter.execute_query("""
    SELECT *
    FROM read_parquet('s3://my-bucket/data/orders/*.parquet')
    WHERE order_date >= '2024-01-01'
""")
```

### Cross-Format Query

```python
# Join files of different formats
result = await adapter.execute_query("""
    SELECT o.*, c.name as customer_name
    FROM read_parquet('s3://my-bucket/orders.parquet') o
    JOIN read_csv_auto('s3://my-bucket/customers.csv') c
        ON o.customer_id = c.id
""")
```

## File Formats

### Parquet (Recommended)

```python
# Parquet with predicate pushdown
result = await adapter.execute_query("""
    SELECT order_id, amount
    FROM read_parquet('s3://bucket/orders.parquet')
    WHERE amount > 100  -- Pushed to file scan
""")
```

### CSV

```python
# CSV with auto-detection
result = await adapter.execute_query("""
    SELECT *
    FROM read_csv_auto('s3://bucket/data.csv')
    LIMIT 100
""")

# CSV with explicit options
result = await adapter.execute_query("""
    SELECT *
    FROM read_csv('s3://bucket/data.csv',
        header=true,
        delimiter=',',
        quote='"'
    )
""")
```

### JSON/JSONL

```python
# Line-delimited JSON
result = await adapter.execute_query("""
    SELECT *
    FROM read_json_auto('s3://bucket/events.jsonl')
    LIMIT 100
""")
```

## Schema Discovery

dataing discovers schema by reading file metadata:

```python
# List files in bucket
files = await adapter.list_files(pattern="*.parquet")

# Infer schema for a file
table = await adapter.infer_schema("s3://bucket/orders.parquet")
# Returns columns, types, and file metadata

# Get full schema (all files as tables)
schema = await adapter.get_schema()
```

## Investigation Use Cases

### Data Quality Checks

```python
# Check for null spikes
result = await adapter.execute_query("""
    SELECT
        date_trunc('day', created_at) as day,
        COUNT(*) as total,
        SUM(CASE WHEN user_id IS NULL THEN 1 ELSE 0 END) as null_count,
        null_count * 100.0 / total as null_pct
    FROM read_parquet('s3://bucket/events/*.parquet')
    GROUP BY 1
    ORDER BY 1
""")
```

### Schema Drift Detection

```python
# Compare schemas across partitions
files = await adapter.list_files(pattern="orders/*.parquet")

schemas = []
for file in files:
    table = await adapter.infer_schema(file.path)
    schemas.append({
        "file": file.name,
        "columns": [c.name for c in table.columns]
    })

# Detect missing columns
```

### Duplicate Detection

```python
result = await adapter.execute_query("""
    SELECT order_id, COUNT(*) as cnt
    FROM read_parquet('s3://bucket/orders.parquet')
    GROUP BY order_id
    HAVING cnt > 1
""")
```

## Troubleshooting

### "Access Denied"

Verify IAM permissions:

```bash
# Test with AWS CLI
aws s3 ls s3://your-bucket/
aws s3 cp s3://your-bucket/test.parquet - | head
```

### "Bucket not found"

Check bucket name and region:

```bash
aws s3api head-bucket --bucket your-bucket --region us-east-1
```

### "Invalid credentials"

Verify credentials are correct:

```bash
aws sts get-caller-identity
```

### "File format error"

Ensure file format matches:

```python
# Explicit format selection
result = await adapter.read_file(
    "s3://bucket/data.parquet",
    file_format="parquet",  # Don't auto-detect
)
```
