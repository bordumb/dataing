# Task fn-13.5: Networking & Ingress

**Epic:** fn-13 Helm Charts for Self-Hosted Deployment
**Status:** blocked-by fn-13.2
**Estimate:** Small

## Objective

Create networking templates for external access and cluster security.

## Deliverables

1. **ingress.yaml**:
   - Conditional on `ingress.enabled`
   - Support for multiple ingress classes (nginx, traefik, etc.)
   - TLS configuration with cert-manager annotations
   - Path-based routing

2. **networkpolicy.yaml** (optional):
   - Restrict traffic between pods
   - Allow only necessary connections
   - Conditional on `networkPolicy.enabled`

3. **poddisruptionbudget.yaml**:
   - For API deployment (maintain availability during upgrades)
   - Conditional on replicas > 1

4. **values.yaml structure**:
   ```yaml
   ingress:
     enabled: false
     className: nginx
     annotations: {}
     hosts:
       - host: dataing.example.com
         paths:
           - path: /
             pathType: Prefix
     tls: []

   networkPolicy:
     enabled: false

   podDisruptionBudget:
     enabled: true
     minAvailable: 1
   ```

## Acceptance Criteria

- [ ] Ingress routes traffic to API service
- [ ] TLS termination works with cert-manager
- [ ] PDB prevents all pods being evicted simultaneously
- [ ] NetworkPolicy (when enabled) doesn't break connectivity
