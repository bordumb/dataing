# fn-35.2 Add replay magic handler to load investigation with evidence

## Description

Add a `%dataing replay <id>` subcommand that fetches a completed investigation by ID from the API and renders its full state (evidence, synthesis, hypotheses) in the notebook. This enables users to review any past investigation without re-running it, loading cached results from the persistence layer.

Depends on fn-35.1 because the history command is the primary way users discover investigation IDs to replay.

### Implementation

1. **Register the handler in magic.py** -- add `"replay": self._handle_replay` to the `handlers` dict.

2. **Implement `_handle_replay`** in `DataingMagics`:
   ```python
   def _handle_replay(self, args: list[str]) -> None:
       """Handle replay subcommand -- load a past investigation."""
       parser = argparse.ArgumentParser(prog="%dataing replay")
       parser.add_argument("investigation_id", help="Investigation UUID to replay")
       parser.add_argument("--format", "-f", choices=["rich", "plain"],
                           default="rich", help="Output format")
       # parse ...

       if self._state.client is None:
           print("Error: Not connected. Use '%dataing connect' first.",
                 file=sys.stderr)
           return

       # Fetch full investigation state from API
       # Uses GET /api/v1/investigations/{id} which returns
       # InvestigationStateResponse with main_branch containing
       # evidence list and synthesis dict.
       investigation = self._state.client.get_investigation(parsed.investigation_id)

       # Render investigation details
       self._render_replay(investigation, parsed.format)
   ```

3. **Implement `_render_replay`** -- display the investigation in a structured format:
   - Header: investigation ID, status, dataset
   - Synthesis / root cause summary (if completed)
   - Evidence items rendered using existing `render_evidence()` from `rendering.py`
   - Step history timeline

4. **Store replayed investigation in session state** so `%dataing export` can export it without a re-fetch:
   ```python
   self._state._history.append({
       "action": "replay",
       "investigation_id": parsed.investigation_id,
       "investigation": investigation,
   })
   ```

5. **Add `replay` to the help text** in `_show_help`.

6. **Error handling** -- wrap the API call in try/except and print a clear message for 404 (investigation not found) or network errors.
