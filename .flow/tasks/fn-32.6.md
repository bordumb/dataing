# fn-32.6 Suggestions workflow: list, confirm, dismiss

## Description

Add endpoints for managing auto-discovered (unconfirmed) mappings. Users can review suggestions and confirm or dismiss them.

### Implementation

Add to the repo_mappings router (`routes/repo_mappings.py`):

1. **`GET /dataset-repo-mappings/suggestions`** — List unconfirmed mappings
   - Calls `db.list_repo_mapping_suggestions(tenant_id, limit, offset)`
   - Returns `RepoMappingListResponse`

2. **`POST /dataset-repo-mappings/{id}/confirm`** — Promote suggestion to confirmed
   - Calls `db.confirm_repo_mapping(mapping_id, tenant_id)`
   - Sets `confirmed=true`, `priority=0`
   - Returns updated `RepoMappingResponse`
   - 404 if mapping not found
   - 400 if mapping already confirmed

3. **`POST /dataset-repo-mappings/{id}/dismiss`** — Delete rejected suggestion
   - Calls `db.dismiss_repo_mapping(mapping_id, tenant_id)`
   - Only deletes if `confirmed=false`
   - 404 if not found or already confirmed
   - Returns 204 No Content

### Route ordering note
The `/suggestions` GET must be registered BEFORE `/{id}` routes to avoid FastAPI treating "suggestions" as a UUID path parameter.
