# fn-41.5 Add environment variable documentation and .env.example

## Description

Create a comprehensive `.env.example` file and document all environment variables needed by the Docker Compose stack. Users must understand which variables are required (e.g., `ANTHROPIC_API_KEY`), which have sensible defaults, and which are security-sensitive. This is critical for first-run experience since investigations cannot run without an LLM API key.

**Depends on**: fn-41.3 (docker-compose.yml)

### Implementation

1. Create `.env.example` at the repository root with all environment variables, organized by category:
   ```env
   # =============================================================================
   # Dataing Self-Host Configuration
   # Copy this file to .env and fill in required values
   # =============================================================================

   # --- Required ---
   ANTHROPIC_API_KEY=          # Your Anthropic API key (sk-ant-...)

   # --- Database ---
   POSTGRES_USER=dataing
   POSTGRES_PASSWORD=dataing       # CHANGE in production
   POSTGRES_DB=dataing
   DATABASE_URL=postgresql://dataing:dataing@postgres:5432/dataing
   APP_DATABASE_URL=postgresql://dataing:dataing@postgres:5432/dataing

   # --- Encryption ---
   DATADR_ENCRYPTION_KEY=         # Fernet key: python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

   # --- Temporal ---
   TEMPORAL_HOST=temporal:7233
   TEMPORAL_NAMESPACE=default
   TEMPORAL_TASK_QUEUE=investigations

   # --- API ---
   API_PORT=8000
   LLM_MODEL=claude-sonnet-4-20250514

   # --- Frontend ---
   API_URL=http://api:8000

   # --- Temporal DB (separate from app DB) ---
   TEMPORAL_POSTGRES_USER=temporal
   TEMPORAL_POSTGRES_PASSWORD=temporal   # CHANGE in production
   ```
2. Add inline comments explaining each variable's purpose, whether it is required or optional, and default values.
3. Include a commented-out section for optional observability variables (OTEL endpoints, Jaeger config).
4. Add a first-run initialization section documenting:
   - How to generate the Fernet encryption key
   - How to create the first admin user and API key
   - How the database migrations run automatically on first startup
5. Update `docker-compose.yml` to reference `.env` file via `env_file: .env` on the api and worker services, so users only need to edit one file.
6. Add a startup validation script `infra/check-env.sh` that verifies required variables are set and prints warnings:
   ```bash
   #!/bin/bash
   if [ -z "$ANTHROPIC_API_KEY" ]; then
     echo "WARNING: ANTHROPIC_API_KEY is not set. Investigations will fail."
     echo "Get your key at https://console.anthropic.com"
   fi
   ```
