# fn-41.2 Create multi-stage Dockerfile for frontend (Vite build + nginx)

## Description

Create a production multi-stage Dockerfile at `infra/Dockerfile.frontend` for the frontend application. The frontend is a Vite + React + TypeScript app located at `frontend/app/`. The image should build static assets and serve them via nginx, with API requests proxied to the backend.

### Implementation

1. Create `infra/Dockerfile.frontend` with a multi-stage build:
   - **Stage 1 (`builder`)**: Use `node:20-alpine` as base, install `pnpm`, copy `frontend/app/package.json` and `frontend/app/pnpm-lock.yaml`, run `pnpm install --frozen-lockfile`, copy source, run `pnpm build` (which runs `tsc && vite build`), output goes to `frontend/app/dist/`.
   - **Stage 2 (`runtime`)**: Use `nginx:alpine`, copy the built `dist/` from builder to `/usr/share/nginx/html/`, copy a custom nginx config.
2. Create `infra/nginx.conf` with:
   - Serve static files from `/usr/share/nginx/html/`
   - SPA fallback: all non-file routes return `index.html`
   - Proxy `/api` requests to the backend service (configurable via env var `API_URL`, default `http://api:8000`)
   - Gzip compression for JS/CSS/HTML
   - Security headers (X-Frame-Options, X-Content-Type-Options, etc.)
   - Listen on port 3000 (matching existing demo compose)
3. Use `envsubst` at container startup to template the `API_URL` into nginx config, so the backend URL is configurable at runtime without rebuilding.
4. Add appropriate OCI labels.

### Key Files
- **CREATE**: `infra/Dockerfile.frontend`
- **CREATE**: `infra/nginx.conf`
- **REFERENCE**: `frontend/app/package.json` (build scripts)
- **REFERENCE**: `frontend/app/vite.config.ts` (build config, proxy settings)

### Verification
```bash
# Build the image
docker build -f infra/Dockerfile.frontend -t dataing-frontend:dev .

# Verify image size (target < 50MB)
docker images dataing-frontend:dev --format '{{.Size}}'

# Verify nginx starts and serves content
docker run --rm -d -p 3000:3000 --name frontend-test dataing-frontend:dev
sleep 2
curl -f http://localhost:3000/ | head -5
docker stop frontend-test

# Verify API proxy config is present
docker run --rm dataing-frontend:dev cat /etc/nginx/conf.d/default.conf | grep proxy_pass

# Verify multi-arch build
docker buildx build --platform linux/amd64,linux/arm64 -f infra/Dockerfile.frontend .
```
