# fn-15.6 Create engine.py with Pure Reducer Engine Class

## Description

Create `maestro/src/maestro/engine.py` with the deterministic Engine class.

**Key principle:** Engine is a pure function: `(state, event) -> (new_state, command)`.

**Critical rules:**
1. Engine.apply() takes **Events only** - never raw exceptions or StepResults
2. Engine **never** performs I/O, logging, or side effects
3. Engine computes `resume_step` for AWAIT_USER (Steps don't decide routing)
4. All state changes use `dataclasses.replace()` for immutability

**Class to implement:**

```python
class Engine(Generic[ContextT]):
    def __init__(self, step_order: list[str], merge_strategy: MergeStrategy):
        self._step_order = step_order
        self._merge = merge_strategy

    def init(self, run_id: str, context: ContextT, start_step: str) -> tuple[RunState[ContextT], Command, Event]:
        """Initialize a new run. Returns (initial_state, first_command, RunStarted event)."""
        ...

    def apply(self, state: RunState[ContextT], event: Event) -> tuple[RunState[ContextT], Command]:
        """Pure reducer. Apply event to state, return new state and next command."""
        ...
```

**Event handling in `apply()`:**

| Event | State Change | Command |
|-------|-------------|---------|
| `RunStarted` | Set current_step | `ExecuteStep(start_step)` |
| `StepStarted` | (no state change, informational) | Continue with current command |
| `StepCompleted` | Apply context_update, check signal | Depends on signal |
| `StepFailed` | Set status="failed" | `Stop(status="failed")` |
| `BranchStarted` | (no state change, informational) | Continue |
| `BranchCompleted` | Add to completed, check if all done | `ExecuteStep(merge_step)` when complete |
| `InputRequested` | Set pending_await with computed resume_step | `WaitForInput(token)` |
| `InputReceived` | Clear pending_await | `ExecuteStep(resume_step)` |
| `RunPaused` | Set status="paused" | `WaitForInput(...)` |
| `RunResumed` | Set status="running" | `ExecuteStep(resume_step)` |
| `RunCompleted` | Set status="completed" | `Stop(status="completed")` |
| `RunFailed` | Set status="failed" | `Stop(status="failed")` |

**Context update application:**

```python
# Engine applies delta to state context:
new_context = {**state.context, **event.context_update}
state = replace(state, context=new_context)
```

**AWAIT_USER routing (Engine decides, not Steps):**

```python
# When handling InputRequested:
resume_step = self._default_next(state.current_step)
await_state = AwaitState(token=event.token, resume_step=resume_step)
state = replace(state, pending_await=await_state, status="paused")
```
