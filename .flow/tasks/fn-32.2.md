# fn-32.2 AppDatabase repository methods for repo mappings

## Description

Add methods to `AppDatabase` for CRUD operations on `dataset_repo_mappings`. Follow the existing pattern of parameterized SQL queries with `$1, $2` placeholders.

### Implementation

Add these methods to `python-packages/dataing/src/dataing/adapters/db/app_db.py`:

1. **`create_repo_mapping(tenant_id, mapping_data) -> dict`** — INSERT with RETURNING
2. **`get_repo_mapping(mapping_id, tenant_id) -> dict | None`** — SELECT by id + tenant
3. **`list_repo_mappings(tenant_id, source=None, confirmed=None, limit=50, offset=0) -> list[dict]`** — Filtered list with pagination
4. **`update_repo_mapping(mapping_id, tenant_id, updates) -> dict | None`** — UPDATE with RETURNING, set updated_at=NOW()
5. **`delete_repo_mapping(mapping_id, tenant_id) -> bool`** — DELETE, return True if row deleted
6. **`bulk_create_repo_mappings(tenant_id, mappings) -> list[dict]`** — Multi-row INSERT
7. **`upsert_repo_mapping(tenant_id, dataset_pattern, repo_owner, repo_name, defaults) -> dict`** — INSERT ON CONFLICT (tenant_id, dataset_pattern, repo_owner, repo_name) WHERE confirmed DO UPDATE
8. **`resolve_repo_for_dataset(tenant_id, dataset_id) -> list[dict]`** — Query exact matches + all glob patterns for tenant, return ordered by (priority ASC, confidence DESC, created_at DESC)
9. **`list_repo_mapping_suggestions(tenant_id, limit=50, offset=0) -> list[dict]`** — WHERE confirmed=false
10. **`confirm_repo_mapping(mapping_id, tenant_id) -> dict | None`** — SET confirmed=true, priority=0
11. **`dismiss_repo_mapping(mapping_id, tenant_id) -> bool`** — DELETE WHERE confirmed=false

All queries use parameterized `$1, $2` style. Use `to_json_string()` for metadata JSONB serialization.
