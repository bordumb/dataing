# fn-39.1 Define snapshot archive structure and metadata.json schema

## Description

Define the canonical snapshot archive directory layout and the `metadata.json` schema that sits at its root. This is the foundational contract that every other fn-39 task depends on -- the archive builder, importer, API, and CLI all need an agreed-upon structure before implementation can start.

The schema must include a version field for forward compatibility, references to the originating investigation, and an inventory of every file in the archive so importers can validate completeness.

### Implementation

1. Create a new module `python-packages/dataing/src/dataing/core/snapshot_schema.py` containing:
   - A `SNAPSHOT_SCHEMA_VERSION` constant (start at `"1.0"`).
   - A Pydantic `SnapshotMetadata` model with fields:
     ```python
     class SnapshotMetadata(BaseModel):
         schema_version: str = SNAPSHOT_SCHEMA_VERSION
         investigation_id: str
         created_at: datetime
         source_instance: str | None = None  # originating server URL
         tenant_id: str | None = None  # stripped on cross-tenant import (EE)
         status: str  # investigation status at export time
         evidence_count: int
         root_hash: str | None = None  # from evidence hash chain (fn-33)
         chain_metadata: dict[str, str] | None = None
         max_size_bytes: int = 100 * 1024 * 1024  # 100MB default
         files: list[str]  # relative paths of every file in the archive
     ```
   - An `ArchivePaths` helper with constants for well-known paths:
     ```python
     class ArchivePaths:
         METADATA = "metadata.json"
         EVIDENCE_DIR = "evidence/"
         LINEAGE = "lineage.json"
         CODE_CHANGES = "code_changes.json"
         PROMPTS_DIR = "prompts/"
     ```
   - A `validate_metadata(data: dict) -> SnapshotMetadata` function that parses and validates incoming JSON against the model.

2. Add a JSON Schema export so external tools can validate snapshots:
   ```python
   def json_schema() -> dict[str, Any]:
       return SnapshotMetadata.model_json_schema()
   ```

3. Document the archive layout as a module docstring matching the epic spec:
   ```
   snapshot-<id>/
     metadata.json
     evidence/
       001-hypothesis.json
       002-query.json
       003-results.parquet
       ...
     lineage.json
     code_changes.json
     prompts/
       hypothesis.txt
       query.txt
       synthesis.txt
   ```
