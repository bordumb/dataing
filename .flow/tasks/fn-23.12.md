# fn-23.12 Keyboard Shortcuts

## Description
## Task: Keyboard Shortcuts

Add keyboard shortcuts for common sidebar actions.

### Goal
Power users can quickly access Dataing sidebar functions without mouse.

### Implementation

1. **Shortcuts to add**:
   - `Ctrl+Shift+D` - Toggle Dataing sidebar visibility
   - `Ctrl+Shift+A` - Focus asset picker (when sidebar open)
   - `Ctrl+Shift+C` - Open connection wizard (when sidebar open)
   - `Escape` - Close modals/dialogs

2. **Registration via JupyterLab**:
   - Add commands to `ICommandPalette`
   - Register shortcuts in settings schema (`jupyter.lab.shortcuts`)
   - Commands should check prerequisites (e.g., "attach" requires connection)

3. **Discoverability**:
   - Show shortcuts in command palette
   - Tooltip hints in UI elements

### Files to Modify
- `frontend/jupyterlab-dataing/schema/plugin.json` - Add shortcuts to schema
- `frontend/jupyterlab-dataing/src/index.ts` - Register commands
- `frontend/jupyterlab-dataing/src/widget.ts` - Command handlers

### UX Considerations
- Don't conflict with existing JupyterLab shortcuts
- Shortcuts should be memorable (D for Dataing, A for Attach, C for Connect)
- Allow user customization via settings
