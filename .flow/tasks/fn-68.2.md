# fn-68.2 Point frontend pre-commit hooks at frontend/app

## Description
The tsc, eslint and prettier hooks in .pre-commit-config.yaml matched `^frontend/src/` and ran `cd frontend`. The app lives in `frontend/app`, so they never ran.

Point them at `frontend/app`, and make prettier receive the staged paths.
## Acceptance
- tsc/eslint/prettier hooks match `^frontend/app/src/` and run inside frontend/app
- prettier receives the staged file paths (relative to frontend/app)
- Verified with `pre-commit run <hook> --files <frontend/app file>`


## Done summary
- tsc/eslint/prettier hooks now match ^frontend/app/src/ and run inside frontend/app (they matched ^frontend/src/ and never ran).
- tsc runs `pnpm typecheck` (same script as Frontend CI).
- prettier hook fixed: staged paths now reach prettier via "$@" with the frontend/app/ prefix stripped (previously swallowed as bash $0..).
- Verified with prek 0.3.1 and pre-commit 4.5.1: pass on clean file; fail on injected TS2322, unused var, and 2 unformatted files.
- Note: 2 of 822 frontend files are not prettier-formatted yet (InvestigationDetail.tsx, codify-widget.tsx); the hook will format them on next touch.
