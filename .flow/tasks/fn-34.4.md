# fn-34.4 Add depth and direction parameters to lineage magic command

## Description

Extend the `%dataing lineage` magic command in `magic.py` to accept `--depth` and `--direction` parameters, and wire it to the new interactive graph renderer instead of the current Rich tree output. The existing `_handle_lineage` method (lines 406-458 of `magic.py`) currently renders a Rich tree; this task replaces that with a call to `render_lineage_graph()` while passing through the new CLI parameters.

Depends on: fn-34.2 (the `render_lineage_graph()` function must be functional).

### Implementation

1. **Add argparse arguments** to `_handle_lineage()` in `magic.py`:

```python
def _handle_lineage(self, args: list[str]) -> None:
    """Handle lineage subcommand with interactive graph visualization.

    Args:
        args: Command arguments.
    """
    parser = argparse.ArgumentParser(prog="%dataing lineage")
    parser.add_argument(
        "--depth", "-d",
        type=int,
        default=2,
        help="Max traversal depth from root (default: 2)",
    )
    parser.add_argument(
        "--direction",
        choices=["upstream", "downstream", "both"],
        default="both",
        help="Traversal direction (default: both)",
    )

    try:
        parsed = parser.parse_args(args)
    except SystemExit:
        return

    if not self._state.is_attached:
        print("Error: No context attached. Use '%dataing attach' first.", file=sys.stderr)
        return

    ctx = self._state.context
    if ctx is None:
        return

    lineage = ctx.lineage
    if lineage is None or not lineage:
        print("No lineage information available for this context.")
        print("(Lineage requires a configured lineage provider like dbt or Airflow)")
        return

    # Render using interactive graph
    from .lineage_graph import render_lineage_graph

    widget = render_lineage_graph(
        lineage,
        depth=parsed.depth,
        direction=parsed.direction,
    )

    if widget is not None:
        # Display widget in notebook
        from IPython.display import display
        display(widget)
    # else: ASCII fallback was already printed by render_lineage_graph
```
