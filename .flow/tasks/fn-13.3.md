# Task fn-13.3: Database & Redis

**Epic:** fn-13 Helm Charts for Self-Hosted Deployment
**Status:** blocked-by fn-13.1
**Estimate:** Medium

## Objective

Configure PostgreSQL and Redis as subchart dependencies with options for external services.

## Deliverables

1. **PostgreSQL subchart configuration**:
   - Add bitnami/postgresql as dependency
   - Configure in values.yaml
   - Support `postgresql.enabled: false` for external DB
   - External connection string option

2. **Redis subchart configuration**:
   - Add bitnami/redis as dependency
   - Configure in values.yaml
   - Support `redis.enabled: false` for external Redis
   - External connection options

3. **Migration job** (templates/job-migrations.yaml):
   - Kubernetes Job to run DB migrations
   - Runs as pre-install and pre-upgrade hook
   - Waits for PostgreSQL to be ready

4. **values.yaml updates**:
   ```yaml
   postgresql:
     enabled: true
     auth:
       database: dataing
       username: dataing
       existingSecret: ""
     # External DB settings (when enabled: false)
     external:
       host: ""
       port: 5432
       database: dataing
       existingSecret: ""

   redis:
     enabled: true
     auth:
       enabled: false
     # External Redis (when enabled: false)
     external:
       host: ""
       port: 6379
   ```

## Acceptance Criteria

- [ ] PostgreSQL subchart installs and connects
- [ ] Redis subchart installs and connects
- [ ] External database option works
- [ ] Migration job runs successfully
- [ ] Secrets are properly referenced
