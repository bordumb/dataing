# fn-10.9 Create Kubernetes worker Deployment

## Description

Create Kubernetes Deployment manifest for the Arq worker.

### Files to Create

**k8s/worker.yaml**:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: dataing-worker
  labels:
    app: dataing-worker
spec:
  replicas: 3
  selector:
    matchLabels:
      app: dataing-worker
  template:
    metadata:
      labels:
        app: dataing-worker
    spec:
      terminationGracePeriodSeconds: 60  # job_completion_wait + buffer
      containers:
      - name: worker
        image: dataing/worker:latest
        command: ["python", "-m", "dataing.entrypoints.worker"]
        resources:
          requests:
            memory: "2Gi"
            cpu: "1000m"
          limits:
            memory: "4Gi"
            cpu: "2000m"
        envFrom:
        - secretRef:
            name: dataing-secrets
        env:
        - name: REDIS_HOST
          value: redis-master
        - name: DATABASE_URL
          valueFrom:
            secretKeyRef:
              name: dataing-secrets
              key: DATABASE_URL
        lifecycle:
          preStop:
            exec:
              command: ["sleep", "5"]
        livenessProbe:
          exec:
            command: ["python", "-c", "import redis; redis.Redis().ping()"]
          initialDelaySeconds: 10
          periodSeconds: 30
        readinessProbe:
          exec:
            command: ["python", "-c", "import redis; redis.Redis().ping()"]
          initialDelaySeconds: 5
          periodSeconds: 10
```

### Notes

- `terminationGracePeriodSeconds: 60` = `job_completion_wait(30)` + buffer
- `preStop` sleep allows load balancer to drain connections
- Liveness/readiness probes check Redis connectivity
- Use `envFrom` for bulk secrets
