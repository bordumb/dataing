# fn-47.2 Create SQLAlchemy model and schedule repository

## Description

Create the SQLAlchemy ORM model for `scheduled_investigations` and a repository class that encapsulates all database operations (CRUD, pause/resume, next-run queries). This layer sits between the API/workflow code and the raw database, providing a clean domain interface.

Depends on: fn-47.1 (migration must exist first).

### Implementation

1. Create `python-packages/dataing/src/dataing/models/scheduled_investigation.py`:

```python
"""Scheduled investigation persistence model."""

from datetime import datetime
from typing import TYPE_CHECKING, Any
from uuid import UUID

from sqlalchemy import Boolean, ForeignKey, Integer, String, Text
from sqlalchemy.dialects.postgresql import JSONB
from sqlalchemy.orm import Mapped, mapped_column, relationship

from dataing.models.base import BaseModel

if TYPE_CHECKING:
    from dataing.models.tenant import Tenant
    from dataing.models.user import User


class ScheduledInvestigation(BaseModel):
    """Persisted scheduled investigation configuration."""

    __tablename__ = "scheduled_investigations"

    tenant_id: Mapped[UUID] = mapped_column(
        ForeignKey("tenants.id"), nullable=False
    )
    workspace_id: Mapped[UUID | None] = mapped_column(nullable=True)
    asset_id: Mapped[UUID] = mapped_column(nullable=False)
    goal: Mapped[str] = mapped_column(Text, nullable=False)
    cron_expression: Mapped[str] = mapped_column(String(100), nullable=False)
    timezone: Mapped[str] = mapped_column(String(50), default="UTC")
    is_active: Mapped[bool] = mapped_column(Boolean, default=True)
    notify_always: Mapped[bool] = mapped_column(Boolean, default=False)
    notification_channels: Mapped[list[dict[str, Any]]] = mapped_column(
        JSONB, default=list
    )
    max_concurrent: Mapped[int] = mapped_column(Integer, default=1)
    last_run_at: Mapped[datetime | None] = mapped_column(nullable=True)
    next_run_at: Mapped[datetime | None] = mapped_column(nullable=True)
    last_run_status: Mapped[str | None] = mapped_column(
        String(50), nullable=True
    )
    created_by: Mapped[UUID | None] = mapped_column(
        ForeignKey("users.id"), nullable=True
    )

    # Relationships
    tenant: Mapped["Tenant"] = relationship("Tenant")
    created_by_user: Mapped["User | None"] = relationship("User")
```

2. Create `python-packages/dataing/src/dataing/core/schedule/repository.py` with a `ScheduleRepository` class:
   - `create(tenant_id, asset_id, goal, cron_expression, ...) -> ScheduledInvestigation`
   - `get(schedule_id, tenant_id) -> ScheduledInvestigation | None`
   - `list_by_tenant(tenant_id, active_only=False) -> list[ScheduledInvestigation]`
   - `update(schedule_id, tenant_id, **fields) -> ScheduledInvestigation`
   - `delete(schedule_id, tenant_id) -> bool`
   - `pause(schedule_id, tenant_id) -> ScheduledInvestigation`
   - `resume(schedule_id, tenant_id) -> ScheduledInvestigation`
   - `get_due_schedules(now: datetime) -> list[ScheduledInvestigation]` -- queries by `next_run_at <= now AND is_active = TRUE`
   - `update_last_run(schedule_id, status, next_run_at) -> None`

3. Create `python-packages/dataing/src/dataing/core/schedule/cron_utils.py` with a `compute_next_run(cron_expression, timezone, after) -> datetime` utility that uses `croniter` to compute the next run time.

4. Register the model in `python-packages/dataing/src/dataing/models/__init__.py`.
