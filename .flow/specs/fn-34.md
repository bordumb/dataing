# Notebook Lineage Visualization

**Plan ref:** Task 0.2.2
**Phase:** 0 (Foundation)
**Designation:** OSS

## Overview

Add interactive lineage graph visualization to the notebook extension using ipycytoscape. When a user runs `%dataing lineage`, render an interactive DAG showing upstream/downstream dependencies with pan/zoom, node click handlers for dataset details, and export capabilities.

## Scope

- Replace current Rich tree lineage display with interactive ipycytoscape graph
- Add `--depth` and `--direction` parameters to lineage command
- Node click handlers showing dataset details (schema, metrics, recent investigations)
- Export to PNG/SVG for sharing
- ASCII fallback for non-widget environments (VS Code, plain terminal)

## Approach

1. Add `ipycytoscape` as optional dependency to dataing-notebook
2. Build graph renderer that converts lineage API response to cytoscape elements
3. Use dagre layout algorithm for hierarchical display
4. Color coding: tables=blue, views=green, current=highlighted, jobs=diamond
5. Implement fallback detection for non-widget environments
