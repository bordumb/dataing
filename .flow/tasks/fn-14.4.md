# fn-14.4 Investigation spawn from Issue API

## Description

Add API to spawn investigations from issues.

### Endpoints
- POST /api/issues/:id/investigation-runs - Spawn investigation
- GET /api/issues/:id/investigation-runs - List runs for issue

### Request Body
- dataset_id (optional, prefilled from issue)
- focus_prompt (required)
- execution_profile (safe/standard/deep)
- time_window (optional)

### Permission Requirements
- User MUST have dataset permission to spawn investigation
- Deep profile may require approval (approval_status = queued)

### Investigation Completion Handling
When investigation completes:
1. Auto-post synthesis summary as comment on issue
2. Populate structured fields on run record: confidence, root_cause_tag, synthesis_summary
3. Do NOT auto-resolve issue (human decision)
