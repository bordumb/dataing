# fn-19: Persistence Layer

## Goal
Replace in-memory stores with PostgreSQL so bundles, runs, and events survive restarts and can be retrieved later.

## Problem
Currently `runs.py` uses module-level dicts (`_run_events`, `_run_metadata`) at lines 164-165. This means:
- Runs disappear on server restart
- Events can't be replayed after `REPLAY_WINDOW_SECONDS`
- No way to re-open past investigations

## Solution
Add PostgreSQL tables for persistence:
1. `sdk_bundles` table - Store bundle snapshots with hash for deduplication
2. `sdk_runs` table - Store run metadata, status, timestamps, errors
3. `sdk_run_events` table - Store SSE events with seq ordering and event names

Use existing `app_db` adapter pattern from `dataing/adapters/db/app_db.py`.

## Schema Design

### Bundles Table
```sql
CREATE TABLE sdk_bundles (
    id UUID PRIMARY KEY,
    tenant_id UUID NOT NULL,
    bundle_hash VARCHAR(64) NOT NULL,
    assets JSONB NOT NULL,
    window VARCHAR(50),
    expires_at TIMESTAMPTZ,  -- Retention: when to auto-delete
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE(tenant_id, bundle_hash)
);
```

### Runs Table
```sql
CREATE TABLE sdk_runs (
    id UUID PRIMARY KEY,
    tenant_id UUID NOT NULL,
    bundle_id UUID REFERENCES sdk_bundles(id),
    bundle_hash VARCHAR(64),  -- Denormalized for queries without join
    goal TEXT NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'running',
    error_code VARCHAR(50),      -- Structured error code (e.g., 'timeout', 'rate_limit')
    error_message TEXT,          -- Human-readable error description
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    completed_at TIMESTAMPTZ,
    expires_at TIMESTAMPTZ       -- Retention: when to auto-delete
);
CREATE INDEX idx_sdk_runs_tenant_status ON sdk_runs(tenant_id, status);
CREATE INDEX idx_sdk_runs_bundle_hash ON sdk_runs(bundle_hash);
```

### Run Events Table
```sql
CREATE TABLE sdk_run_events (
    id BIGSERIAL PRIMARY KEY,
    run_id UUID NOT NULL REFERENCES sdk_runs(id),
    seq INTEGER NOT NULL,
    event_type VARCHAR(50) NOT NULL,   -- Internal type (run_started, run_evidence, etc.)
    event_name VARCHAR(100),           -- External/display name for stable client rendering
    data JSONB NOT NULL,
    timestamp TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE(run_id, seq)
);
CREATE INDEX idx_sdk_run_events_run_seq ON sdk_run_events(run_id, seq);
```

## Product-Critical Fields (VP Feedback)

| Field | Table | Purpose |
|-------|-------|---------|
| `bundle_hash` | runs | Query runs by bundle without join |
| `error_code` | runs | Structured error categorization |
| `error_message` | runs | Human-readable error for display |
| `event_name` | run_events | Stable client rendering (vs internal event_type) |
| `expires_at` | bundles, runs | Deterministic retention behavior |
