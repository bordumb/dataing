# fn-39.6 Add unit tests for snapshot export and import

## Description

Add comprehensive unit tests covering the snapshot archive builder, importer, schema validation, CLI commands, and API endpoints. Tests must cover both the happy path and edge cases: oversized archives, malformed metadata, missing Parquet support, path traversal attacks, and schema version mismatches.

**Depends on:** fn-39.5

### Implementation

1. Create `python-packages/dataing/tests/unit/core/test_snapshot_schema.py`:
   - Test `SnapshotMetadata` validation (valid, missing fields, unknown fields).
   - Test `SNAPSHOT_SCHEMA_VERSION` is `"1.0"`.
   - Test `ArchivePaths` constants.
   - Test JSON Schema export.

2. Create `python-packages/dataing/tests/unit/core/test_snapshot_builder.py`:
   - Test archive creation with minimal investigation (no evidence).
   - Test archive with multiple evidence types (hypothesis, query result).
   - Test Parquet output when `pyarrow` is available (mock if needed).
   - Test JSON fallback when `pyarrow` is not installed (mock `ImportError`).
   - Test `SnapshotSizeExceededError` when archive exceeds limit.
   - Test `metadata.json` file inventory matches actual archive contents.
   - Test archive structure matches the canonical layout.

3. Create `python-packages/dataing/tests/unit/core/test_snapshot_importer.py`:
   - Test valid archive import produces correct replay investigation.
   - Test `status = "replay"` on imported investigation.
   - Test `original_investigation_id` preserved.
   - Test rejection of invalid/corrupt archives.
   - Test `UnsupportedSchemaVersionError` for unknown schema versions.
   - Test path traversal rejection (tar entries with `..` or absolute paths).
   - Test `tenant_id` stripping.
   - Test file inventory mismatch detection.

4. Create `python-packages/dataing-cli/tests/test_snapshot_commands.py`:
   - Test `snapshot` command with mocked SDK client.
   - Test `import` command with mocked SDK client.
   - Test error display on snapshot failure.
   - Test `--max-size` option.

5. Create `python-packages/dataing/tests/unit/api/test_snapshot_endpoints.py`:
   - Test `GET /investigations/{id}/snapshot` returns gzip response.
   - Test `POST /investigations/import` with valid archive.
   - Test import rejects oversized files.
   - Test 404 for non-existent investigation on export.
   - Test tenant authorization on both endpoints.

6. Use test fixtures:
   ```python
   @pytest.fixture
   def sample_investigation_state() -> dict[str, Any]:
       """Minimal investigation state for snapshot tests."""

   @pytest.fixture
   def sample_evidence_items() -> list[dict[str, Any]]:
       """Evidence items spanning multiple kinds."""

   @pytest.fixture
   def sample_snapshot_archive(tmp_path) -> Path:
       """Pre-built snapshot archive for import tests."""
   ```
