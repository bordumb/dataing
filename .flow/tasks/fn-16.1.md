# fn-16.1 Implement context forking for branch execution

## Description

Each branch needs a deep copy of the parent context for isolation. `BranchSpec.data` is NOT merged into context - it's passed as `input_data` to the first branch step (handled in fn-16.2).

## Implementation

In `Runner._run_branch`:
1. Deep copy the parent context from `state.branch.parent_context`
2. Use `copy.deepcopy()` for all context types (dict, Pydantic, dataclass)
3. Return the forked context for branch execution

```python
def _deep_copy_context(self, context: ContextT) -> ContextT:
    import copy
    return copy.deepcopy(context)
```

**What this task does NOT do**:
- Does NOT merge `BranchSpec.data` into context
- `BranchSpec.data` is passed separately as `input_data` to the first branch step (fn-16.2)

## Acceptance

- [ ] Parent context is deep copied (not referenced)
- [ ] Original parent context is unchanged after branch execution
- [ ] Works with dict contexts
- [ ] Works with Pydantic model contexts (like `InvestigationContext`)
- [ ] Mutations in one branch don't leak to other branches
