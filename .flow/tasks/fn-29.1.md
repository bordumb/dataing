# fn-29.1 Add timeline display formatters

## Description

Add new timeline-specific display formatters to `display.py` that render investigation events with visual distinction and elapsed timestamps.

### File to Modify
`python-packages/dataing-cli/src/dataing_cli/display.py`

### Functions to Add

1. **`format_timestamp(start_time: float) -> str`**
   - Returns elapsed time as `[MM:SS]` string
   - Example: `[01:23]`

2. **`format_hypothesis(event: RunEvent, index: int, elapsed: str) -> Panel`**
   - Blue border panel
   - Title: `{elapsed} Hypothesis #{index}`
   - Body: hypothesis text from event data
   - Use `Panel.fit()` for compact display

3. **`format_query(event: RunEvent, elapsed: str) -> Panel`**
   - Yellow border panel
   - Title: `{elapsed} Executing Query`
   - Body: SQL with syntax highlighting using `Syntax(sql, "sql", theme="monokai")`
   - Reuse pattern from existing `format_event()` lines 50-60

4. **`format_evidence_item(event: RunEvent, elapsed: str) -> Panel`**
   - Green border if `supports_hypothesis=True`, Red if `False`
   - Title: `{elapsed} Evidence: Supports` or `Evidence: Refutes`
   - Body: interpretation text + confidence score
   - Show SQL snippet if present

5. **`format_synthesis(event: RunEvent, elapsed: str) -> Panel`**
   - Cyan border panel
   - Title: `{elapsed} Synthesis`
   - Body: root_cause, confidence (as percentage), recommendations list
   - Use Rich Table for structured display of recommendations

### Patterns to Reuse
- `display.py:20-79` - `format_event()` Panel construction pattern
- `display.py:82-106` - `format_completion()` final result pattern
- Use existing `console` singleton (line 17)

### Notes
- All formatters should handle missing fields gracefully (use `.get()` with defaults)
- Truncate very long SQL to 20 lines with "..." indicator
- Confidence should display as percentage (e.g., "85%")
