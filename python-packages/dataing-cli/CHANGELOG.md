## [0.1.0] - UNRELEASED

### Added
- Initial release of the Dataing CLI.
- `dataing run start` - Start investigations from the command line.
- `dataing run status` - Check investigation status with real-time updates.
- `dataing run list` - List investigations with filtering options.
- `dataing run snapshot` - Export investigations as portable archives.
- `dataing run import` - Import investigation archives.
- Rich terminal output with progress indicators and formatted results.
