# fn-10.8 Add Redis to docker-compose.demo.yml

## Description

Add Redis service to `demo/docker-compose.demo.yml` for local development.

### Files to Modify

**demo/docker-compose.demo.yml**:

Add Redis service:
```yaml
services:
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 5

volumes:
  redis_data:
```

Update backend service to depend on Redis:
```yaml
services:
  backend:
    depends_on:
      - postgres
      - redis
    environment:
      - REDIS_HOST=redis
      - REDIS_PORT=6379
```

### Reference

- Existing compose: `demo/docker-compose.demo.yml:1-54`

### Notes

- Use `redis:7-alpine` for smaller image
- Add healthcheck for service dependency ordering
- Volume for data persistence during development
