# fn-43.4 Create PR template with checklist

## Description

Create a pull request template that guides contributors through a consistent review-ready submission. The template enforces quality checks (tests, lint, DCO sign-off) and provides structure so reviewers can quickly understand the change. This reduces review cycles and ensures compliance with project standards.

### Implementation

1. Create `.github/PULL_REQUEST_TEMPLATE.md` with the following sections:
   - **Summary** -- placeholder prompting the author to describe what changed and why.
   - **Related Issues** -- `Closes #` or `Relates to #` placeholder.
   - **Type of Change** -- checkbox list: bug fix, new feature, breaking change, documentation, refactor, test, chore.
   - **Checklist** -- checkbox items:
     - [ ] I have read the [CONTRIBUTING.md](CONTRIBUTING.md) guidelines
     - [ ] My commits follow conventional commit format
     - [ ] My commits are signed off (`git commit -s`) per the DCO
     - [ ] I have added/updated tests for my changes
     - [ ] `just lint` passes locally
     - [ ] `just typecheck` passes locally
     - [ ] `just test` passes locally
     - [ ] I have updated documentation if needed
     - [ ] My changes do not introduce secrets or credentials
   - **Screenshots / Recordings** -- optional section for UI changes.
   - **Additional Context** -- free-form section.
2. Ensure the template is discoverable by GitHub (must be at `.github/PULL_REQUEST_TEMPLATE.md` or `.github/pull_request_template.md`).
