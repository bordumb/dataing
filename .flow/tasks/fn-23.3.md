# fn-23.3 Connection Test Proxy Endpoint

## Description
## Task: Connection Test Proxy Endpoint

Expose the backend connection test through the server extension proxy.

### Goal
Allow the JupyterLab sidebar to test connections before saving, using the existing backend `/datasources/test` endpoint.

### Implementation

1. **Proxy existing endpoint**: The backend already has `POST /api/v1/datasources/test`
   - Server extension should proxy this through `/dataing/api/datasources/test`

2. **Pre-credential test**: For testing before saving credentials:
   - `POST /dataing/connection/test` with `{base_url, api_key}`
   - Server extension makes direct request to backend
   - Returns `{success: true/false, error?: string}`

3. **Extend ProxyHandler**:
   - Add `/api/v1/datasources/test` to allowed proxy paths
   - Or create dedicated `ConnectionTestHandler`

### Files to Modify
- `python-packages/dataing-notebook/src/dataing_notebook/serverextension/handlers.py` - Add test endpoint
- `frontend/jupyterlab-dataing/src/index.ts` - Add test connection function

### Testing
- Unit test: Mock backend, verify proxy forwards correctly
- Integration test: Real backend, verify test succeeds/fails appropriately
