# fn-35.1 Add history magic handler with API-backed browsing and filtering

## Description

Add a `%dataing history` subcommand to the notebook magic that lists past investigations by querying the backend API. Today, only in-memory session history exists (`state.py:36-85`). This task introduces API-backed browsing so users can see investigations from previous sessions, with filtering by dataset and recency.

### Implementation

1. **Register the handler in magic.py** -- add `"history": self._handle_history` to the `handlers` dict at line 160-168.

2. **Implement `_handle_history`** in `DataingMagics`:
   ```python
   def _handle_history(self, args: list[str]) -> None:
       """Handle history subcommand -- list past investigations."""
       parser = argparse.ArgumentParser(prog="%dataing history")
       parser.add_argument("--dataset", "-d", help="Filter by dataset ID")
       parser.add_argument("--days", "-n", type=int, default=30,
                           help="Show investigations from last N days")
       parser.add_argument("--limit", "-l", type=int, default=20,
                           help="Max results to return")
       parser.add_argument("--offset", type=int, default=0,
                           help="Pagination offset")
       # parse ...

       if self._state.client is None:
           print("Error: Not connected. Use '%dataing connect' first.",
                 file=sys.stderr)
           return

       investigations = self._state.client.list_investigations(
           dataset=parsed.dataset,
           days=parsed.days,
           limit=parsed.limit,
           offset=parsed.offset,
       )
       # Render as table (plain text fallback for now; fn-35.4 adds rich HTML)
   ```

3. **Add `list_investigations` wrapper to state or use the SDK client directly.** The backend already exposes `GET /api/v1/investigations` (see `investigations.py:191-238`). The SDK client should be used to call this endpoint. If the SDK lacks query param support, add `dataset`, `days`, `limit`, `offset` params to its `list_investigations()` method.

4. **Add `history` to the help text** in `_show_help` so it appears in `%dataing help`.

5. **Plain-text fallback rendering** -- print a simple columnar table (investigation_id, dataset, status, created_at) until fn-35.4 adds the rich HTML version.
