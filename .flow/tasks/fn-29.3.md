# fn-29.3 Add --no-stream flag with wait behavior

## Description

Add `--no-stream` flag to `dataing run start` that waits for investigation completion and outputs only the final result.

### File to Modify
`python-packages/dataing-cli/src/dataing_cli/commands/run.py`

### Changes

1. **Add `--no-stream` option to `start_run()`**
   ```python
   no_stream: Annotated[bool, typer.Option(
       "--no-stream",
       help="Wait for completion and output final result only (no streaming)",
   )] = False,
   ```

2. **Keep `--no-watch` as hidden alias for backwards compatibility**
   - Both flags should have the same effect
   - `--no-watch` existing behavior: exits immediately with run URL
   - NEW `--no-stream` behavior: waits silently, then outputs final result

3. **Implement wait-and-output behavior**
   ```python
   if no_stream:
       # Stream silently to wait for completion
       final_event = None
       for event in client.stream_run(run_id):
           if event.is_terminal:
               final_event = event
               break

       # Output final result
       if state.json_output:
           console.print(json.dumps(final_event.model_dump(), separators=(',', ':')))
       else:
           console.print(format_completion(final_event))

       # Exit with appropriate code
       if final_event.event == "run_failed":
           raise typer.Exit(1)
   ```

4. **Update help text**
   - `--no-watch`: "(Deprecated) Same as --no-stream"
   - `--no-stream`: "Wait for completion and output final result only"

### Notes
- The existing `--no-watch` prints run URL and exits immediately
- New `--no-stream` actually waits for completion
- This is a behavior change - document in help text
