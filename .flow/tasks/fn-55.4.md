# fn-55.4 Inject PgVectorMemoryStore at entrypoints

## Description

Create `PgVectorMemoryStore` instances at application entrypoints and inject into AgentClient/TemporalAgentAdapter.

### Implementation

1. **Temporal Worker** (entrypoints/temporal_worker.py lines 63-102):
   ```python
   from bond.tools.memory import PgVectorMemoryStore

   # In create_dependencies():
   memory_store = PgVectorMemoryStore(
       pool=app_db.pool,
       embedding_model="openai:text-embedding-3-small",
   )
   agent_client = AgentClient(
       api_key=config.ANTHROPIC_API_KEY,
       memory_store=memory_store,
   )
   ```

2. **API Lifespan** (entrypoints/api/deps.py lines 112-130):
   - Same pattern: create PgVectorMemoryStore from app_db.pool
   - Inject into AgentClient stored in app.state

3. **Graceful Degradation**:
   - If embedding API key not available, log warning and pass `memory_store=None`
   - If pgvector extension missing, fail fast with clear error

### Environment
- `OPENAI_API_KEY` required for embeddings (or use Anthropic embeddings if available)
- Embedding model configurable via `MEMORY_EMBEDDING_MODEL` env var (default: `openai:text-embedding-3-small`)
