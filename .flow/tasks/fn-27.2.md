# fn-27.2 Add to_anomaly_alert conversion to IntegrationAdapter

## Description
Add a `to_anomaly_alert()` method to the `IntegrationAdapter` base class to convert `IssueData` into `AnomalyAlert`.

## Why

Investigations require `AnomalyAlert` with rich context (metric_spec, expected/actual values, anomaly_type). Currently adapters only produce `IssueData` which lacks this structure.

## What to Do

1. Add `to_anomaly_alert(issue_data: IssueData) -> AnomalyAlert` method to `IntegrationAdapter`
2. Add type mapping dictionaries for each provider:
   ```python
   MC_TYPE_MAP = {"freshness": "freshness", "volume": "row_count", ...}
   ```
3. Extract metric info from issue description/metadata where possible
4. Implement in base class with provider-specific overrides
