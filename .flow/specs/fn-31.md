# CLI ask Interactive Mode

## Overview

Implement `dataing ask` command for interactive conversations with running or completed investigations. Users can send follow-up questions, request deeper analysis on specific hypotheses, or pivot the investigation direction through a REPL interface.

## Scope

### In Scope
- `dataing ask` with no args enters interactive REPL for current investigation
- `dataing ask "<question>"` sends one-shot question and streams response
- `dataing ask --investigation <id>` attaches to specific investigation
- Interactive prompt with context indicator (investigation ID, hypothesis count, evidence count)
- Slash commands: `/lineage`, `/hypotheses`, `/evidence`, `/export`, `/help`, `/quit`
- Tab completion for slash commands
- Streaming agent responses with Rich Live display
- Ctrl+C graceful exit (single press cancels stream, double press exits REPL)
- History persistence in `~/.dataing/history` (readline format)

### Out of Scope
- Starting new investigations from within REPL (use `dataing run start`)
- Multi-line input (future enhancement)
- Per-investigation history files (use global history)
- Customizable prompt themes

## Approach

### Context Management

Store current investigation ID in CLI config (`~/.config/dataing/config.toml`):
```toml
[session]
current_investigation_id = "uuid-here"
```

Context is set via:
1. `dataing ask --investigation <id>` - explicit attachment
2. `dataing run start` - auto-attach on successful start
3. Previous session persistence

### Architecture

```
dataing ask
    |
    v
AskCommand (ask.py)
    |
    +-- get_current_investigation() -> UUID
    |       - from --investigation arg
    |       - from config.current_investigation_id
    |       - error if none
    |
    +-- DataingREPL (repl.py)
            |
            +-- PromptSession (prompt_toolkit)
            |       - FileHistory(~/.dataing/history)
            |       - NestedCompleter for slash commands
            |
            +-- CommandHandler
            |       - /lineage -> GET /api/v1/lineage/graph
            |       - /hypotheses -> from investigation state
            |       - /evidence -> from investigation state
            |       - /export -> call existing export logic
            |       - /help -> show available commands
            |       - /quit -> exit REPL
            |
            +-- MessageHandler
                    - POST /api/v1/investigations/{id}/messages
                    - Stream response via /events SSE
```

### SDK Changes

Add to `DataingClient`:
```python
def send_message(self, investigation_id: str, message: str) -> SendMessageResponse:
    """Send a user message to an investigation."""

async def stream_after_message(self, investigation_id: str, message: str) -> AsyncIterator[RunEvent]:
    """Send message and stream subsequent events."""
```
