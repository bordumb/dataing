# fn-34.5 Implement PNG/SVG export and ASCII fallback for non-widget envs

## Description

Add two complementary capabilities to the lineage graph module: (1) export the rendered graph to PNG or SVG files for sharing outside notebooks, and (2) provide a clean ASCII/text-based fallback for environments that do not support ipywidgets (plain terminal IPython, VS Code interactive window without widget support, CI/CD). The ASCII fallback replaces the old Rich tree and should produce a readable DAG representation using box-drawing characters.

Depends on: fn-34.2 (cytoscape widget rendering must be working).

### Implementation

1. **PNG/SVG export via ipycytoscape** -- ipycytoscape supports `.get_png()` and `.get_svg()` methods on the widget. Wrap these in a user-facing export function:

```python
def export_lineage_graph(
    lineage_data: dict[str, Any],
    output_path: str,
    *,
    fmt: str = "png",
    depth: int = 2,
    direction: str = "both",
) -> str:
    """Export lineage graph to PNG or SVG file.

    Args:
        lineage_data: Lineage API response dict.
        output_path: File path to write (e.g., "lineage.png").
        fmt: Export format, either "png" or "svg".
        depth: Max traversal depth.
        direction: 'upstream', 'downstream', or 'both'.

    Returns:
        Absolute path of the written file.

    Raises:
        ImportError: If ipycytoscape is not installed.
        ValueError: If fmt is not 'png' or 'svg'.
    """
    if fmt not in ("png", "svg"):
        raise ValueError(f"Unsupported format: {fmt}. Use 'png' or 'svg'.")

    elements = lineage_to_cytoscape_elements(
        lineage_data, depth=depth, direction=direction
    )
    widget = _build_widget(elements)

    if fmt == "png":
        data = widget.get_png()
    else:
        data = widget.get_svg()

    with open(output_path, "wb" if fmt == "png" else "w") as f:
        f.write(data)

    return str(Path(output_path).resolve())
```

3. **ASCII fallback renderer** using box-drawing characters for non-widget environments:

```python
def _render_ascii_fallback(
    lineage_data: dict[str, Any],
    *,
    depth: int = 2,
    direction: str = "both",
) -> None:
    """Render lineage as ASCII tree to stdout.

    Uses box-drawing characters for a clean DAG display:

        orders (root)
        +-- raw_orders [table]
        |   +-- stg_orders [view]
        +-- raw_customers [table]
            +-- stg_customers [view]

    Args:
        lineage_data: Lineage API response dict.
        depth: Max traversal depth.
        direction: 'upstream', 'downstream', or 'both'.
    """
    root = lineage_data.get("root", "Unknown")
    datasets = lineage_data.get("datasets", {})
    edges = lineage_data.get("edges", [])

    # Build adjacency list
    children: dict[str, list[str]] = {}
    for edge in edges:
        src = edge.get("source", "")
        tgt = edge.get("target", "")
        if direction == "upstream":
            children.setdefault(tgt, []).append(src)
        elif direction == "downstream":
            children.setdefault(src, []).append(tgt)
        else:
            children.setdefault(src, []).append(tgt)
            children.setdefault(tgt, []).append(src)

    # BFS with depth limit, then print tree
    visited: set[str] = set()

    def _print_tree(node: str, prefix: str, is_last: bool, current_depth: int):
        if current_depth > depth or node in visited:
            return
        visited.add(node)

        connector = "+-- " if not is_last else "+-- "
        ds_info = datasets.get(node, {})
        ds_type = ds_info.get("dataset_type", "")
        type_label = f" [{ds_type}]" if ds_type else ""
        root_label = " (root)" if node == root else ""

        print(f"{prefix}{connector}{node}{type_label}{root_label}")

        child_nodes = children.get(node, [])
        for i, child in enumerate(child_nodes):
            is_child_last = i == len(child_nodes) - 1
            child_prefix = prefix + ("    " if is_last else "|   ")
            _print_tree(child, child_prefix, is_child_last, current_depth + 1)

    print(f"Lineage Graph (depth={depth}, direction={direction})")
    print(f"{'=' * 50}")
    _print_tree(root, "", True, 0)
```
