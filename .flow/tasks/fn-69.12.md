# fn-69.12 [M1] Frontend: per-user datasource credentials page

## Description
### Goal
Build the page that the gateway's 403 links to (`/settings/datasources/{id}/credentials`). It doesn't exist yet (design §5.2).

### Implementation
- **Page:** a route and page under `features/settings/`, with forms generated from fn-69.31's schema for each adapter: username/password, key pair, or service-account JSON.
  - Test and Delete buttons.
  - Never echo secrets back.
- **403 handling:** catch 403 `credentials_not_configured` globally in `lib/api/client.ts`, next to the existing `feature_not_available` handling at `:58-65`. Show a toast that links to the page.
## Acceptance
- [ ] Save, test and delete work for username/password, a Snowflake key pair and BigQuery service-account JSON.
- [ ] "Run now" without credentials shows the prompt and link; after saving credentials, "Run now" succeeds.
- [ ] Vitest tests pass.
