# fn-17: SDK → Notebook → Ecosystem

## Overview

Build a coherent data work platform from SDK to notebook to ecosystem tools. The goal: a data worker opens any environment and can point at an asset, get context, run actions, and produce shareable artifacts.

**North Star**: Asset-centric, context-first. IDs are internal details.

**Rule**: User starts from assets/window; the system creates runs. Never require IDs as input.

**No backwards compatibility**: Pre-launch. Ship clean APIs now, not ones we'll hate in 2 months.

## Scope

### In Scope
- `dataing-sdk` Python package (client library, deps: httpx, pydantic, httpx-sse[optional], sqlglot[optional])
- Bundles API (`POST /api/v1/context/bundles`) - snapshot resolution
- Runs API (`POST /api/v1/runs`, `GET /api/v1/runs/{run_id}/events`) - streaming
- Actions API (query, diff, explain with evidence logging)
- `dataing-notebook` package (IPython magics, rich rendering)
- Jupyter server extension (token proxy, multi-user)
- JupyterLab 4.x extension (sidebar, timeline panel)

### Out of Scope
- CLI (`dataing ctx ...`) - future epic
- VS Code extension - future epic
- Slack bot integration - future epic
- JupyterLab 3.x support - future epic
- Mobile apps

## Architecture

### Core Primitives

1. **AssetRef** - Minimal, aligned with DatasetId
   ```python
   class AssetRef(BaseModel):
       platform: str  # "postgres", "snowflake", "dbt"
       name: str      # "db.schema.table" - qualified name
       datasource_id: str | None = None  # Optional disambiguation hint

       def to_urn(self) -> str:
           return f"{self.platform}://{self.name}"

       @classmethod
       def from_urn(cls, urn: str) -> "AssetRef":
           ds = DatasetId.from_urn(urn)
           return cls(platform=ds.platform, name=ds.name)
   ```

   **Canonical URN format**: `{platform}://{name}` where:
   - `platform` = connector type ("postgres", "snowflake", "dbt", etc.)
   - `name` = fully qualified when possible ("db.schema.table")
   - `datasource_id` is **separate**, never embedded in URN

2. **ResolvedAsset** - Per-asset resolution result
   ```python
   class ResolvedAsset(BaseModel):
       asset: AssetRef
       datasource_id: str | None
       dataset_id: str  # Canonical URN
       dataset_type: str | None  # TABLE/VIEW/MODEL
   ```

3. **ContextBundle** - Snapshot (cacheable)
   ```python
   class ContextBundle(BaseModel):
       bundle_id: str
       resolved_assets: list[ResolvedAsset]
       default_datasource_id: str | None
       lineage: LineageGraphResponse | None
       operational: OperationalFacts | None
       anomalies: list[AnomalySummary] | None
       bundle_hash: str  # SERVER-DERIVED, IS the cache key
       expires_at: datetime
   ```

4. **Run** - Streaming container
   ```python
   class RunStatus(str, Enum):
       RUNNING = "running"
       COMPLETED = "completed"
       FAILED = "failed"
       CANCELLED = "cancelled"

   TERMINAL_STATUSES = {RunStatus.COMPLETED, RunStatus.FAILED, RunStatus.CANCELLED}

   class Run(BaseModel):
       run_id: str
       bundle_id: str
       bundle_hash: str
       status: RunStatus
       error_code: str | None = None
       created_at: datetime
   ```

5. **StreamEvent** - seq-based cursor
   ```python
   class StreamEvent(BaseModel):
       seq: int  # Resume cursor - NOT UUID
       event: str
       run_id: str
       data: dict
       timestamp: datetime
   ```

6. **RunEvidence** - Attached to run
   ```python
   class EvidenceKind(str, Enum):
       SQL = "sql"
       LOG = "log"
       METRIC = "metric"
       SCHEMA = "schema"
       PIPELINE = "pipeline"
       NOTE = "note"

   class RunEvidence(BaseModel):
       evidence_id: str
       run_id: str
       kind: EvidenceKind
       sql_hash: str | None
       source: dict | None
       result_summary: str | None
       conclusion: str | None
       confidence: float | None
       linked_assets: list[str]  # URN strings
   ```

7. **SDK Exceptions**
   ```python
   class DataingError(Exception): pass
   class AmbiguousAssetError(DataingError): ...
   class AuthError(DataingError): pass
   class RateLimitError(DataingError): ...
   ```

## Acceptance

- [ ] SDK installable via pip
- [ ] One-call API: `/api/v1/runs` accepts inline `bundle` OR `bundle_id`
- [ ] One-call SDK: `client.run(assets, goal)` works
- [ ] Per-asset resolution with disambiguation (409 + candidates)
- [ ] RunStatus enum with terminal states

- [ ] URN format: `{platform}://{name}`, datasource_id separate
- [ ] Token proxy discovers URL (JupyterHub-safe)
- [ ] from_sql supports dialect, default_database, default_schema
