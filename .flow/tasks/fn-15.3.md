# fn-15.3 Create events.py with Complete Event Catalog

## Description

Create `maistro/src/maistro/events.py` with the complete event type catalog as frozen dataclasses.

**Base class:**

```python
@dataclass(frozen=True)
class Event:
    """Base event class. seq is assigned by EventLog, not by caller."""
    seq: int = 0  # Placeholder, stamped by log.append()
```

**Complete Event Catalog:**

| Event | Fields | Purpose |
|-------|--------|---------|
| `RunStarted` | `run_id: str`, `start_step: str` | Workflow execution begins |
| `StepStarted` | `step_name: str` | Step execution begins (UI, stuck detection) |
| `StepCompleted` | `step_name: str`, `context_update: dict[str, Any]`, `signal: Signal` | Step finished successfully |
| `StepFailed` | `step_name: str`, `error: str` | Step raised exception |
| `BranchStarted` | `branch_name: str`, `start_step: str` | Branch execution begins |
| `BranchCompleted` | `branch_name: str`, `context_update: dict[str, Any]` | Branch finished |
| `InputRequested` | `token: str` | AWAIT_USER triggered |
| `InputReceived` | `token: str`, `payload: Any` | External input provided |
| `RunPaused` | `reason: str` | Run paused |
| `RunResumed` | `reason: str` | Run resumed |
| `RunCompleted` | `final_context: dict[str, Any]` | Workflow finished successfully |
| `RunFailed` | `error: str` | Workflow finished with failure |

**Design notes:**
- Events store `context_update` (delta), not full context - keeps logs lightweight
- `StepCompleted.signal` captures what the step returned (CONTINUE, COMPLETE, etc.)
- `BranchCompleted` events are emitted in canonical alphabetical order by Runner
- All events are frozen (immutable after creation)
- `seq` is assigned by `EventLog.append()`, not by event creators
